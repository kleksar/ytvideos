# Обязательный вход в работу канала

Прочитать этот документ до процедуры любого `ytv-*` skill. Ссылка сама по себе не означает загрузку документа.

1. Прочитать [корневой AGENTS.md](../AGENTS.md).
   Маршрутизация Paper по умолчанию и заморозка Nuviko History описаны в root §2; реестр используется для сверки конкретного выпуска.
2. Если вместе с клоном получен согласованный episode bundle, сверить его реестр и точный рабочий путь. Прочитать `current_context`, если он указан; в `state_sources` — только нужные текущему действию сведения. В клоне доступен компактный [текстовый архив](../archive/story_text/README.md); он не содержит полноценные рабочие эпизоды или медиа. Не создавайте выпуск по номеру или slug: запросите рабочий bundle и владельца у команды.
3. Прочитать правила выбранного канала: **Paper Detour** → [канальные правила](../channels/paper_detour/AGENTS.md); **Nuviko History** → [канальные правила](../channels/nuviko_history/AGENTS.md); **Scenes on Repeat** → [канальные правила](../channels/scenes_on_repeat/AGENTS.md); русскоязычный **«Нувико»** → [идентичность и владельцы](../COLLABORATION.md#каналы-и-владельцы). Архив **Stories RU/EN** → [канальная заметка](../channels/nuviko_stories/AGENTS.md) только при явном поручении по архиву; он не является каналом «Нувико». Номер, тема и slug не назначают канал.
4. Перед канально-зависимой работой установить канал по [root §2](../AGENTS.md#2-bootstrap-и-канал): Paper Detour используется по умолчанию; зарегистрированный выпуск сверять по поручению и материалам. Nuviko History остаётся замороженным, пока пользователь прямо не снимет заморозку или не поручит конкретное исключение. Для общей задачи достаточно root и предметной документации. `UNVERIFIED` требует установить идентичность перед действием, зависящим от канала.
5. Для подбора новой темы, в том числе через тренды или аналитику, применять [ytv-topic-research](../.agents/skills/ytv-topic-research/SKILL.md).
6. Выбрать процедуру текущей задачи:

Для разработки и приёмки изображений любого канала прочитать [общий стандарт смелой визуальной подачи](VISUAL_STAGING.md); канальный профиль задаёт его художественное исполнение.

`history` в машинном реестре хранит происхождение и прошлые решения для разбора по необходимости. Поле `records` — полный инвентарь источников, а не обязательный список чтения. Если текущей сводки нет, установить нужное состояние по записям и фактическим материалам, затем сохранить короткое актуальное обновление выпуска. Действующие разрешения, права и ограничения из этих источников сохраняются.

Для радио 001 перед монтажом обязательны актуальные владение и блокировка из его журнала координации. Это эксплуатационное условие относится к конкретному target.

Для полного производства Paper Detour/Nuviko History использовать [карту маршрута](../.agents/skills/ytv-video-production/references/episode-flow-state.md) только после получения episode bundle, сверки текущего состояния и активного владельца. Существующие активные выпуски не мигрируются без координации.

## Локальные точки входа

Канонические skills находятся в `.agents/skills` в корне репозитория. В клоне эта папка используется напрямую; локальные compatibility symlinks не нужны и не входят в Git. Относительные ссылки внутри skill вычислять от его канонического файла.

Новый выпуск добавить в реестр, затем выполнить `python3.11 .agent/scripts/install-entrypoints.py` и проверить discovery. Из произвольных глубоких папок использовать корень либо зарегистрированный вход выпуска. Эпизодный AGENTS указывает root, bootstrap и канал.

Native `skills/list` проверяет обнаружение, пути и отсутствие дублей. Это не тест будущего выбора навыка моделью или фактического чтения ею правил.

## Проверка опубликованных изменений правил

На старте и возобновлении работы выполнять [проверку изменений](RULES_SYNC.md) для фактического scope. Дальнейшие безопасные точки и обработка ошибок описаны там; текущие процессы и решения пользователя сохраняются.
