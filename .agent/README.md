# Рабочая карта ytvideos

Точка входа — [AGENTS.md](../AGENTS.md). Процедуры находятся в `.agents/skills`, обязанности исполнителей — в `.codex/agents`. Справки из этой папки читаются по ссылке для текущей задачи.

- [Канальный bootstrap](CHANNEL_BOOTSTRAP.md) — порядок входа и поддерживаемые рабочие каталоги.
- [Каталог навыков](skill-catalog.md) — процедура по задаче.
- [Владельцы правил](documentation-index.md) — канонический документ каждой темы.
- Реестр и каталоги выпусков могут быть вынесены из source-only клона; работайте с ними только после получения согласованного episode bundle.

Текущую работу записывать рядом с episode bundle по [шаблону](templates/episode-update.md); консультацию — по [шаблону](templates/consultation.md). Записывать фактически сделанное и проверенное. При изменении процесса заменить действующее правило и связанные ссылки в том же проходе.

Локальные журналы обслуживания и исходные квитанции остаются вне source-only клона; подключайте их только по необходимости и после согласования.

Структура каналов и общих компонентов — [CHANNEL_LAYOUT](CHANNEL_LAYOUT.md). Машинные карты и выпускные реестры подключаются вместе с соответствующими рабочими материалами.
