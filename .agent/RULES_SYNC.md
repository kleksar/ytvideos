# Закрепление правил

Run использует закреплённые code/profile/workflow/skill versions. Новая версия main не меняет работающий выпуск автоматически. Перед задачей worker проверяет pins через приложение; чтение правил с абсолютного пути другого Mac не требуется.

Изменение правил сохраняется по [общему порядку Git](../docs/development.md#git-и-совместная-работа) и применяется к новым runs: основная ветка — `main`, для отдельной ветки сразу открывается PR в `main`. Старым consumers до переключения общих входов сохранить прежний checkout либо verified snapshot. Перенос конкретного run выполняется по [migration](../docs/migration.md), с owner, исходными evidence и receipt.

Проверять актуальность внешней API capability, когда конкретное действие этого требует; это не повод на каждом stage переписывать художественный контракт текущего выпуска. Уже отправленные внешние операции сверять при rollback отдельно.
