## Конечные заставки · план первой примерки

- **Paper Detour.** Подтверждённый сохранённый образец по квитанции — [Paper 038, 47 Ronin](../channels/paper_detour/videos/038_47_ronin/Packaging/EndScreen/END_SCREEN_PLAN_v04.md), `muokDIO62dg`. Нативный Subscribe слева, две конкретные видеокарточки справа. Содержимое квитанции прочитано. В этой сессии открыта страница видео, отдельный свежий read-back элементов не получен из-за прерванного перехода в редактор. Использовать действующий [Paper стандарт](../.agents/skills/ytv-video-production/references/paper-end-screens.md).
- **Nuviko History.** В пользовательской разработке почти десятисекундный финал. Для примерки на первом новом длинном фильме зарезервировать слева место под нативный Subscribe с аватаром канала, справа две зоны 16:9 одна над другой. Координаты и размеры определить в Studio по реальному 16:9 MP4. История и последняя реплика заканчиваются до появления карточек. Фоновая композиция работает сама по себе при скрытых элементах. Текущая [справка Nuviko](../.agents/skills/ytv-video-production/references/nuviko-end-screens.md) предусматривает кадр под сюжет. Общую схему размещения можно применять к этим кадрам. Единый фон, который разрабатывает пользователь, остаётся кандидатом для отдельной примерки. Правила профиля этой квитанцией не изменены.
- **Цели Nuviko.** Свежий API подтвердил открытые обработанные фильмы канала, включая Marseille 1720 (`lBRlnobdTvQ`), Black Death (`oH_daCEzekA`), Pompeii (`3mhzbbbWA0g`), Voyager (`-dTi-_jQPgg`) и Gunpowder Plot (`S9dKN5iXmPc`). Конкретную пару выбрать по теме следующего фильма и заново проверить Public, канал и формат. При одной подходящей цели достаточно одной видеокарточки. При отсутствии подходящих целей оставить этот этап открытым. Выбор конкретного выпуска и целей в этой задаче не зафиксирован.
- **При порученном выпуске.** Открыть видео в Studio → Редактор → Конечная заставка. Если доступен импорт из своего видео, взять утверждённый образец того же канала. Иначе добавить Subscribe и видеокарточки вручную либо взять встроенный шаблон Studio. На новом видео заново выставить начало по фактическому финалу MP4 (обычно `D−10 с`), проверить расположение и точные цели. Сохранить и повторно открыть редактор. Первый проверенный выпуск Nuviko станет образцом своего канала. Наличие и поведение импорта предстоит проверить на подходящем новом видео.
- **Shorts.** Для них есть отдельная функция [«Связанное видео»](https://support.google.com/youtube/answer/14075157?hl=en). Этот план относится к длинным 16:9.

Конфигурация ни одного видео в этой задаче не записывалась. [Справка Studio об End Screen](https://support.google.com/youtube/answer/6388789?hl=en) · [Запись консультации](consultations/2026-11-05-two-channel-end-screen.md).
