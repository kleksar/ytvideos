## 1. Рекомендуемая стартовая модель

Для 10-минутного Paper Detour предлагаю рассматривать пакет как набор независимых публикаций, а не обязательный комплект фиксированного размера.

Базовый пакет для тестирования

# 1

Long film

Основной продукт

# 1–3

Shorts

Только самостоятельные истории

# 0–1

Карусель

Необязательное дополнение

# 1

Общий календарь

С учётом всех публикаций канала

Три потенциальных Shorts — это три кандидата, а не обязательство выпустить все три.

## 2. Критерии количества производных

Для каждого Short проверить:

| Критерий          | Условие допуска                                            |
| ----------------- | ---------------------------------------------------------- |
| Самостоятельность | Есть собственный хук, причинная история и развязка         |
| Отличие           | Не пересказывает другой Short или центральную линию фильма |
| Визуальность      | Есть собственная последовательность выразительных диорам   |
| Фактология        | Все существенные утверждения подтверждаются источниками    |
| Ценность          | Зритель получает законченную историю без перехода к фильму |

Для карусели дополнительно:

- история понятна без просмотра видео;
- изображения образуют последовательное повествование;
- текст не дублирует Short;
- материал оправдывает отдельную публикацию.

Правило пропуска: если материал слабее фильма, повторяет уже опубликованный Short или требует удержать развязку ради перехода — не публиковать его в составе пакета.

## 3. Предлагаемая тестовая последовательность

Это стартовая гипотеза для обсуждения, а не установленный алгоритмический оптимум.

1. День 0 — Long film

   Сначала завершить QA, загрузить фильм Private. Проверить финальную версию, метаданные, звук и доступность.
2. День 1 — Short A

   Первый самостоятельный вопрос. После открытия фильма сделать его Public или Unlisted, проверить доступность и привязать как Related video.
3. День 3 — Карусель (если прошла редакционный отбор)

   Самостоятельная визуальная история. Не использовать её исключительно как рекламу фильма.
4. День 5 — Short B

   Другой самостоятельный вопрос, отличный от первого и от центральной истории фильма.
5. День 8 — Short C (условно)

   Выпускать только при наличии третьего полноценного материала. Иначе пропустить.

Интервалы 1/3/5/8 дней нужны для начального сравнения и распределения нагрузки. Их не следует считать оптимальными интервалами YouTube.

## 4. Связь с общим календарём канала

Календарь должен учитывать не только пакет, но и остальные публикации Paper Detour.

При планировании учитывать:

- готовность каждого материала;
- ожидаемую продолжительность QA и исправлений;
- фактическую производительность производства;
- уже запланированные длинные фильмы и Shorts;
- конкуренцию за внимание аудитории между близкими публикациями.

Не переносить автоматически все производные вслед за задержавшимся фильмом. Сначала проверить их самостоятельную ценность и актуальность.

Особенно важно: не выпускать три Shorts подряд только потому, что они принадлежат одному фильму.

## 5. Техническое правило Related video

Официальное ограничение YouTube: Related video должен вести на видео со статусом Public или Unlisted. Private для этой привязки не подходит.

Поэтому:

1. Загрузить фильм Private.
2. Проверить фильм и его финальную версию.
3. Открыть фильм до Public или Unlisted.
4. Создать или обновить привязки Shorts.
5. Проверить фактическую доступность перехода.

Само расписание публикаций не выполняет эту проверку автоматически.

Официальная справка: [Add a related video to your YouTube Shorts](https://support.google.com/youtube/answer/14075157?utm_source=chatgpt.com).

## 6. Как оценивать эксперимент

Не пытаться приписать весь рост длинного фильма конкретному Short.

Для каждого материала отдельно фиксировать:

| Материал  | Основные показатели                                             |
| --------- | --------------------------------------------------------------- |
| Long film | Views, impressions, CTR, average view duration, retention       |
| Short     | Engaged views, viewed vs swiped away, average percentage viewed |
| Карусель  | Доступные показы, взаимодействия и комментарии                  |
| Связка    | Переходы по Related video, если соответствующие данные доступны |

Дополнительно смотреть:

- динамику длинного фильма до и после выхода производных;
- доступные источники трафика;
- различия между Shorts;
- комментарии и содержательные реакции;
- повторные просмотры и возвращающихся зрителей, если метрики доступны.

Не делать вывод о причинном эффекте только по совпадению роста фильма с публикацией Short. Для более уверенного вывода нужны отдельные данные о переходах и сопоставление с обычной динамикой канала.

## 7. Правило принятия решения после пилота

- Если Short получает самостоятельный отклик и приводит измеримые переходы — формат стоит развивать.
- Если Short интересен сам по себе, но переходов мало — он всё равно может быть успешной отдельной публикацией.
- Если карусель требует много производства, но не добавляет самостоятельной ценности — исключить её из будущих пакетов.
- Если три Shorts заметно конкурируют между собой или с фильмом, сократить количество производных.
- Если третий Short слабый, не выпускать его ради соблюдения плана.

Итоговая рекомендация: начать с одного фильма, двух обязательных кандидатов Shorts, одного условного третьего и одной необязательной карусели. Сначала подтвердить качество фильма, затем готовность производных, после чего назначить даты по общему календарю. Через один полный цикл оценить не только переходы на фильм, но и самостоятельную ценность каждого формата.
