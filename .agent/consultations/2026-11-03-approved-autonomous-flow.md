4. Packaging/A-B: для длинных фильмов любого канала три названия и три обложки параллельно просмотру. Shorts — обычная упаковка. Варианты не превращать в обязательный запуск YouTube теста.
5. Release: после одобрения видео и упаковки автономные export, техническая проверка и Unlisted, затем остановка; без дополнительного согласования экспорта.
6. Lifecycle: без безусловной очистки; только owned-run manifests с сохранением source/import dependencies/current final/provenance.
Приоритет — устранить дублирующие требования, оставить одного владельца правила.
