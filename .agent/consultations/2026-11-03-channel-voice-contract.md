# Консультация: контракт голосов каналов

- Дата: 2026-11-03; координатор лично в Google Chrome.
- URL: https://chatgpt.com/g/g-p-6ae147d3975481919b5bfda6935777d0-yt-video/c/6aea19ad-8cc0-83eb-9130-29cae3498da3
- Непосредственно перед запросом видимая маркировка: `Extra High`.
- Промпт: «Ты — консультант в уже открытом ChatGPT Extra High. Требование внешнего координатора уже выполнено этим обращением; дай ответ здесь, не открывай рекурсивно другой ChatGPT. Одна узкая задача: предложи краткий технический контракт, который исключит случайный выбор другого ElevenLabs voice ID при генерации для двух каналов. Учитывай явный обязательный channel, единый реестр, проверку ID до платного запроса, запрет молчаливого fallback, историю фактического голоса и существующие старые записи. Не выбирай голоса самостоятельно.»
- Завершённый ответ: строгое соответствие channel → voice ID в едином реестре; обязательный channel без общего default; до платного вызова проверить ID и доступность read-only API; при переключении аккаунта проверить тот же ID; при отсутствии/расхождении остановиться. На каждый аудиофайл сохранять канал, запрошенный и отправленный ID, параметры, hash, статус, account reference и ревизию реестра. Старые файлы сохранить; ID извлекать из фактических свидетельств, при их отсутствии unknown. Проверять отказ без канала, несовпадение, доступность и исходящий запрос каждого канала.
- Принято: реестр, обязательный channel, проверка доступности, запрет подмены, запись запроса и тесты. Отдельные requested/sent ID, account reference и ревизия реестра в квитанции прямого helper не реализованы; записанный ID соответствует параметру запроса. Историю не выводить из текущего реестра. Доступность голоса не доказывает качество звучания.
