# Проверка кандидатов очистки

Chrome, ChatGPT project YT Видео; режим непосредственно перед запросом: `Extra High, 4 из 5`; чат https://chatgpt.com/g/g-p-6ae147d3975481919b5bfda6935777d0-yt-video/c/6aea2068-4f88-83eb-9cb9-f308a6c63c0d

Запрос: порядок безопасной проверки старых рендеров, общего кэша и активного ремейка; оценка освобождения на APFS. Первый ответ не загрузился, короткий повтор выполнен при том же режиме.

Ответ: сначала проверять рендеры по фактическим версиям, проектам и экспортам, затем общий кэш по потребителям; неизвестные связи сохранять. Разделять logical, allocated и фактически освобождённое место: APFS clones, snapshots и hard links не позволяют обещать освобождение по сумме. Измерять до/после, учитывая параллельную запись.

Принято для данного отчёта: показывать предварительные объёмы и отдельно действующие проекты/потребителей; пользователь просил оценку, не удаление. Консультация не доказывает принадлежность файлов или их безопасность.
