### 2. Минимальная норма для root AGENTS

Сценарий должен быть понятен целевой аудитории при первом прослушивании без предварительного знания конкретной истории. Учитывай язык, релевантные культурные различия и предполагаемый уровень подготовки аудитории.

Различай знакомство со словом, понимание его значения в данном контексте и знание конкретного события.

Сохраняй знакомые и достаточно понятные слова без словарных определений. Уточняй бытовые или неоднозначные значения только там, где это необходимо для понимания сюжета. Малоизвестные имена и названия вводи через роль, действие или значимость.

Перед оценкой понятности зафиксируй нейтральный профиль целевой аудитории: язык, основные регионы, общий или специализированный зритель.

Проводя независимую проверку первого слушателя, передавай оценщику только narration и нейтральный профиль аудитории, без авторских объяснений и утверждений о знакомости терминов.

### 4. Архитектурное решение
