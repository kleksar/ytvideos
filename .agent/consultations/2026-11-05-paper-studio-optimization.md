## Ответ

Рекомендованный дефолт — Education для новых историко-научных роликов, независимо от длительности. Entertainment оставить для развлекательного архива и отдельных новых видео, где основной продукт — развлечение, а не объяснение реальных событий.

Не нужно массово менять категории старых роликов или рассчитывать, что смена категории сама по себе повысит просмотры. YouTube документирует выбор категории, но не гарантирует прирост рекомендаций от Education.

### 1. Категория и настройки выпуска

| Тип видео | Категория | Дополнительная настройка |
|---|---|---|
| Исторический документальный фильм | Education | Concept overview или Other |
| Историко-научный Short | Education | Concept overview или Other |
| Научное объяснение, эксперимент | Education | Science experiment только для реального эксперимента |
| Развлекательная история без образовательной задачи | Entertainment | Необязательные образовательные поля пропустить |
| Старые развлекательные видео | Оставить прежнюю | Массовая миграция не требуется |

Поля Academic system, Level, Exam / course / standard не нужно заполнять искусственно: для обычной документалистики они чаще неприменимы. (YouTube Help +1.)

Настроить дефолт можно через YouTube Studio → Settings → Upload defaults → Advanced settings → Category.

Важное ограничение: YouTube прямо указывает, что Upload defaults применяются к загрузкам через браузер, но не гарантированно к мобильным загрузкам и сторонним инструментам. Для API-автоматизации категорию и остальные поля следует проверять после загрузки. (YouTube Help +1.)

### 2. Настройки канала

В Settings → Channel → Advanced settings я рекомендую следующее:

| Настройка | Рекомендация |
|---|---|
| Audience | No, set this channel as not Made for Kids, если контент действительно не предназначен специально для детей |
| Allow viewers to clip my content | Включить |
| Automatic captions: Don't show potentially inappropriate words | Не включать автоматически; использовать проверенный английский SRT |
| Allow third-party companies to train AI | Оставить выключенным, если нет намерения предоставлять такое разрешение |
| Feature eligibility | Проверить доступность Advanced features |

В настройках комментариев: Comments On + Basic moderation, а также удержание подозрительных ссылок, если доступно.

В Upload defaults установить English, Education, Standard YouTube License, разрешение на встраивание (если нет ограничений правообладателей), включить автоматические главы для подходящих длинных видео и выбрать безопасную непубличную видимость при подготовке выпуска.

Это практические рекомендации, а не требования алгоритма. (YouTube Help +2.)

### 3. Проверки отдельного видео

Перед выпуском проверять:

- Metadata: заголовок, обложка, описание, источники, категория, плейлист.
- Language: English; отдельная английская дорожка SRT, если видео содержит речь.
- Audience / restrictions: Made for Kids, возрастное ограничение, авторские права.
- Altered or synthetic content: реалистично сгенерированные события требуют соответствующей декларации; очевидная стилизованная анимация не обязательно требует её.
- Distribution: видимость, дата публикации, уведомления подписчикам, разрешения на ремиксы.
- Для длинных: главы, End Screen, корректные цели рекомендаций.
- Для Shorts: поле Related Video, если есть подходящий ролик и доступна функция Advanced features. (YouTube Help +2.)

### 4. Повторяемая геометрия End Screen

Для 16:9 и десятисекундного финала предлагаю такую базовую схему:

Вариант A — Subscribe + 2 видео

Схема размещения нативных элементов, не точные координаты Studio.

Вариант B — Subscribe + 1 видео

Меньше визуального шума; предпочтительнее, если две рекомендации слишком мелкие.

Начальный дефолт — вариант A, когда есть два подходящих публичных фильма и три элемента не конфликтуют. При плохой читаемости или наличии только одного подходящего фильма использовать B. Не нужно заполнять место нерелевантным видео ради симметрии.

YouTube подтверждает: End Screen может занимать последние 5–20 секунд видео продолжительностью от 25 секунд; для обычного 16:9 допустимо до четырёх элементов. Но итоговое отображение зависит от устройства и поведения зрителя. (YouTube Help +1.)

### 5. Проверка шаблона

1. Открыть непубличный тестовый длинный ролик: Studio → Content → Editor → End screen.
2. Добавить Subscribe и одно или два Video; для каждого выбрать конкретный ролик.
3. Установить время начала за 10 секунд до конца, проверить положения через Snap to grid, воспроизвести preview.
4. Сохранить и повторно открыть Editor: проверить тайминги, позиции и цели.
5. Открыть ссылку на тестовый ролик в приложении YouTube на телефоне. Посмотреть последние 10 секунд и проверить, что элементы видны, читаемы и ведут к нужным видео.
6. Для следующего ролика проверить Apply template. Если интерфейс предлагает Import from video, отдельно убедиться, что импортировались не только позиции, но и цели с таймингами.

Что зависит от интерфейса: наличие импорта из другого видео, точность воспроизведения геометрии, допустимые положения элементов и их отображение на конкретном телефоне. В мобильном браузере End Screen обычно недоступен — тестировать следует именно приложение. После публикации дополнительно смотреть Analytics → Engagement → End screen element click rate. (YouTube Help +1.)

Такой порядок позволяет сохранить один рабочий шаблон без изменения старого каталога и без предположений о скрытых факторах ранжирования.

## Принятые решения

Education соответствует каталогу и подтверждена в списке категорий Data API. Из консультации взяты явная категория, проверка отдельного выпуска и мобильная проверка заставки. Источники остаются в рабочих материалах по root AGENTS. Точная геометрия получена из Studio. Перенос пропорций, ссылок и положения относительно конца подтверждён пробным импортом на другом ролике. Сохранение дефолта и конфигурации образца подтверждено перечитыванием.
