## Ответ

Рекомендация: использовать YouTube Studio как источник нативных End Screen, а 10-секундный финал MP4 — только как визуальный фон под них. Для первого канала повторно использовать уже принятую конфигурацию через Import from video, если эта команда доступна в текущем Studio. Для второго сначала один раз создать собственную конфигурацию, затем использовать её как образец для следующих видео.

Главный риск первого теста — предположить, что импорт автоматически правильно перенесёт тайминг, координаты и выбранные видео. Это нужно проверить отдельно.

### 1. Что подтверждено документацией YouTube

| Параметр | Установленное правило |
|---|---|
| Продолжительность End Screen | Последние 5–20 секунд |
| Минимальная длина видео | 25 секунд |
| Элементы для 16:9 | До 4 |
| Subscribe | Нативный элемент с каналом |
| Видео | Можно выбрать конкретное видео |
| Playlist | Можно показывать публичный плейлист |
| Тайминг | Настраивается отдельно для каждого элемента |
| Позиции | Перетаскиваются непосредственно в предпросмотре |

Источники: официальная документация YouTube Help (+2).

Для принятой конфигурации первого канала:

End Screen · 10 seconds

Схема расположения нативных элементов

```
            Video 1
SUBSCRIBE
            Video 2
```

Иллюстрация структуры, не точные размеры элементов YouTube.

Начало: D − 10 сек.

Конец: D

Здесь три нативных элемента: Subscribe и два Video. Для стандартного 16:9 это допустимая конфигурация.

Важно: зритель может скрыть End Screen. YouTube также предупреждает, что отображение элементов может различаться в зависимости от устройства и контекста. Поэтому фон должен оставаться визуально завершённым и без интерактивных элементов. (YouTube Help +1.)

### 2. Первый безопасный тест

Я бы проводил его на одном следующем длинном видео, уже находящемся в Studio, не меняя его текущую доступность и не публикуя.

Канал №1 — уже принятый финал.

1. Открыть YouTube Studio → Content.
2. Выбрать тестовое видео.
3. Editor → End screen.
4. Если доступен Import from video, выбрать видео, где уже установлен принятый финал.
5. Проверить импортированные элементы.
6. Установить для каждого интервал последних 10 секунд.
7. Проверить расположение относительно нового фонового финала.
8. Проверить конкретные цели обоих Video-элементов.
9. Save.

Исторически YouTube документировал Import from video как способ повторного использования End Screen другого собственного видео. Однако актуальная справка подробно описывает Apply template, настройку тайминга и расположения, но не гарантирует точное поведение импорта всех параметров. (filmot.com +1.)

#### Что обязательно проверить после импорта

| Параметр | Что проверить |
|---|---|
| Тайминг | Начало = D − 10, конец = D |
| Subscribe | Выбран именно текущий канал |
| Video 1 | Правильный фильм |
| Video 2 | Правильный фильм |
| Позиция Subscribe | Слева |
| Позиции Video | Справа, без перекрытия |
| Размеры | Элементы не выходят за границы кадра |

Особенно важно: не предполагать, что Studio автоматически перенесёт тайминг относительно конца нового видео. Импортированное время может потребовать ручной корректировки.

Для позиций использовать сетку Studio, Snap to grid и Snap to element.

### 3. Повторное использование на двух каналах

Здесь есть существенное различие.

Первый канал: уже есть готовое видео-образец. Его можно использовать как источник импорта для последующих видео этого же канала.

Второй канал: конфигурацию нужно создать отдельно. Не рассчитывать на импорт из первого канала: документированный сценарий импорта предполагает использование собственного предыдущего видео. Нативный Subscribe также должен относиться к текущему каналу.

Порядок для второго канала:

1. Открыть первое подходящее длинное видео.
2. Создать End Screen через Apply template либо вручную добавить элементы.
3. Выставить позиции под новый 10-секундный фон.
4. Добавить только реально существующие подходящие видео.
5. Сохранить.
6. Проверить результат.
7. Использовать это видео как образец для следующих видео второго канала.

Таким образом, у каждого канала будет свой собственный эталонный End Screen.

### 4. Если у второго канала 0, 1 или 2 подходящих фильма

| Доступные фильмы | Конфигурация |
|---|---|
| 0 | Не придумывать цели и не ставить нерелевантные видео. Проверить, принимает ли Studio Subscribe-only. Если нет — пока оставить только визуальный финал без нативных элементов. |
| 1 | Subscribe + один конкретный Video. Второй слот оставить свободным. |
| 2 | Subscribe + два конкретных Video. Полная конфигурация. |

Есть дополнительная возможность: YouTube позволяет выбирать уже существующие публичные и unlisted видео. Поэтому если подходящий фильм уже находится в доступе unlisted и его действительно допустимо рекомендовать зрителям, его можно использовать без изменения видимости. Private-видео не следует считать доступной целью. (YouTube Help +1.)

Не нужно дублировать один фильм в двух карточках ради симметрии. Не нужно выбирать Best for viewer, если принципиально важны две конкретные истории.

Отдельно: актуальная справка не даёт однозначной гарантии, что Subscribe-only будет приниматься редактором во всех случаях. Поэтому нулевой сценарий проверяется непосредственно в Studio.

### 5. Что делать с Shorts

Shorts не следует включать в эту схему 16:9.

Для них YouTube предоставляет отдельный механизм Related video:

- ссылка отображается в Shorts player;
- требуется доступ к расширенным функциям канала;
- можно связать Short с видео, другим Short или трансляцией;
- целевое видео должно быть публичным или unlisted.

Это отдельная функция, а не импортируемый End Screen. (YouTube Studio App Help Center +1.)

### 6. Проверка после Save

Для первого тестового видео использовать следующий короткий контрольный список:

- Studio подтвердил сохранение.
- После повторного открытия Editor элементы остались на месте.
- Тайминг каждого элемента — последние 10 секунд.
- Subscribe ведёт на правильный канал.
- Обе карточки ведут на правильные фильмы.
- Нативные элементы не перекрывают друг друга.
- Элементы не закрывают важную часть фоновой композиции.
- Воспроизведение предпросмотра от начала финала до конца выглядит корректно.
- Текущая видимость видео не изменилась.

После успешного теста сохранить название исходного видео как внутренний эталон конфигурации каждого канала.

Итоговая схема работы:

| Объект | Первый канал | Второй канал |
|---|---|---|
| 10-секундный фон | Принят | Создаётся |
| Нативный Subscribe | Уже настроен | Настроить отдельно |
| Две карточки | Два конкретных фильма | По наличию контента |
| Первый эталон | Уже существует | Создать на первом видео |
| Следующие видео | Import from video | Import from video |
| Shorts | Related video | Related video |

Мой выбор: не пытаться сразу стандартизировать все видео обоих каналов. Сначала провести один тест импорта на первом канале и один ручной тест на втором. После этого закрепить два эталонных шаблона и применять их только к новым длинным видео. Старый каталог, публикации и настройки доступности не затрагивать.

## Решение координатора

Применить идею двух отдельных образцов и повторного чтения настроек. Официальная справка подтверждает редактор, встроенные шаблоны и ручную настройку. Команду импорта и перенос её полей считать условными до фактической примерки на новом видео. Для Paper 038 есть отдельная квитанция, подтверждающая сохранённые элементы. При отсутствии подходящих целей использовать правила канала. Предложения про Subscribe-only и Unlisted из консультации не принимаются как стандарт проекта.
