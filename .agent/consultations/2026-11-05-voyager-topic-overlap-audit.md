## Вывод и исправление

Непосредственная причина — пропущенная проверка текущих работ. Это не осознанное решение заменить длинный фильм коротким и не разработанное предложение поддержки long. Консультант получил неполные входы; координатор не проверил возвращённого кандидата по каталогу перед рекомендацией.

Пробел документации усилил ошибку: bootstrap направлял к registry/current context прежде всего для конкретного выпуска/предоставленного bundle, не выделяя обязательную проверку при общей задаче поиска тем. Root §0 уже требовал сверять доступный реестр; этот пропуск нельзя объяснить только недостатком документации.

Каноническое правило добавлено в bootstrap «Подбор новых тем и пересечения»: доступный реестр, каталог и текущие чаты → контекст потенциальных совпадений → список занятых тем для консультанта → повторная проверка кандидатов перед выдачей. Связанный новый угол или Short обозначается явно с исходной работой и самостоятельной целью. Совпадение одного объекта не запрещает все будущие истории о нём. Root, каталог, карта и skills analytics/history/Extra High ссылаются на одного владельца. Прежняя запись исследования сохранена с явным исправлением рекомендации.

## Сохранённый завершённый ответ консультанта

Причина подтверждается. Это сбой маршрутизации контекста (context discovery), а не трендового исследования.

Координатор выполнил формальные требования для общего поиска тем, но не проверил занятые сюжеты. Bootstrap требует registry/current context для конкретного выпуска, однако не устанавливает обязательный preflight для поиска новых идей.

В результате Voyager был предложен как новая тема, хотя уже существовал согласованный Nuviko037. События различаются, но совпадают объект, ключевой конфликт и зрительский крючок — задержка связи.

Canonical owner — bootstrap. Именно он должен определять порядок обнаружения контекста до вызова аналитических или исследовательских skills. Bootstrap: единое обязательное правило preflight. Root: короткая ссылка на правило. Analytics / History / ExtraHigh: ссылки без дублирования логики. Координатор: отвечает за выполнение проверки и передачу результатов консультанту.

Предлагаемое правило: Topic Collision Preflight. Перед поиском новых тем собрать доступные episode-registry.json, CURRENT_CONTEXT и список активных проектных чатов. Сопоставить новые кандидаты с существующими выпусками по четырём признакам: событие, герой/объект, конфликт, обещание зрителю. Читать подробный контекст только потенциальных совпадений. До выдачи кандидатов повторно проверить пересечения. Занятый сюжет исключать из категории NEW. Новый угол или поддерживающий Short допускается только с явной маркировкой RELATED, отдельной зрительской целью и ссылкой на исходный выпуск. Не менять канал, формат или утверждённый сюжет без явного решения. При неполном доступе указывать COLLISION_CHECK_PARTIAL, но не блокировать независимый поиск.

Дополнение: одного совпадения объекта недостаточно для автоматического исключения. Voyager-2026 потенциально самостоятельный сюжет, но обязан пройти осознанное сравнение с Nuviko037. Критерий готовности: повторный запуск больше не выдаёт Voyager как независимую новую идею без маркировки связи с существующим выпуском.

Структурные проверки не доказывают поведение будущих сессий; новый трендовый поиск в этом аудите не выполнялся.
