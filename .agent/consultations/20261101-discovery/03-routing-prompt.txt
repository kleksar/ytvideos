# Обязательный вход в работу канала

Прочитать этот документ до процедуры любого `ytv-*` skill. Ссылка на документ сама по себе не означает его загрузку.

1. Прочитать [корневой AGENTS.md](../AGENTS.md): общие ограничения действуют на все каналы.
2. Для существующего выпуска найти **точный рабочий путь** в [реестре](episode-registry.md), перейти к указанному canonical-каталогу и прочитать локальный README/журнал, перечисленные records, текущие версии и ранее полученные разрешения. Номер, тема истории и slug не назначают канал. Перенесённый снимок состояния не является новой проверкой.
3. Прочитать нужные канальные инструкции: **Paper Detour / прежний Rarovista** → [new_channel/AGENTS.md](../new_channel/AGENTS.md); **Stories RU/EN** → раздел Stories в [stories/AGENTS.md](../stories/AGENTS.md); **Nuviko History** → раздел History там же. Не переносить ограничения другого раздела только из-за общего физического каталога.
4. Для нового выпуска или задачи о канале без выпуска брать явно заданный канал из поручения и фактических материалов, затем читать тот же канальный AGENTS. Для общепроектной технической задачи выпуск не выдумывать: достаточно root и нужной предметной документации. `UNVERIFIED` блокирует только действия, требующие знания канала; сначала установить идентичность по данным, а не по имени папки.
5. Применить только workflow текущей задачи. Если канал не соответствует узкому skill, выбрать подходящий маршрут, а не переделывать канал под skill:

## Discovery без Git

Канонические десять skills находятся только в `/Users/diplomat/ytvideos/.agents/skills`. В поддерживаемых точках входа (корень, оба канала, оба `videos`, зарегистрированные каталоги выпусков) `.agents/skills` ссылается на этот же каталог. Это ссылки, не копии навыков. Перед вычислением относительных ссылок SKILL разрешить symlink до канонического файла; свежий native `skills/list` проверяет совпадение путей и отсутствие дублей.

Эпизодные AGENTS — маленькие явные указатели на root, реестр и канальные правила. Для нового каталога после добавления записи в реестр выполнить `python3.11 .agent/scripts/install-entrypoints.py`, затем probe discovery. Самостоятельный запуск из более глубокой папки `Source/`, `Edit/` и произвольных новых каталогов этим контрактом не покрыт: использовать корень проекта либо зарегистрированный вход выпуска.

Discovery metadata не доказывает безошибочный выбор skill моделью на любом будущем запросе. Для отчёта различать фактически наблюдаемый каталог, разрешённый implicit policy, прочитанный bootstrap и отдельные e2e model traces.
