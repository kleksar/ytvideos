# Отбор темы из персональной главной YouTube

Дата: 2026-11-01. Координатор лично в Google Chrome; видимая маркировка до запроса `Extra High`.
URL: https://chatgpt.com/g/g-p-6ae147d3975481919b5bfda6935777d0-yt-video/c/6ae79ed9-c81c-83eb-ba08-507600384bb2

Узкая задача: по прямому поручению пользователя выбрать сюжет из наиболее просматриваемых карточек его видимой ленты, предварительно проверить критерии честного отбора. Контекст запроса: сохранять названия/ссылки/просмотры/возраст/длительность, не выдавать персональную выборку за весь YouTube или скорость без надёжной даты; отдельная пригодность EN narrative Paper Detour с причинной историей, цельными статичными диорамами и развязкой. Консультанту не передавалась вся персональная лента и не поручались исследование, сценарий, файлы или рекурсивный чат.

Завершённый содержательный ответ (прочитаны все6 критериев и окончание):

1. Сначала сортировать реально увиденные карточки по показанным просмотрам, отдельно сохранить возраст/длительность и время наблюдения; никаких общеплатформенных выводов.
2. Затем оценить самостоятельную историю: понятный участник, необычная ситуация, цель/конфликт, действие/последствие, изменение обстоятельств. Музыка/игра не получают приоритет только по счётчику.
3. Причинная драматургия: ситуация → действие → последствия → поворот → развязка. Набор фактов сам по себе не история.
4. Для предполагаемого короткого пилота оставить одну линию с полноценной развязкой, понятную без исходного видео. 60–90сек — рабочая гипотеза выбора, не пользовательски утверждённая длительность.
5. История должна выразиться самостоятельными бумажными композициями, без зависимости от оригинального footage или непрерывной сложной анимации.
6. Проверять ключевые события/участников/причины/развязку вне чужого пересказа; ролик — источник кандидата, не единственное доказательство и не готовая структура для копирования.

Приняты эти критерии. Предложенная консультантом оценка0–2 по5 критериям остаётся необязательным способом сравнения, не новым обязательным документом/шлюзом. Итог: одна рекомендуемая тема с источником, наблюдаемыми числами, причиной выбора и существенными ограничениями; не обещание просмотров.
