Это только предварительный шорт-лист, не финальный выбор темы и не сценарий. Не добавляй новых историй. Не включай случаи, где главный крючок держится на легенде или нерешённом споре. Для каждого из восьми дай: краткую причину включения, 2–3 главных утверждения для проверки и конкретный риск/слабое место.
