## Ответ консультанта

Вердикт: предлагаемая правка достаточна по направлению, но не хватает четырёх явных правил.

1. API capability ≠ adapter capability. Отсутствие CLI-команды или метода в upload.py не означает, что YouTube Data API не поддерживает операцию.
2. API-first для всех поддерживаемых операций, а не только для загрузки обложек.
3. Авторизация проверяется отдельно: channel ID, ownership, OAuth scopes и доступ приложения. Ошибки OAuth не являются основанием для перехода в Studio.
4. Безопасность обновлений: read-modify-write только нужных part, сохранение остальных изменяемых полей, readback после записи. При ошибке или неизвестном исходе сначала проверить состояние, не повторять операцию вслепую.

Точная граница API → UI:

> Studio разрешена только если конкретная операция объективно не поддерживается YouTube Data API либо пользователь явно выбрал ручное выполнение. Если API поддерживает операцию, но локальный адаптер её пока не реализует, это пробел реализации, а не основание переходить в браузер.

OAuth и визуальный preview допустимы как вспомогательные этапы API-процесса.

Распределение ответственности: global skill владеет политикой API-first и правилом fallback; project skill — маршрутизацией к адаптеру; README — фактическим покрытием CLI, OAuth и ограничениями. Не дублировать нормативные правила между документами.

## Проверка и принятые решения

- Предложения приняты с сохранением действующих границ поручения и согласий: API-доступ сам по себе не разрешает публикацию, новые scope или изменение чужого канала.
- CLI фактически содержит `authorize`, `upload`, `status`, `set-thumbnail`; универсальной команды изменения метаданных в нём нет. Указатели графа для upload.py устарели относительно файла; проверен актуальный исходник и вывод `--help`.
- [thumbnails.set](https://developers.google.com/youtube/data/reference/rest/v3/thumbnails/set) подтверждает PNG/JPEG, лимит 50 MB и допустимость youtube.upload; [videos.update](https://developers.google.com/youtube/data/reference/rest/v3/videos/update) — отдельные права управления и удаление пропущенных изменяемых полей выбранных parts. Проверено 2026-11-01.
- [OAuth expiration](https://developers.google.com/identity/protocols/oauth2#expiration): External/Testing с YouTube scopes выдаёт refresh token на 7 дней. Нельзя обещать бессрочную работу сохранённой авторизации.
- Правильный токен Paper Detour существует с mode 0600; его содержимое не выводилось. Проверки канала при прошлой записи — исторические квитанции, перед следующей записью требуются актуальные чтения.
- Изменяется текущая процедура у её владельцев, а не отдельный параллельный upload skill. Формат/crop/читаемость остаются у packaging skill. Этот разбор не является обязательным входом каждого выпуска.
