## Coordinator's independent source check

Checked the v02 claims against Robert C. Allen, “The Great Divergence in European Wages and Prices from the Middle Ages to the First World War” (2001), [primary article PDF](https://web.mit.edu/14.731/papers/greatdivergence.pdf).

- **C1 — nominal wages:** Table 2, p. 415, gives London building-laborer daily silver wages of 3.2 g in 1500–1549 and 7.1 g in 1600–1649.
- **C2 — consumer prices:** Table 4, p. 425, gives London's relative CPI values of 0.45 and 1.25; the stated base is Strasbourg, 1745–1754 = 1.00.
- **C3 — welfare ratios:** Table 6, pp. 427–428, gives London's building-laborer ratios of 1.42, 1.16, and 2.15 for the periods stated in the script.
- **C4 — bounded comparison:** 7.1 / 3.2 ≈ 2.22; 1.25 / 0.45 ≈ 2.78. In this comparison, the CPI rose proportionally faster than the daily silver wage, while the welfare ratio declined from 1.42 to 1.16.
- **C5 — longer context:** p. 429 supports the approximate pre-Black-Death value of 0.75 and says fifteenth-century laborer earnings were generally high enough to move above the poverty line. The script does not assign an exact fifteenth-century value or claim every household crossed it.
- **C6 — method and limits:** pp. 424–426 define the welfare ratio, use assumed annual earnings based on 250 days, a notional four-person family, and a 5% minimum rent markup. Allen explicitly calls the calculation notional. The script distinguishes wage-day equivalents from actual work schedules and household accounts.
- **C7 — basket:** Table 3, pp. 420–421, supports the listed categories; Allen notes regional substitutions. The script presents it as a reconstructed benchmark rather than one family's shopping list.
- **C8 — derived values, not source facts:** 250 / 0.75 = 333.3; 250 / 1.42 = 176.1; 250 / 1.16 = 215.5; 250 / 2.15 = 116.3. Rounded values ~333, ~176, ~216, and ~116 are accurate if described as model-implied days' worth of wages, not days actually worked. The script keeps that caveat audible.
