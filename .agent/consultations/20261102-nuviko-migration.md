## Проверенные официальные входы для самостоятельного плана

- https://support.google.com/youtube/answer/2404846?hl=en — каналы нельзя объединить с переносом данных; перезагрузка создаёт новые метрики.
- https://support.google.com/youtube/answer/9481328?hl=en — приглашённые через channel permissions пользователи не получают доступ к YouTube APIs.
- https://support.google.com/youtube/answer/1311392?hl=en — оригинальность, повторяющийся/массовый и reused content, оценка канала в целом.
- https://support.google.com/youtube/answer/14328491?hl=en — декларация реалистичного AI-контента; сама декларация не отменяет eligibility монетизации.
- https://support.google.com/youtube/answer/2657964?hl=en — изменение имени/handle через Studio.
- https://developers.google.com/youtube/data/reference/rest/v3/channels/update?hl=en — API не разрешает заменить основное название через brandingSettings.channel.title.
- https://developers.google.com/youtube/data/reference/rest/v3/videos/insert?apix=true — загрузка и поле status.containsSyntheticMedia.

На первом этапе публичные страницы обоих каналов через веб-инструмент не прочитались из-за throttling. Тогда число видео, подписчиков, показатели аудитории, доходы и внешнее оформление не были проверены. API и Studio не изменялись; рендеры и аудиогенерация не запускались.
