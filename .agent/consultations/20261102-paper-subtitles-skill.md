# Paper subtitles: разделение навыков

Дата: 2026-11-02. Личная консультация координатора в Chrome; непосредственно перед запросом видимая маркировка `Очень высокий`. [Проектный чат](https://chatgpt.com/g/g-p-6ae147d3975481919b5bfda6935777d0-yt-video/c/6ae7efbd-75a4-83ed-ae0c-d762127296eb).

Задача: разделить отдельный Paper skill экранных субтитров, существующий ytv-srt для буквального текста/timing/sidecar и ytv-paper-captions для PNG-акцентов; учесть одобренную пользователем нижнюю строку длинного видео и не выдумывать стиль Shorts. Консультанту прямо указано отвечать в открытом чате без рекурсивной консультации.

Видимый завершённый ответ: рекомендован `ytv-paper-subtitles` как владелец Paper-политики показа; `ytv-srt` — текст речи, SRT и conform; `ytv-paper-captions` — смысловые PNG; production — маршрутизация. Для длинного формата перечислены одна нижняя строка до четырёх слов, обычный регистр, смысловая пунктуация, цвет текущего слова, смысловая разбивка и защита лиц/объектов/акцентов. Для Shorts рекомендовано не наследовать стиль длинного формата и не изобретать неподтверждённые правила. Ответ — рекомендация, не пользовательское утверждение нового оформления Shorts.

Принято: отдельный канальный skill владеет видимой строкой; общий SRT и смысловые акценты остаются у действующих владельцев. Сохраняется принятое пользователем оформление образца 032 и отдельный статус проверки слышимого sync. Ограничение: формат Shorts оставлен на ранее согласованной постановке конкретного выпуска, новый общий стиль не установлен.
