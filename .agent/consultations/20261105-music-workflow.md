## Полный ответ, восстановлен кнопкой «Загрузить ответ заново»

Надёжная схема — машинная проверка комплектности и целостности + человеческое подтверждение музыкального содержания и качества. Не пытаться заменить одно другим.

### 1. Обязательные доказательства
Для каждой версии видео формировать единый audio manifest.

| Поле | Что фиксируется |
|---|---|
| music_policy | required или approved_exception |
| exception_reason | Обоснование отсутствия музыки |
| approved_by | Кто утвердил исключение |
| mix_file | Путь к готовому аудиомиксу |
| mix_sha256 | Контрольная сумма микса |
| timeline_revision | Версия монтажа, для которой подготовлен микс |
| music_sources | ID композиций и использованных версий |
| music_cues | Временные интервалы использования музыки |
| rights_reference | Ссылка на подтверждение разрешённого использования |
| editor_attestation | Подтверждение проверки музыкального содержания и прослушивания |

Для исключения approved_exception обязательны причина, ответственный и привязка к конкретной версии фильма.

### 2. Что должна проверять автоматика
Автоматизировать:
- По умолчанию музыка обязательна.
- Отсутствие микса блокирует рендер, если нет утверждённого исключения.
- Проверять существование файла, SHA-256 и соответствие версии монтажа.
- Проверять технические параметры аудио: длительность, формат, каналы, корректность декодирования.
- Проверять наличие аудиодорожки в итоговом MP4.
- Проверять соответствие встроенного аудио переданному миксу с учётом особенностей кодирования.
- Проверять технические аномалии: обрезание, неожиданные провалы сигнала, клиппинг.
- Сохранять результаты проверок и идентификаторы использованных артефактов.

### 3. Что нельзя поручать автоматике
Только человеческая оценка:
- Действительно ли в миксе присутствует музыка, а не только речь.
- Достаточно ли она слышна на фоне диктора.
- Подходит ли композиция эмоционально конкретной сцене.
- Нет ли неприятного дисбаланса, мешающего восприятию.
- Художественно ли музыка развивается вместе с историей.

Наличие ненулевого аудиосигнала не доказывает наличие музыки. Метаданные и чекбоксы также не доказывают её слышимость.

### 4. Критерий приёмки
Предлагаю три независимых статуса:
1. Policy PASS — музыка обязательна либо имеется утверждённое исключение.
2. Artifact PASS — микс существует, соответствует версии, передан рендереру и присутствует в результате.
3. Editorial PASS — редактор подтвердил музыкальное содержание и качество прослушиванием.

Итоговый выпуск разрешён только при прохождении всех трёх проверок.

Важный принцип: исключение без музыки — полноценное документированное решение, а не обход проверки. Готовый микс — конкретный неизменяемый артефакт, а не обещание редактора его предоставить.

SFX в эту систему включать не нужно. Музыка и звуковые эффекты остаются разными категориями с разными правилами приёмки.
