Use evidence-based metadata and explicitly provisional editorial recommendations. Never turn a composer's description into an implied listening review.

Recommended approach:
1. Separate facts from interpretation: Source evidence: Composer's exact description, tags, licensing statement, recording/version. Editorial interpretation: Possible narrative functions inferred from that description. Audio assessment: Only completed after someone actually listens.
2. Describe story functions, not unverified sound characteristics. Useful suggestions: Potential background for historical exposition; candidate for building narrative tension; possible reflective aftermath or resolution; candidate for transitions between contrasting story beats; possible restrained bed beneath emotionally significant narration. Avoid unsupported claims about tempo, instrumentation, dynamics, emotional intensity, crescendos or endings.
3. Use explicit review statuses: Metadata reviewed — description and source checked; Rights verified — license independently checked; Audio reviewed — exact recording actually auditioned; Narration tested — voice clarity and mix compatibility checked; Production approved — suitable for the intended use.
4. Preserve uncertainty in recommendations. Example: Potential fit: reflective aftermath or restrained transition. Suggested from the composer's written description only. Musical development, dynamics and compatibility with narration remain unverified.
5. Require listening before assignment. Before production, verify the exact recording, alternate version, duration, transitions, dynamic range, voice masking and licensing.

Core rule: Metadata can suggest where to try a track. Only listening and production testing can establish whether it actually works there.

Decision: Preserve user approval as reported, distinguish it from coordinator listening and mix review, and label story roles as suggestions based on authors' descriptions.
