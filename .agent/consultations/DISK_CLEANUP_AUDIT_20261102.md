# Консультация по представлению кандидатов очистки

- Дата: 2026-11-02. Google Chrome, видимая маркировка перед запросом: `Extra High`.
- Чат: https://chatgpt.com/g/g-p-6ae147d3975481919b5bfda6935777d0-yt-video/c/6ae8250a-71b8-83eb-9b39-ac9920dd4f4b
- Запрос: какие данные показать пользователю для решения об удалении крупных файлов видеопроекта с учётом исходников, монтажных зависимостей, законченных рендеров, активных сессий и APFS-клонов?
- Завершённый ответ: показать состав и размеры, связи с проектами и возможность восстановления, статус текущего использования, а также ограничения оценки физического места. Приоритет по реально освобождаемому месту возможен только при наличии достоверной оценки; иначе показывать размеры как ориентир, не обещать освобождение.
- Применение: составлен первичный список групп для выбора пользователем. Наличие размера и расширения не подтверждает ненужность файла. Никаких удалений не выполнено.
