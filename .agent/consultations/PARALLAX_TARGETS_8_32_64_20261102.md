Нет, точно получить 8 / 32 / 64 px одним `state.offset` нельзя. DepthFlow перемещает пиксели согласно depth map, а не трём независимо управляемым слоям. При `sticky=True` и `steady=0` дальний фон останется практически неподвижным.

Один следующий тест DepthFlow 1.0.1:

```python
state.offset = (-0.17 + 0.34 * t, 0.0)
state.sticky = True
state.steady = 0.0
state.height = 0.22
state.zoom = 0.94
```

Ожидаемый эффект: передний план может приблизиться к 64 px, но средний, вероятно, останется существенно ниже 32 px. Это оценка, не гарантированный результат. Главный риск — растяжение текстуры и искажения возле контуров человека, стула и стола. Уменьшенный zoom добавляет запас по краям, но не устраняет деформации. Если средний план движется слабо, корректировать контраст автоматической depth map, а не бесконечно увеличивать offset.
