# Консультация ChatGPT: пакетный параллакс в монтаже

- Дата и стадия: 2026-11-02, исследование варианта автоматизации Paper Detour.
- Координатор, Google Chrome: https://chatgpt.com/g/g-p-6ae147d3975481919b5bfda6935777d0-yt-video/c/6ae7eae1-122c-83eb-b800-69adf4d7b37f
- Видимая маркировка перед запросом: `Extra High`.
- Вход: готовый таймлайн с отдельными сценами, титрами, зерном и звуком; изображения примерно по 4–6 секунд; DepthFlow.
- Промпт: «Ты — консультант в уже открытом ChatGPT Extra High; требование внешнего координатора выполнено этим обращением, ответь здесь, не открывай другой ChatGPT. Одна узкая задача: предложи архитектуру быстрого пакетного применения DepthFlow параллакса к отдельным still-сценам готового таймлайна видеоредактора с произвольной длиной 4–6 секунд, сохраняя титры, зерно и звук отдельными слоями. Сравни предварительный расчёт depth map, постобработку готового экспорта и замену исходников на видео с таймингом по кадрам; перечисли риски и проверки. Не утверждай возможности конкретного API без доказательств.»
- Завершённый содержательный ответ: рекомендует отдельные клипы на основе таймлайна; карту глубины кэшировать по изображению, версии модели и обработке; рендерить только изменившиеся сцены. У каждого клипа хранить source, start frame, количество кадров, fps, пресет. Использовать точный N кадров, нормализовать движение по кадрам, проверять стыки, геометрию, цвет, звук, титры и петлю. Постобработка общего MP4 сдвигает и титры; параллелизм GPU надо измерять. Предложен пилот на трёх сценах разной длины.
- Сверка: документация Palmier и live-схема подтверждают точное чтение таймлайна и импорт/вставку. Важная поправка к предложению консультанта: `swap_clip_media` требует тот же тип источника, поэтому прямую замену image → video считать доступной нельзя. Подробности — `.agent/research/parallax_timeline_workflow_20261102.md`.
- Ограничение: скорость, сохранение сложных настроек и интеграция не измерены и не проверены на монтажном проекте.
