Упростить можно через **один обязательный cleanup-gate**, связанный только с публикацией и целостностью архива.

- После подтверждённой публикации проверить только: финальный MP4 существует и читается, URL/ID публикации сохранён, нужные script/SRT/metadata сохранены.
- Затем сразу удалять project-local расходники: промежуточные рендеры, временные кадры, proxies, caches, старые версии финала.
- Не блокировать cleanup проверками обложек, аналитики, описания, A/B-тестов и другими задачами, если они не используют удаляемые файлы.
- Общие ресурсы хранить вне каталога эпизода и никогда не включать в project cleanup: музыка, border assets, шаблоны, reusable overlays/fonts.
- Оставлять минимальное свидетельство: final hash/размер, publication ID/URL, timestamp cleanup и список удалённых классов файлов.

Критерий простой: **если файл не нужен для воспроизведения опубликованного результата, повторного редактирования из сохранённых исходников или аудита факта публикации — после gate он не должен оставаться.**

Решение: использовать разделение несвязанных проверок и расходных файлов; не подменять им фактическую идентичность загрузки, требования к расписанию/A/B-пакету, защиты других выпусков и правила среды по удалению. Сохранение MP4 или исходников по умолчанию после принятого полного архивирования не требуется.
