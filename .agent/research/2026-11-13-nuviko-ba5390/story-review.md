## Three story maps and substantive contrast

**02m (baseline Short retained)**: captain outside → attendant grasps waist → turbulent airflow blocks retrieval → relieved attendant grips ankles → Southampton landing → survivor and wrong bolt types → causal return to first image. Strong compressed recovery and intact cold opening. Weakness: ends on a colon; an independent first listener may hear the loop as a trailer rather than a complete bridge. Root storyboarding 17 scenes belongs only to unchanged root/02m exact text, subject to SHA match before use.

**05m (new)**: opening questions (land / rescue / bolts) → Birmingham–Málaga and roles → windscreen/decompression as main hook → Ogden grabs captain → co-pilot must regain flight controls while crew cannot retract Lancaster → handoff between attendants → Southampton landing and injuries → 84+6 bolt finding and single-person certification → safe-flight checks payoff. Added value beyond 02m: causal relationship between flight and hands-on cabin work, meaningful aviation context, inspection chain. Weakness: mid-air details between handoff and landing could slow without concrete visuals.

**10m (new)**: questions → two converging timelines → ordinary flight → window ejection → first restraint → loss of autopilot/comms → handoff and trapped legs → controlled diversion/landing → recovery and injuries → evidence at crash site → night-shift replacement → inherited wrong bolt sample → second dark storeroom → physical fit/missed cues → missing independent check → systemic lesson. Added value beyond 05m: verified reasons that wrong parts *seemed* usable, so audience learns system failure rather than one wrong-sized screw. Weakness: after captain's survival, second maintenance act is less urgent; if viewers only want rescue, interest likely falls at 'The next question was mechanical.'

Recommendation (author): **05m Long**, conditional independent listener and measured runtime. It includes the rescue and the maintenance mechanism while avoiding 10m's long post-landing diagnosis. 02m is valid alternative if concise survival pacing wins a blind listener test. 10m documentary depth is not automatically better. Recommendation ≠ owner choice, script approval or permission for any production.
