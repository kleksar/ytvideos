# McDonald's Monopoly — кто выбирал победителей?

**Logline:** ФБР снимает победителя с миллионным чеком, чтобы выяснить, как редкие фишки попадали к выбранным людям ещё до распределения; затем суд выясняет, было ли доказано участие отдельных получателей в едином сговоре.
