# Nuviko History · The Oceanos Rescue (4 August 1991)

**RU логлайн:** шторм выводит круизный лайнер из строя. Пока часть офицеров и команды уже покинула его, артисты помогают эвакуировать пассажиров. Гитарист выходит на радиосвязь с пустого мостика, затем водолазы и вертолёты снимают оставшихся людей. Лайнер тонет примерно через 45 минут после окончания спасения; **никто не погиб**. Не изображать гитариста единственным спасателем и не выдавать спор о капитане за установленный мотив.
