# Nuviko History · Vajont 1963: the safety test was too slow

**Логлайн.** В 1963 году гора Ток сползла в водохранилище Вайонт. Бетонная плотина выстояла, но волна перескочила через неё и уничтожила Лонгароне. Ранние испытания предполагали минуты движения оползня; в действительности всё произошло за секунды. Главная интрига: почему правильная прочность стены не защитила людей ниже?
