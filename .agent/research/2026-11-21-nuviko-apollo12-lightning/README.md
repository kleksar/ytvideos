# Nuviko History — Apollo 12: The Rocket Kept Flying

**Логлайн:** Через 36,5 секунды после запуска «Аполлона-12» молния отключила все три топливных элемента корабля. В Хьюстоне перестали поступать нормальные показания, но «Сатурн-5» продолжал лететь на собственной системе наведения. Диспетчер Джон Аарон вспомнил редкий режим прибора, Алан Бин включил его, и команда смогла по показаниям восстановить электропитание. Позже астронавты достигли Луны, а NASA выяснило, что ракета сама спровоцировала разряды.

**Почему пять минут:** на странице одни и те же реальные люди проходят через отдельные шаги, а не три пересказа известного переключателя: ракета продолжает полёт, датчики не дают данных, Аарон узнаёт ошибку, Бин включает AUX, в Хьюстоне снова видят приборы, топливные элементы подключают отдельно, и экипаж проверяет корабль на орбите. Двухминутный вариант даёт полную короткую историю; десятиминутный теперь показывает восстановление навигации по звёздам, проверку потерь датчиков, стыковку с лунным модулем и его осмотр; несмотря на это, 05m раньше даёт основной ответ.
