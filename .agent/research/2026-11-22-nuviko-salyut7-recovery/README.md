# Nuviko History — They Docked With a Dead Space Station. That Was the Easy Part.

**RU логлайн:** в 1985 году два космонавта вручную состыковались с молчащим, вращающимся «Салютом-7». Стыковка оказалась только первым испытанием: внутри был иней, аккумуляторы разрядились, солнечные панели не могли повернуться без питания. Экипаж использовал свой «Союз», чтобы вернуть станции свет, а затем должен был безопасно справиться с оттаиванием.
