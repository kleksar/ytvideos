# Paper Detour — Atari's landfill was not just E.T.

**Логлайн.** В 2014 году экскаватор нашёл печально известную E.T. на свалке Нью-Мексико, но вместе с ней появились успешные игры Atari. Находка подтверждает само захоронение и одновременно разрушает удобную легенду, будто одна игра погубила всю индустрию. Неофициальный редакционный кандидат, **не** зарегистрированный `ytv` run и не одобренный script gate.
