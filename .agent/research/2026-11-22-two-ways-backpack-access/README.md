# Two Ways Lab — The neat backpack lost, until it rained again

**RU логлайн:** я сравниваю порядок восьми вещей в одном рюкзаке. A — по категориям, B — по порядку запланированного использования. После четырёх обращений B выигрывает по числу помех (A 9, B 6). Два дополнительных обращения к зонту меняют победителя (A 9, B 12). Это **авторская расчётная модель**, а не эксперимент с настоящим рюкзаком и не измерение времени.
