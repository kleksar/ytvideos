# Nuviko History — USS Franklin: They Were Still Towing the Fire

**RU логлайн:** две японские бомбы вызвали взрывы собственных боеприпасов на полностью заправленном авианосце «Франклин». Сотни людей оказались в ловушке; другие корабли эвакуировали моряков и буксировали горящий авианосец, пока механики не вернули ему ход. У спасения была высокая человеческая цена.
