# Knight Capital: The Fix That Spread a $460 Million Trading Glitch

В 2012 году Knight Capital пропустила один сервер при обновлении торговой системы; попытка отката на семи исправных серверах усугубила сбой. Более четырёх миллионов сделок по 212 клиентским поручениям привели к убытку свыше $460 млн и срочному привлечению $400 млн.
