# Nuviko History — The last natural smallpox patient

В 1977 году повар больницы в Сомали показал дорогу машине с двумя больными оспой детьми. Его пропустили при отслеживании контактов, затем дважды ошиблись с диагнозом. Он выздоровел, а новые случаи от него не обнаружили. Последний известный естественный больной позднее сам убеждал родителей прививать детей от полиомиелита.
