# Голоса каналов

Канонические машинные назначения хранятся в [`channel_voices.json`](../../../../automation/elevenlabs/channel_voices.json): Paper Detour — Lawrence `ktkP7Nsj67dw2zcplQYt`; Nuviko History — `5vsgZsi667xMyGinrNIM`. Имя второго голоса не подтверждено. Это два разных единственных голоса каналов для любой новой озвучки; имя канала определяется по реестру выпуска, не по папке или slug. Заморозка Nuviko остаётся в силе.

Перед генерацией установить канал по материалам выпуска, использовать `tts.py --channel paper_detour` либо `--channel nuviko_history`, проверить ID и доступность в выбранном аккаунте. Без установленного канала или при несовпадении ID остановиться до платного запроса. Не заменять голос на похожий и не переносить default из старых Stories; при смене аккаунта подтверждать тот же ID. Прямые вызовы API и другие генераторы обязаны соблюдать тот же контракт. Для действующих старых записей сохранять реальный voice ID по доказательствам, при отсутствии доказательства — UNKNOWN; не приписывать им голос из текущего реестра. Новую озвучку, включая замену старой, создавать только в рамках имеющегося разрешения. Исторические данные не переписывать.

`voice_run.py` также требует явный `--channel`; его журнал и прямой helper фиксируют запрошенный ID. Это защита маршрутов проекта, не проверка на слух и не гарантия поведения внешних инструментов.
