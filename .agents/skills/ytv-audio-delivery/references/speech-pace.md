# Измерение темпа готовой речи

Audio владеет измерениями и доказательствами параметров; [visual-direction](../../ytv-visual-direction/SKILL.md#речь-и-длительность) применяет их к сценам. Измерение существующих записей не запускает новую озвучку. Сводку выбранного профиля и ссылку на данные хранить в разделе «Время» EPISODE.

Выбирать несколько разных завершённых выпусков по принятым версиям, а не несколько дублей одного сюжета. Проверять цепочку принятого edit → точное аудио → карта слов/транскрипт. Для каждого примера записать канал, язык, формат, voice ID, модель, скорость и место её применения, версии/hash источников, способ подсчёта, границы речи и ограничения проверки. Текущий реестр голоса не доказывает параметры старой записи. Неизвестные параметры оставить UNKNOWN; такие примеры не включать в профиль с известными параметрами.

Эффективный темп: `R = 60 × N / (t_last_end − t_first_start)`. Интервал включает внутренние паузы; ведущая и конечная тишина, отдельная заставка в него не входят. Проверять, что метки относятся к уже окончательно ускоренному аудио. Если есть только длина полного файла, назвать метрику отдельно и не смешивать её с интервалом речи. Сумма длительностей отдельных слов без пауз для бюджета ролика не подходит.

Подсчёт должен быть воспроизводимым и одинаковым для базы и нового текста. Предпочтительна произносимая форма чисел/сокращений. Архивный alignment может хранить «1916» одним токеном: такой результат обозначать как темп по текстовым токенам, сохранять правило и числовые токены, не выдавать его за точный подсчёт произнесённых слов. При иной нормализации пересчитать базу; не смешивать счётчики. Отдельные знаки пунктуации не считать словами.

Группировать по каналу, языку, голосу/модели, формату и фактическому способу применения скорости. TTS speed и последующее atempo хранить раздельно: одинаковая цифра не доказывает одинаковый результат. Для каждой группы показывать размер выборки, медиану и наблюдаемый min–max, существенные отличия и неизвестное. Один пример — одиночный ориентир, два — предварительная выборка. Наблюдаемый диапазон не является доверительным интервалом или гарантией для следующей записи. Не объявлять универсальную скорость канала по смешанным форматам.

Для планирования использовать `T = 60 × N / R`, диапазон образцов `60N/Rmax … 60N/Rmin`; отдельную тишину добавлять лишь если её нет в измеренном интервале. Уже учтённые скорость и паузы повторно не применять. Не переносить английский темп на русский исходник; сначала использовать точную производственную языковую версию. Когда подходящего профиля нет, фиксировать оценочное допущение и его пределы, не создавать звук без разрешения.

После записи точные сцены привязать к проверенной карте слов этой версии через visual-direction. Средняя скорость не назначает склейки и не подтверждает синхрон. Машинный alignment, принятие фильма пользователем и независимое прослушивание — разные свидетельства. Сохранять исходные статусы и честно указывать, что нового прослушивания не было.
