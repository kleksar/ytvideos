# Проверка исторических фактов

Прочитать [bootstrap](../../../.agent/CHANNEL_BOOTSTRAP.md), root, канал и текущую запись выпуска, если он зарегистрирован. Маршрутизация Paper по умолчанию и заморозка Nuviko History — [root §2](../../../AGENTS.md#2-bootstrap-и-канал).

Применять к исторической основе выбранной темы или порученной проверке конкретных утверждений. Уточнить вопрос и, для проверки текста, зафиксировать его точную версию. Получить содержание источников, установить хронологию и сопоставить существенные версии событий. Различать современное событию свидетельство, поздний пересказ, реконструкцию и неизвестное. Проверять числа, цитаты и заявленные причины по источникам. Порученное исследование и консультации выполнять по root §1; применять требования канала к историческим утверждениям.

Выдать проверенную хронологию либо таблицу утверждений с точными ссылками и местами в источниках. Отдельно указать расхождения, неизвестное и пределы подтверждения, которые меняют смысл истории. Сохранить результат в материалах выпуска. Зафиксировать фактического проверяющего и отделить независимый фактчек от повторного прохода автора. Для узкой проверки на этом остановиться.

При разработке истории передать проверенную основу в [ytv-storycraft](../ytv-storycraft/SKILL.md). Для поиска тем использовать [ytv-topic-research](../ytv-topic-research/SKILL.md); для эпохи, предметов и внешности в кадре — [исторические визуальные референсы](../ytv-scene-images/references/historical-visual-references.md). Принятый сюжет и готовый сценарий сохраняются по [входу в производство](../ytv-video-production/SKILL.md#вход-и-полномочия); проверять их повторно только по прямому поручению.
