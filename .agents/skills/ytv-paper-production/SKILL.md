# Paper Detour production

Для фильма/Short использовать [единое производство](../ytv-video-production/SKILL.md) и его flow. При разработке нового сюжета или порученной редактуре сначала применять [сценарную процедуру Paper](references/story-development.md), которая направляет к общему процессу сюжета; принятый сценарий сохранять по общему flow. Канальные настройки — [Paper AGENTS](../../../channels/paper_detour/AGENTS.md), сценовый стиль — [Paper profile](../ytv-scene-images/references/paper-detour.md).

Для самостоятельной карусели использовать [Posts Playbook](../../../channels/paper_detour/docs/YOUTUBE_POSTS_PLAYBOOK.md): упорядоченные изображения и текст поста. Формат задаётся поручением.
