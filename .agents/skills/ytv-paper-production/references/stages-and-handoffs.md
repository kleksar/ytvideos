# Состояния и передачи

Общий владелец: [единый flow](../../ytv-video-production/SKILL.md#очистка-и-завершение). G-номера старых журналов сохраняют исторический смысл; текущий процесс использует общую нумерацию этапов.

Передача фиксирует задачу, точные версии/пути/hashes, project/timeline/revision, writer, результат и реальную проверку/принятие. Пользовательская контрольная точка — экспортированный MP4 на этапе 16 и показанная упаковка. После одобрения — загрузка принятого файла и оформленный Unlisted.

Для разрешённого делегирования назначать непересекающийся scope: «Ты не один в проекте; сохраняй изменения других исполнителей». Право spawning — по root/runtime. Автор и независимый reviewer фиксируются фактически.
