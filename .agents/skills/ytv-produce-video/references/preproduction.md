# Подготовить и использовать текстовый пакет


Для порученного сюжетного MR до медиа подготовить [preproduction.json](../../../../docs/operations/preproduction-contract.md) выбранного варианта; это текстовая подготовка, не выполнение production tasks без approval.

1. Завершить факты, полный рассказ, устную редактуру и применимый review. Сохранить exact EN/RU/hash и честный статус независимой проверки. Слабый замысел не спасать количеством prompts. Для разрешённого editorial-кандидата без runtime/reviewer сохранить его метку и ограничения; не выдумывать run/receipts.
2. Получить и полностью прочитать канальные instructions для `storyboard`, `audio`, `packaging` с нужным форматом. Разработать самостоятельные композиции, опоры/листы, полные независимые prompts, continuity, движение, звук, монтаж и упаковку по контракту. Покрыть точный текст, проверить приблизительную плотность; не переносить на локального агента выбор сюжета/камеры/реквизита. Параметры реального файла и окончательные тайминги оставить для фактического измерения.
3. Выполнить structural validator, затем отдельно проверить содержание, визуальную функцию, соответствие EN/RU и все открытые входы. В README показать комплектность и ссылку на точный пакет. Не генерировать медиа и не запрашивать платные jobs в сюжетном MR.
4. На локальном host для принятого пакета прочитать `task_guide.preproduction.artifact` через `artifact_root` с проверкой hash. **Повторно не сочинять готовые prompts/раскадровку:** получить подготовленные references, проверить actual bytes, связать asset IDs с настоящими artifacts; использовать сцены и briefs пакета в обычных production tasks. Source не заменяет проверки/receipt/claim. Старый пакет с `stale_baseline` не применять к изменённому master.
5. После генерации исправлять конкретное расхождение, сохраняя исходный prompt и точные новые versions/hashes. Привязать планы к реальной записи. Для Flow сверить черновик движения с осмотренным кадром и согласовать точную партию; не выдавать предварительный prompt за наблюдение. QA/approval MP4 и release scope сохраняются.
