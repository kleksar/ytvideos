# Проверка речевых стыков

Требование принадлежит [audio standard](../../../../docs/standards/audio.md#естественная-пауза-на-стыке-речи).

1. Получить exact исходную дикторскую дорожку до padding, gate, музыки/SFX и её hash. Не анализировать финальный микс как речевую тишину. Подготовить signed PCM WAV без изменения тайминга.
2. Для каждого фактического речевого монтажа подготовить JSON-массив объектов с `id`, `left_word_end`, `right_word_start`, `cut` в секундах на этой дорожке. Проверить границы слов по исходнику, а не доверять приблизительному SRT.
3. Выбрать и записать порог dBFS по измеренному шумовому полу и тихим окончаниям. Запустить `python automation/helpers/speech_seams.py voice.wav boundaries.json --threshold-dbfs -50 > seams.json`; -50 здесь пример, не универсальный порог. По умолчанию диагностика использует ориентир 100 мс; для обоснованного темпом/смыслом исключения указать `--minimum-ms N --timing-reason 'причина'` и сохранить решение по конкретным стыкам. Это не автоматическое одобрение исключения. Скрипт читает PCM, ищет непрерывный тихий интервал вокруг cut внутри проверенного межсловного интервала, учитывает максимум каналов и не меняет аудио.
4. `REVIEW` / exit 2 требует разбор исходника, не автоматический ремонт. `MEASURED_CANDIDATE` / exit 0 подтверждает только измеренный запас: доказать, что пауза естественная, проверить согласные/вдохи и прослушать обе стороны в финальном миксе. Не утверждать проверку слухом, если она не выполнена.
5. Сохранить report с exact hash, исходными границами, выбранными порогом и длительностью, причиной исключения и результатом прослушивания. После ремонта повторить на изменённой дорожке и проверить итоговый MP4. Не нормализовать/приглушать всю сцену без установленной причины скачка.
