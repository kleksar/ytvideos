# Редактируемая сборка

1. Прочитать [visual](../../../../docs/standards/visual.md), [audio](../../../../docs/standards/audio.md), [delivery](../../../../docs/standards/delivery.md) и профиль. Снять native read-back версии, текущего project/timeline, geometry/fps, media availability. Не менять активный чужой проект. Сохранить исходное состояние и собственные IDs; сериализовать создание/import/settings/save/render mutations. Не полагаться на неизвестные методы: проверить локальный официальный scripting API соответствующей версии.
2. Подготовить точный frame manifest с источниками, in/out, длительностями, слоями, параметрами движения и audio cues. Установить timeline fps/геометрию **до импорта**; проверенные форматы — 1920×1080/30 и 1080×1920/30. Это не отменяет более высокого/другого разрешения закреплённого профиля: его проверить отдельно, не понижать до тестового пресета. Сохранить фактический timeline read-back, а не только запрошенное SetSetting.
3. Импортировать source assets и edit timeline штатным native API. Для numbered PNG Resolve может ошибочно распознать sequence. При наблюдаемом Media Offline/ошибке длины подготовить uniquely named exact-length ProRes MOV carriers (4444 для alpha); сверить первый/последний кадр, fps, длительность и alpha, затем импортировать. Не выдавать это за обязательную конверсию любого PNG; исходники сохранить. Carrier не должен запекать монтажную камеру, которую требуется редактировать.
4. Сохранить отдельные picture cuts, object/alpha overlays, narration, music и **один клип на каждый авторский SFX cue**. Для одновременных эффектов выделить необходимые неперекрывающиеся lanes, не фиксированное число дорожек. Проверить trim/position/gain/fades/ducking по фактической слышимости, clips/channel map и sync. Старый baked master допустим лишь как явно подписанный legacy underlay: из него не возникают отдельные editable voice/music/SFX; отсутствие stems записать, не обещать полную раздельную правку.
5. Монтажная камера: static — полноценный выбор; где движение выбрано, native keyframes/эквивалентная проверенная editable конструкция линейны от первого до последнего отображённого кадра без ease/edge holds. Проверить interpolation фактически, не по имени preset. Применять актуальные правила общего visual/channel без ослабления: обычный zoom не более примерно ±5% от исходного скомпонованного framing, более строгий cap имеет приоритет; выбранные zoom в соседних движущихся планах чередуются. Проверять реальный видимый crop относительно fit, не одни Inspector numbers. Статику предпочитать при быстрых склейках без смысловой причины движения; pan в каждом из четырёх направлений выбирать по задаче reveal/action/travel, не ради квоты. Сохранить safe crop; направление artwork противоположно перемещению camera. Событийная анимация предмета имеет свой смысловой старт, не обязана двигаться весь кадр. Первый/средний/последний кадры и непрерывные соседние склейки проверять на clipping, скачки и повтор псевдо-нового плана.
6. Субтитры: канальные single-line/word highlight/safe area сохраняются. Можно импортировать проверенный alpha karaoke слой; он baked относительно текста/тайминга, не нативно редактируемая subtitle track. Сохранить word map, cue map, source текста и способ пересборки. **SRT в Media Pool или sidecar не означает применённую subtitle track.** Для новых речевых выпусков импортировать финальный EN SRT (иной язык — только по явному языковому поручению) на отдельную **native editable subtitle track**, не только в Media Pool. Учитывать export origin/timeline offset; сверить текст, cue count, первый/последний cue и sync после всех trims. Проверить, что cues действительно доступны для редактирования, и повторно экспортировать отдельный timed SRT; прочитать его обратно и сравнить текст/таймкоды с финальным монтажом. Для `no_speech` не создавать фиктивную речь. Native CC track хранить отдельно от burned/alpha captions: явно выбрать видимость при render, чтобы оба слоя не отображались одновременно. Не считать импорт файла проверкой native-track применения. Для History-подобного hold сохранять текущую фразу до следующей, neutral highlight в паузах, только если это правило применимо каналу.
7. SaveProject и повторный read-back: project/timeline IDs, frame count, cut/track/item counts, offline state, endpoints, source hashes, editable vs baked components. При поручении «только проект» закончить здесь, не запускать export. Для export перейти к delivery reference.

## Главы длинного видео

Для применимого Long поставить **timeline markers**, не clip markers, по окончательному монтажу. Выбрать и записать один chapter color, названия и позиции; QA/служебные markers других цветов в главы не включать. Пересчитать относительно начала экспортируемого диапазона, после trim/intro снова сверить. Сохранить рядом с проектом список timestamp + title и read-back marker type/color/position. Для Short chapter toggle остаётся выключенным. Публикация глав и selectable CC — по [delivery](delivery.md), а не по одному наличию track/markers в проекте.
