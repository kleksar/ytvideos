### S001

| Поле | Решение |
|---|---|
| Речь | narration revision / язык; от N-ID + слова + вхождение до N-ID + слова + вхождение; либо NO_SPEECH |
| Время | ESTIMATED или ALIGNED; интервал / длительность / источник; после alignment — [start_frame,end_frame) и FPS |
| Задача и визуальная находка | Что зритель поймёт/почувствует; что заметит первым |
| Видимая ситуация | Кто что делает; цель, препятствие, состояние и значимые отношения |
| Логика и ошибочное прочтение | Пространство, взгляды/жесты, опоры; что может быть понято неверно и как исключено |
| Ведущий | Отсутствует либо конкретное действие, вклад и результат проверки удаления |
| Операторское решение | Крупность, ракурс, размещение, глубина, свет, акцент; связь с соседними планами |
| Текст в сцене | Точная надпись / язык / функция / носитель / место либо мотивированное отсутствие |
| Continuity и переход | Состояние на входе/выходе; что меняется; опережение речи, если задумано |
| Опора и статус изображения | Факт / реконструкция / объясняющий образ; необходимые источники и референсы |
| Движение и защищаемые детали | Намерение, фокус, пределы кадрирования; ссылки на геометрию субтитров/оформления и окончательный motion handoff |
| Звук | Связанные M-ID и локальный акцент, если нужен |
| Постановка | DRAFT; редакция / смысловой проход / операторский проход / открытые дефекты |
| Изготовление и выбор | PLANNED; ссылка на S-ID в единственном image manifest; точный prompt/run и выбранный файл — через него |
