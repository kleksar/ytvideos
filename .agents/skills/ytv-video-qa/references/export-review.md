# Передача MP4 пользователю

После успешного FFmpeg-рендера сразу показывать фактический MP4 пользователю, без дополнительных пострендерных проверок по умолчанию. Зафиксировать версию и решение пользователя. Не выдавать незапущенные проверки и просмотр за выполненные. Отдельная проверка или разбор дефекта выполняется по поручению пользователя; методы и границы — в [video QA](../SKILL.md). Принятие конкретного MP4 не переносится на изменённый файл. Разрешения на выпуск — в [production flow](../../ytv-video-production/SKILL.md).

Для нового upload Paper/Nuviko использовать тот же `VIDEO.mp4.delivery.json` по [контракту renderer](../../../../automation/ffmpeg_montage/README.md#приёмка-и-загрузка). Переносить в него только выполненные проверки с методом, покрытием и evidence; хеши и успешный рендер не заполняют слуховую или смысловую приёмку. Пользовательское одобрение связывается с точным MP4, отдельно от технических проверок. При изменении зависимости обновить затронутые данные; готовность старой выдачи не переносится на новую.
