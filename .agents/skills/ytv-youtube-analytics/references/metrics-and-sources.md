# Metric definitions and access

Check these primary sources when collecting a new report; APIs and Studio need not expose identical metrics or definitions.

| Source | Use and boundary |
|---|---|
| [Data API video resource](https://developers.google.com/youtube/data/reference/rest/v3/videos#statistics) | Current cumulative statistics and publication metadata; no historical retention or impression/CTR report inferred from these counters. |
| [Analytics reports.query](https://developers.google.com/youtube/analytics/reference/reports/query) | Explicit dates, dimensions/filters and authorized Analytics access. Requested endDate can exceed the last day available for every requested metric; record returned coverage. |
| [Analytics dimensions](https://developers.google.com/youtube/analytics/dimensions#day) | Check reporting-day/timezone semantics rather than assuming local calendar days. |
| [API metrics](https://developers.google.com/youtube/analytics/metrics) | Definitions/units depend on report. Check the selected metric rather than map an API field blindly to a similarly named Studio card. |
| [Studio reach](https://support.google.com/youtube/answer/9314355?hl=en) | Stayed-to-watch concerns initial Shorts viewing; average duration can use engaged-view watch time. Preserve the selected format/base. |
| [Thumbnail impressions](https://support.google.com/youtube/answer/9314486?hl=en) | CTR covers registered thumbnail impressions, not every view or feed exposure. Different cards refresh at different times. |
| [Content by format](https://support.google.com/youtube/answer/12942217?hl=en) | Filter Videos/Shorts and inspect traffic and retention in their context. |

Verified 2026-11-02. Copy the exact report labels and missing-value messages into evidence; do not overwrite them with a remembered historical definition. Save changes to definitions in the relevant measurement record, not as a silent cross-period comparison.

## vidIQ

- Use Trending/VPH for recent video velocity, Outliers for relative performance within a channel, and Keyword Research for estimated search demand. Keep these fields separate. Record the endpoint, observation time and known window. When VPH snapshots disagree and the distinction affects the decision, compare timestamped cumulative counts and report the change over the actual interval. Label a peer median separately from the vendor's outlier score. A small channel baseline can yield a large outlier score. Missing country volume, dates or VPH remain unknown. A country filter alone does not make a global estimate country-specific. [Outliers](https://support.vidiq.com/en/articles/9660010-outliers)
- Public competitor data cannot establish registered impressions, CTR, retention or the share of paid traffic. A title/thumbnail wins result selects positive before/after cases. Use it to find hypotheses and check the timeline and what changed. Evaluate lift using the actual experiment. [YouTube A/B](https://support.google.com/youtube/answer/16391400?hl=en)
- For own-channel MCP reports verify the connected channel ID and exact video ID against the intended scope. If a Studio header, embedded player or extension disagrees, resolve identity before channel-level interpretation or writes. Use native Studio or authorized Analytics for fields and breakdowns absent from the connector. Match the source, date range and denominator on each card. Separate paid traffic, Search, Browse and Shorts feed when assessing performance. If paid and organic results cannot be separated, report that limit. Forecasts and best-time suggestions are hypotheses with their observed context, including timezone when known.
- Use automated content reviews to locate moments for inspection. Verify any alleged edit defect against the actual video at the stated time. Label a vidIQ breakdown as tool analysis and state which material was directly inspected. Treat Videos To Gain Views From and similar keyword matches as leads whose relevance needs verification.
- Treat title, thumbnail and Optimize/SEO scores as vendor suggestions. They do not measure a video's CTR, validate a claim, or determine the result of a native experiment. [vidIQ Scorecard](https://support.vidiq.com/en/articles/9696241-the-vidiq-scorecard)
- Daily Ideas potential and Channel Audit grades are also vendor assessments. Audit cards can show cached packaging, a different view base or a lagging period. Preserve their labels; do not silently relabel them as lifetime views, current packaging or organic performance. A displayed month-over-month percentage needs the underlying periods and a positive baseline before interpretation. Claims of a fixed engagement multiplier from a suggested action remain unverified for our channel. An average retention above 100% does not mean that every viewer finished the video. Resolve material discrepancies using native Studio or an authorized report rather than averaging conflicting values.
- Competitors surfaces use different graph transformations. In the web comparison, the observed Data normalization tooltip describes smoothing missing/duplicated counts across days, not adjustment for channel size. In the extension's Compare view, Growth is percentage change indexed to each channel's starting value, while Total shows actual values over time. Record the surface, metric, window, daily/cumulative/total mode and transformation; inspect the live definition if labels change. A tiny starting value can dominate the Growth chart. Neither smoothing nor indexing isolates organic traffic or makes channels comparable by format.
- For Competitors tables, preserve the direction of change: a text/DOM export may contain an unsigned percentage while the visual arrow/color denotes decline. Check the visual indicator before reporting a rise/fall. Treat unavailable average views/video as missing, not zero, and do not use that average as a same-age median without a known cohort. Top-video windows, channel-statistic periods and graph windows are separate controls/bases. Conflicting VPH/counts in MCP, web and extension remain separate timestamped observations until reconciled.
