# Paper Detour: главы

Прочитать [bootstrap](../../../../.agent/CHANNEL_BOOTSTRAP.md), обязательные входы и [Paper AGENTS](../../../../channels/paper_detour/AGENTS.md), состояние выпуска по реестру. Главы разрабатывать и проверять самостоятельно по точному принятому фильму.

Язык — по [общему production skill](../../ytv-video-production/SKILL.md#язык-готового-контента). Для длинных фильмов включать этап глав в производство; Shorts не дробить автоматически. Старый draft не становится проверенным после копирования. Для общего production flow сверять границы по фактической речи и принятому монтажу; после экспорта связать блок с тем же edit/file/hash и запустить формальный валидатор. Аудит существующего MP4 использует его фактическую дорожку и контекст границ. Возвращать метод и фактическое покрытие по общему chapters skill.

Принятый блок — [descriptions](../../ytv-youtube-descriptions/SKILL.md), сохранение по поручению — [release](../../ytv-youtube-release/SKILL.md). Не спрашивать заново разрешение на порученное действие, не менять доступ существующего фильма. Результаты — Packaging/Metadata выпуска; точные IDs и версии не хранить в переносимом навыке.
