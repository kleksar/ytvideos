# Профиль хэштегов Paper Detour

Перед работой прочитать [bootstrap](../../../../.agent/CHANNEL_BOOTSTRAP.md), его обязательные входы и [Paper AGENTS](../../../../channels/paper_detour/AGENTS.md). Точный выпуск и принятый материал определяются по реестру и состоянию, а не по slug. Личная консультация координатора — через [проектного владельца](../../ytv-chatgpt-extra-high/SKILL.md); подбор меток — отдельная узкая задача после установления содержания, не одновременно с написанием описания.

- Язык — по [общему production skill](../../ytv-video-production/SKILL.md#язык-готового-контента). Тематика и жанр берутся из конкретного фильма: канал включает реальные истории, легенды, личные рассказы, технологии и иные принятые темы.
- Каждый редакционный выпуск получает релевантные метки в описании. Для подтверждённого Shorts включать `#Shorts`, сохраняя существующее допустимое написание. Широкую категорию выбирать по содержанию: `#History` подходит историческому сюжету; она не обязательна для IQ, отношений или произвольного научного мысленного эксперимента. Конкретный готовый список не переносить между сюжетами.
- Брендовая `#PaperDetour` допустима как дополнительная навигация, но не заменяет предметные метки. Применять цель максимального содержательного покрытия из [основной процедуры](../SKILL.md) с первого прохода. Не просить «компактный набор» по умолчанию и не обрезать полезные конкретные метки ради лаконичности. Отсутствие данных о спросе записывать без выдуманных трендов.
- Для длинного ролика по умолчанию метки размещать в описании. Для Shorts метки допустимы в названии после смыслового хука. Читаемость и фактическое отображение принадлежат [titles](../../ytv-paper-video-titles/SKILL.md); обрезание хвоста меток само по себе не требует сокращать понятное название. При правке только описания не менять существующее название.
- Блок передавать [descriptions](../../ytv-youtube-descriptions/SKILL.md) для сборки с текстом, ссылками и уже принятыми главами. Внешние изменения — через [release](../../ytv-youtube-release/SKILL.md), который вызывает существующий глобальный uploader. Повторно спрашивать разрешение на уже порученную правку не требуется.
- Результат хранить в `Packaging/Metadata/` фактического выпуска; для общеканального аудита допустима общая сводка с поэпизодными ссылками.
