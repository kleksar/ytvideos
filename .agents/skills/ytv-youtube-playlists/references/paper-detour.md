# Paper Detour profile

Before use read [bootstrap](../../../../.agent/CHANNEL_BOOTSTRAP.md), the required root/registry/episode sources and [Paper rules](../../../../channels/paper_detour/AGENTS.md).

[YOUTUBE_PLAYLISTS.md](../../../../channels/paper_detour/docs/YOUTUBE_PLAYLISTS.md) owns playlist IDs, promises, language/order choices, current access, membership and exceptions. Reconcile it with fresh API state; old private receipts do not supersede a later owner-authorized Public state. Existing public collections retain their access. For a genuinely new collection without an explicit access decision use Private; preparation and membership do not authorize public release.

Use the [shared product-language rule](../../ytv-video-production/SKILL.md#язык-готового-контента). Titles/descriptions of playlists should explain the viewer route, with no hashtag dump or forced channel-name repetition. The registry's documentary, retold-story and digital-life boundaries apply to accepted final content; preserve reported-match, folklore, personal-account and IQ-estimate qualifications. Do not classify by old slug: 027 is Minnie Freeman; scrolling is 004.

For a new film, the [production coordinator](../../ytv-paper-production/SKILL.md) calls this owner while assembling packaging. Store an assignment/position even if the request ends at local video. When the request includes YouTube release/organization, [release](../../ytv-youtube-release/SKILL.md) resolves the video ID, invokes global uploader mechanics and verifies saved membership. Do not wait for another user prompt for an already authorized step.

Use the [API adapter](../../../../automation/youtube/README.md) and channel configuration it names. Its existing private-only membership helper and unlisted-only creation helper do not cover every Paper target; check official endpoints rather than silently changing access to satisfy those scripts.
