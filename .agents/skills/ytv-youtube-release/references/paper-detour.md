# Настройки выпуска Paper Detour

## Категория и настройки канала

- В Studio → Настройки → Загрузка видео → Расширенные настройки установлено **Образование** для загрузок из браузера. Категорию конкретного фильма или Short выбирать и проверять по [общему стандарту](video-categories.md).
- Использовать English для оригинального английского видео, названия и описания. По умолчанию в Studio установлены Standard YouTube License, Private для подготовки, автоматические главы, включённые комментарии с базовой модерацией. У длинного фильма проверять главы из описания по финальному MP4. Для видео с речью проверять отдельную ручную дорожку на языке принятого звука.
- На канале включены Clips и автоматический дубляж с ручной проверкой перед публикацией. Улучшения картинки и звука и разрешение на стороннее обучение ИИ выключены. Декларации аудитории, возрастных ограничений, платного продвижения и синтетического контента определяются по фактическому выпуску.

## Приёмка отдельного выпуска

При порученном выпуске сверить сохранённые название, описание с главами и хэштегами, обложку, применимые поисковые теги и плейлист, категорию, оба поля языка, права и декларации, обработку, дорожку субтитров и разрешённый доступ. Проверить, что длинный фильм получил [конечную заставку Paper](../../ytv-video-production/references/paper-end-screens.md), а Short — связанное видео при наличии подходящей цели и доступной функции. Для выбранных зрительских переходов проверять точные цели. Отмечать, какие поля проверены, какие неприменимы и какие требуют отдельного действия.
