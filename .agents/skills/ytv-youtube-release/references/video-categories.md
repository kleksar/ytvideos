# Категории видео на YouTube

Выбирайте категорию для каждого длинного фильма и Short по основному содержанию. Сверяйте название и описание с принятым сценарием, транскриптом или самим роликом, если упаковка оставляет сомнения. В пограничном случае проверьте, что зритель получает от основной части и финала.

| Категория | Когда выбирать |
|---|---|
| Education / Образование (`27`) | Фактическая история, документальная реконструкция, научное или техническое объяснение. Для Paper Detour и Nuviko History это исходная категория таких выпусков. Сюда входит явно обозначенный мысленный эксперимент, если он объясняет научные принципы, и разбор происхождения легенды. |
| Entertainment / Развлечения (`24`) | Драматизированный пересказ легенды, художественная история или развлекательная подборка, когда зритель прежде всего следит за сюжетом или смотрит подборку ради интереса. |
| People & Blogs / Люди и блоги (`22`) | Бытовой сторитайм, личный опыт, отношения и повседневность с точки зрения участника. Это исходная категория для такого формата русскоязычного «Нувико». |
| Science & Technology / Наука и технологии (`28`) | Выпуск посвящён самой технологии, устройству или инженерной разработке, например демонстрации технологии, техническому обзору или отраслевой новости. Документальная история разработки и объяснение научного принципа обычно относятся к Education. |

Для другой тематики проверьте доступные категории через `videoCategories.list` и выберите подходящую. Учебную программу, уровень и экзамен указывайте, только если они действительно относятся к выпуску.

## При загрузке

Запишите выбранную категорию в метаданные выпуска. Передавайте `category_id` явно при API-загрузке и проверяйте поле категории при загрузке через Studio. Сохранённое значение сверяйте по `videos.list` → `snippet.categoryId`. Настройка Studio для новых загрузок применяется к загрузкам из браузера.

## При порученном аудите каталога

1. Сверьте каналы по точным ID и проверьте действующий OAuth для каждого. Получите все страницы плейлиста загрузок с авторизацией канала, затем сверяйте каждый video ID и владельца по API. Отдельно фиксируйте публичное покрытие без доступа владельца, недоступные ID и разницу с ожидаемым составом.
2. Запишите для каждого ролика текущую и выбранную категорию, основание и источник сведений о содержании. При совпадении достаточно проверки сохранённого значения.
3. Исправляйте только расхождения по процедуре глобального `youtube-upload`. При `videos.update` запрашивайте свежий `snippet` и сохраняйте прочие редактируемые поля этой части. Используйте проверку ETag. После записи перечитайте категорию и сопоставьте остальной `snippet`, доступ, расписание и локализации с исходными данными. При неизвестном исходе сначала сверяйте состояние чтением.
4. Сохраните результат по каждому video ID. Отдельно укажите подтверждённые изменения, уже верные значения, публичное покрытие без доступа владельца и блокеры.
