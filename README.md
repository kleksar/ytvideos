# ytvideos

Проект для производства видео нескольких каналов. Корневые рабочие правила — в [AGENTS.md](AGENTS.md); владельцы процедур и канальные входы указаны там и в [каталоге skills](.agent/skill-catalog.md).

Структура каналов и общих компонентов — в [CHANNEL_LAYOUT.md](.agent/CHANNEL_LAYOUT.md). Каналы находятся в `channels/`, отдельные проекты — в `projects/`, общая автоматизация — в `automation/`.

Для первого запуска, зависимостей и авторизации см. [ONBOARDING.md](ONBOARDING.md). Правила веток, коммитов и merge request — в [COLLABORATION.md](COLLABORATION.md). Перед добавлением файлов проверяйте `git status` и staged diff. Исключения в [.gitignore](.gitignore) защищают кэши, локальные окружения, монтажные сессии, рендеры и аудио/видео от случайного попадания в Git. Файлы остаются на диске.

Целевой хостинг — приватный GitHub-репозиторий владельца `kleksar`; пользователь разрешил его создание и загрузку проверенной выборки. Приватный репозиторий создан: `https://github.com/kleksar/ytvideos`. Локально есть ветка `main`, два коммита и настроенный SSH remote; GitHub пока пуст — отправка ожидает повторной аутентификации владельца. Коллега ещё не добавлен. Перед отправкой повторно проверьте staged diff и приватность remote.
