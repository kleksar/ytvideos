# ytvideos

Проект для производства видео нескольких каналов. Корневые рабочие правила — в [AGENTS.md](AGENTS.md); владельцы процедур и канальные входы указаны там и в [каталоге skills](.agent/skill-catalog.md).

Для первого запуска, зависимостей и авторизации см. [ONBOARDING.md](ONBOARDING.md). Правила веток, коммитов и merge request — в [COLLABORATION.md](COLLABORATION.md). Перед добавлением файлов проверяйте `git status` и staged diff. Исключения в [.gitignore](.gitignore) защищают кэши, локальные окружения, монтажные сессии, рендеры и аудио/видео от случайного попадания в Git. Файлы остаются на диске.

Целевой хостинг — приватный GitHub-репозиторий владельца `kleksar`; пользователь разрешил его создание и загрузку проверенной выборки. Сейчас локальная рабочая копия ещё без коммитов и remote: доступный GitHub-коннектор не умеет создавать репозитории, а локальный `gh` не авторизован. Коллега пока не добавлен. Не отправляйте проект, пока remote не создан и не проверена приватность.
