# ytvideos

Единый процесс создания YouTube-видео с GPT-6 Luna: самостоятельный поиск темы → полный сценарий → согласование → производство → проверенный MP4 → согласование → полностью оформленная отложенная публикация.

Канал задаёт содержание, стиль, голос, производственный рецепт и календарь. Код определяет допустимые задачи, версии, проверки и полномочия. Состояние сохраняется вне чата; параллельные workers получают отдельные задания.

## Начать

Для агента: [AGENTS.md](AGENTS.md), затем [ytv-start](.agents/skills/ytv-start/SKILL.md). Для разработчика: [development](docs/development.md). Для переноса текущих выпусков: [migration](docs/migration.md).

```bash
uv sync
uv run python -m ytvideos --help
```

Использовать один рабочий каталог и одно хранилище состояния для взаимосвязанных сессий. SQLite подходит для изолированной локальной работы; для нескольких production workers использовать PostgreSQL. Пути и DSN передавать через аргументы CLI/конфигурацию окружения; секреты в Git не сохранять.

| Каталог | Содержание |
|---|---|

| `channels/` | Идентичность, профиль и художественные эталоны каналов |
| `automation/` | Существующие технические средства TTS, монтажа, QA и YouTube |
| `docs/standards/` | Единственные владельцы повторяемых требований |
| `tests/`, `evals/` | Контракты, отказные случаи и проверки маршрута на Luna |

Наличие кода очереди не означает работающую круглосуточную ферму. Для фактического исполнения нужны доступные runtime workers, media storage, разрешённые генераторы и доступ к целевому каналу. Проверять их через `doctor`; отсутствие публикационного доступа не должно останавливать независимую сценарную работу.
