# ytvideos

Проект для производства видео нескольких каналов. Корневые рабочие правила — в [AGENTS.md](AGENTS.md); владельцы процедур и канальные входы указаны там и в [каталоге skills](.agent/skill-catalog.md).

Структура каналов и общих компонентов — в [CHANNEL_LAYOUT.md](.agent/CHANNEL_LAYOUT.md). Каналы находятся в `channels/`, отдельные проекты — в `projects/`, общая автоматизация — в `automation/`.

Для первого запуска, зависимостей и авторизации см. [ONBOARDING.md](ONBOARDING.md). Состав переносимых визуальных стандартов и ссылок — в [индексе бренд-материалов](channels/BRAND_ASSETS.md). Правила веток, коммитов и merge request — в [COLLABORATION.md](COLLABORATION.md). Перед добавлением файлов проверяйте `git status` и staged diff. Исключения в [.gitignore](.gitignore) защищают кэши, локальные окружения, монтажные сессии, рендеры и аудио/видео от случайного попадания в Git. Файлы остаются на диске.

Проект опубликован в приватном GitHub-репозитории [`kleksar/ytvideos`](https://github.com/kleksar/ytvideos). Доступ коллеги владелец выдаёт отдельно. В source-only клоне нет выпускных медиа, секретов и локальных OAuth-настроек; инструкции по запуску и передаче зависимых материалов — в [ONBOARDING.md](ONBOARDING.md).
