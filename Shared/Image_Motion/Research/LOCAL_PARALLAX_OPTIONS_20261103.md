# Local parallax research — 2026-11-03

Context: user's current comparison chose combinations 2 and 3 (opposite parallax and whole-frame directions) for consideration. Target hardware checked: MacBook Pro M1 Pro, 32GB unified RAM. Existing production path: DepthAnythingV2-small + DepthFlow 1.0.1, with one image/depth surface; user-approved experimental variant 08 uses isometric=1, height .26, signed linear offset .18; FFmpeg perspective interpolation separately tested for subpixel camera motion. This is an episode experiment, not a production change.

## Candidates

1. Layered approach: SAM 2 foreground masks plus matting/refinement, LaMa inpainting and separate background/foreground animation. SAM 2 provides local inference and Apache 2.0 checkpoints https://github.com/facebookresearch/sam2 ; CoreML conversion https://github.com/huggingface/segment-anything-2/tree/coreml-conversion ; LaMa https://github.com/advimman/lama and conversion https://github.com/mallman/CoreMLaMa (author says runs on macOS GPU). Project already has local proof-of-concept new_channel/automation/paper_detour_sam2_pilot/README.md but default checkpoint absent at checked path. Its own README says binary masks not refined mattes and no background inpainting/full composite verification. No full pipeline test or licensing of exact weights/dependencies checked.
2. https://github.com/vt-vl-lab/3d-photo-inpainting contains layered depth synthesis and MIT license, but documented Python 3.7 / PyTorch 1.4 / Ubuntu/CUDA environment; unverified M1 installation. Test only in isolated environment and check bundled weights/dependencies before production.
3. https://github.com/apple/ml-sharp predicts 3D on CPU/MPS but bundled trajectory rendering CUDA-only and https://github.com/apple-aiml-research/ml-sharp/blob/main/LICENSE_MODEL limits weights to noncommercial scientific research; not a candidate for monetized production without appropriate authorization. Do not confuse code license with model license.
4. https://github.com/DepthAnything/Depth-Anything-V2 Small Apache-2.0, Base/Large/Giant CC BY-NC. Current small already used; depth quality alone does not reconstruct hidden pixels. No grounds to substitute NC versions for monetized channels.

Recommendation to test on exact same scene at 6s, 1080p, 30fps and identical camera path: existing option 08 vs SAM2 + matte + LaMa filled BG + independently moving planes, then broader testing on multiple scenes. Evaluate subjective start/mid/end and full playback, fine hair, halos, content-preservation, seam/motion, and processing cost. Technology research only; no new models installed or outputs produced.
