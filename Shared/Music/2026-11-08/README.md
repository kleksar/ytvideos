# Музыкальная библиотека ytvideos

В папке Tracks — 26 исходных MP3 Kevin MacLeod и Scott Buckley, полученных из каталогов авторов без перекодирования. Для каждой записи в manifest.json указаны точная версия, категория, источник, лицензия, длительность и SHA-256. В ATTRIBUTION.txt есть английские кредиты для описаний YouTube. При обрезке, обработке или сведении допишите, что изменили.

## Как музыка используется в проекте

- Paper Detour и Nuviko History выбирают точные версии из общего списка в `channels/paper_detour/docs/MUSIC_CATALOG.md`. Спокойная подложка поддерживает голос, тематическая музыка сменяет её на повороте. У выпуска фиксируют источник, версию, интервалы, фейды, уровень, лицензию и кредит. В Paper 050 основой была Satiate - only percussion, а темой — Signal to Noise — No Piano Melody. В Nuviko History 049 Endurance музыкальный стем и полный микс хранились отдельными версиями.
- Scenes on Repeat ведёт музыку, оригинальный звук фильма и диктора отдельными дорожками. Музыку приглушают под ключевой репликой или звуком действия. Примеры в проекте — Hitman в Kingsman и Constance в Edge of Tomorrow. Трек и кредит записывают у фильма.
- Звуки из Add sound используются через редактор Shorts. В эту библиотеку входят записи, полученные напрямую у авторов и доступные для локального монтажа по CC BY 4.0.

Подбор для выпуска начинается с [музыкального брифа](../../../.agents/skills/ytv-audio-delivery/references/music-direction.md). Индекс ниже помогает найти отрывок с нужной динамикой.

## Как использовать таймкоды отрывков

У каждого трека есть кандидаты на ровную подложку, нарастание, акцент и спад. Ровную подложку алгоритм ищет в 16-секундных окнах. Для нарастания сравнивает начало, середину и конец восьмисекундного участка. Для акцента учитывает атаку звука и её контраст с окружающим фрагментом. Для спада ищет снижение активности, которое сохраняется несколько секунд. Таймкоды относятся к конкретным MP3 из манифеста. В таблице показан первый вариант каждого типа, в JSON есть до трёх. [Таблица таймкодов](CUES.md) · [Данные для автоматизации](CUES.json)

Чтобы совместить акцент, вычтите из его времени в треке интервал от входа музыки до события в ролике. Если нужное начало выходит за пределы записи или заход не подходит по темпу, возьмите другой кандидат либо начните музыку позже. Сверьте привязку в пробе по музыкальному брифу.

Обновление индекса из корня проекта. Нужны FFmpeg и Python с NumPy.

```sh
python3 automation/music_cues.py Shared/Music/2026-11-08/manifest.json
```
