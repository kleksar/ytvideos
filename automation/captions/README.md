# Исходная карта слов

`word_timings.py` локально проверяет exact text и character alignment, затем создаёт слова с временами первого/последнего символа. Это исходная оценка, а не принятый sync или готовый экранный subtitle layer.

```bash
python3 automation/captions/word_timings.py --help
```

Передать принятый UTF-8 текст, реальный alignment, язык и новый output. `normalized_alignment` выбирать только при доказанном совпадении с текстом. Проверяются массивы/timing/Unicode NFC; текст не исправлять молча ради совпадения. Существующий output не перезаписывать.

Имена, числа, сокращения и произнесённые варианты сверять с записью. `source_sha256` относится к прочитанному UTF-8 тексту; байтовые особенности и `.strip()` в разных helpers учитывать при binding, не смешивать разные hashes. Финальная скорость/монтаж и фактическое прослушивание — [audio standard](../../docs/standards/audio.md).
