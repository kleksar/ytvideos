# Пословные тайминги ElevenLabs

`word_timings.py` проверяет утверждённый текст и посимвольное `alignment`, затем создаёт JSON со словами, отображаемой формой в верхнем регистре и временем первого и последнего символа каждого слова. Он работает локально, без сети. Это исходная карта слов, **не готовые титры**: смысловое разбиение, отображение, прослушивание и синхронизация проверяются отдельно по `../../docs/story-shorts-v1/CAPTIONS.md`.

В примере используйте каталог нужной истории вместо `002_pompeii`.

```sh
python3 automation/captions/word_timings.py \
  --text videos/002_pompeii/Source/Voice/script_ru.txt \
  --alignment videos/002_pompeii/Source/Voice/voice_ru.alignment.json \
  --language ru \
  --output videos/002_pompeii/Source/Voice/voice_ru.words.json
```

Для английского используйте соответствующие `script_en.txt`, `voice_en.alignment.json` и `--language en`. Существующий результат не перезаписывается. Проверка берёт `alignment`; `--field normalized_alignment` допускается только при явном выборе, когда она совпадает с утверждённым текстом. Несовпадения, неверные массивы/тайминги и отсутствие данных останавливают работу. Различия можно исправлять только после ручной проверки, не подменяя исходный текст. Пробелы по краям удаляются так же, как в TTS; Unicode сравнивается в NFC. Внутренние апострофы и дефисы в словах сохраняются, пунктуационное тире и знаки за пределами слов убираются из отображения. Необычные символы и числовые записи могут потребовать ручной адаптации произношения и проверки.

Время слова — временной диапазон символов из ответа API, не гарантия реального звучания. `source_sha256` рассчитан по UTF-8 тексту после чтения Python (с универсальными переводами строк), включая внешние пробелы. Модель могла произнести написанный текст иначе, например число или сокращение; совпадение массива символов не подтверждает качество произношения. Проверяйте полную озвучку и готовые титры, ограничения длины и смысловых связей.

Проверка, в том числе на сохранённых русской и английской пробах:

```sh
python3 -m unittest discover -s automation/captions -p 'test_*.py' -v
```
