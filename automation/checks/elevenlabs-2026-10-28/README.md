# Проверка ElevenLabs — 28 октября 2026

Выполнена одна пробная генерация короткой фразы на каждом языке через
`/v1/text-to-speech/{voice_id}/with-timestamps`: голос `ZEchI3lWet1JsdNubYRY`
(Darth), модель `eleven_v4`, `stability=1.0`, `similarity_boost=0.0`,
автоопределение языка. Числа выбраны по крайним видимым положениям на
скриншоте и требуют проверки на слух; свернутые аудиоэффекты и Clone
strength не передавались. Настройки по умолчанию, возвращённые запросом
голоса, отличаются от этой пары, поэтому скрипт передавал её явно.

Результаты: `voice_ru.mp3` — 3,92 с, `voice_en.mp3` — 3,76 с; оба файла
MP3 44,1 кГц/128 кбит/с успешно декодируются. API вернул посимвольную
разметку на 54 и 50 символов соответственно. Это подтверждает получение
файлов и разметки, но качество произношения и синхронизацию нужно
прослушать и проверить отдельно.

Пользователь подтвердил, что русская и английская пробы звучат хорошо;
эту пару параметров можно использовать как рабочую для серии.
