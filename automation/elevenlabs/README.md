# Озвучка ElevenLabs

Единственный источник соответствия каналов и голосов — [реестр и контракт](../../.agents/skills/ytv-audio-delivery/references/channel-voices.md). `tts.py` требует `--channel paper_detour` или `--channel nuviko_history` и берёт ID из машинного реестра; `--voice-id`, если указан, должен совпадать. Без `--generate` проверка не обращается к сети. До платного запроса проверяется доступность того же ID в аккаунте. При неизвестном исходе не повторять запрос без проверки истории; существующие файлы и квитанции не перезаписываются.

```sh
python3 automation/elevenlabs/tts.py --channel paper_detour --en-text path/to/script.txt --output-dir path/to/output
```

Добавьте `--generate` только при действующем разрешении. Для каждого языка до запроса сохраняется `voice_<lang>.request.json`; после успешного ответа в нём фиксируются параметры и hash аудио. `request_started` означает, что исход нужно проверить вручную, а не что генерация состоялась. Реестр не определяет исторический голос существующего аудио. Модель `eleven_v4`, MP3 44.1 kHz / 128 kbps, stability 1.0, similarity 0.0; генерационная скорость не задана, если явно не передана. Скорость монтажа определяется профилем канала и применяется один раз.

Ключи перебираются по возрастанию: `ELEVENLABS_API_KEY`, `ELEVENLABS_API_KEY_2`, `ELEVENLABS_API_KEY_3` и далее, включая номера с пропусками. Для каждого номера переменная среды имеет приоритет над Keychain `yt-stories-elevenlabs`, `yt-stories-elevenlabs-2` и т. д. Записи Keychain 1 и 2 проверяются по умолчанию; дополнительные номера перечислите в `ELEVENLABS_KEYCHAIN_SLOTS`, например `2,3,5`. Одинаковые ключи проверяются однократно; сами значения нигде не печатаются. Перед запросом каждый аккаунт должен подтвердить тот же ID голоса. При отказе авторизации, отсутствии доступа к голосу или подтверждённой нехватке квоты выбирается следующий ключ. Ошибки параметров, 429, 5xx, связь и неоднозначный ответ останавливают процесс: повтор платного запроса может создать расход или дубликат. Если ни один аккаунт не подходит, исправьте ключи, квоту или доступ к голосу. При неизвестном исходе проверьте историю ElevenLabs до повторной генерации.

Все локальные процессы и worktree одного пользователя автоматически разделяют состояние в `~/.cache/ytvideos/elevenlabs/` (при необходимости путь можно задать через `ELEVENLABS_CACHE_DIR`; у всех параллельных процессов он должен совпадать). Файловая блокировка объединяет одновременные проверки: успешная проверка относится только к паре ключ/voice ID и действует 10 минут; отказ ключа или доступа к голосу — 2 минуты, подтверждённая нехватка квоты для той же модели и текста не короче отклонённого — 1 минуту. Затем проверка выполняется заново. При 401 ранее подтверждённые голоса этого ключа сбрасываются; замена ключа автоматически получает отдельное состояние. В кеше хранятся хеши ключей и время, но не ключи, текст или аудио. Каталог доступен только владельцу. Удаление кеша при остановленных процессах безопасно и принудительно инициирует проверки заново.

Синтез нескольких процессов не сериализуется: если они одновременно начали работу до получения отказа, несколько запросов могут попасть на один аккаунт. После получения однозначного отказа следующие проверки используют обновлённое состояние. Если связь с сервисом прервалась или ответ неоднозначен, повтор на другом ключе не выполняется: сначала проверьте историю сервиса и квитанцию.
