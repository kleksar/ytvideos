# Проверка подключения Palmier Pro

В установленном приложении используется штатный локальный MCP-мост
`http://127.0.0.1:19789/mcp` из комплекта `palmier-pro.mcpb`. После обновления
до Palmier Pro 0.12.0 (29 октября 2026) живой MCP-контракт проверен 1 ноября:
операции проекта используют `projectId`, операции таймлайна — одновременно
`projectId` и `timelineId`. Видимое окно больше не определяет цель операции.
Официальные сведения: [Agent and MCP](https://www.palmier.io/docs/agent-and-mcp),
[changelog 0.12.0](https://www.palmier.io/changelog).

Этот адаптер общий для каналов проекта; расположение в `archive/legacy_stories/` не ограничивает его выпуском или каналом. Предпочтение MCP и границы UI задаёт единственный владелец [ytv-palmier-edit](../../.agents/skills/ytv-palmier-edit/SKILL.md).

### Если инструменты не видны в чате

Использовать существующий Python-клиент `PalmierConnection` из `inspect_connection.py` напрямую. Он выполняет `initialize` → `notifications/initialized`, согласует версию протокола, сохраняет `Mcp-Session-Id` при его наличии и разбирает JSON/SSE-ответы. Это обращения к штатному MCP-серверу, не чтение или редактирование файлов `.palmier`.

Из корня `ytvideos/` получить живые схемы и короткую сводку:

```python
import json
import sys
from pathlib import Path

sys.path.insert(0, "automation/palmier")
from inspect_connection import PalmierConnection

connection = PalmierConnection()
connection.connect()
tools = []
cursor = None
while True:
    page = connection.request("tools/list", {"cursor": cursor} if cursor else {})
    tools.extend(page.get("tools", []))
    cursor = page.get("nextCursor")
    if not cursor:
        break
# output_path — путь квитанции текущей задачи вне .palmier.
Path(output_path).write_text(json.dumps({"tools": tools}, ensure_ascii=False, indent=2))
print([tool["name"] for tool in tools])
projects = connection.read_tool("manage_project", {"action": "list"})
```

Прочитать `description` и `inputSchema` нужной команды из полного сохранённого списка. Для чтения инвентаря/таймлайна использовать `read_tool`, для другой проверенной команды — `connection.request("tools/call", {"name": tool_name, "arguments": arguments})`. `read_tool` намеренно допускает только три безопасных вида чтения; его отказ на другую команду не означает, что команда недоступна в MCP. У `tools/call` проверять и JSON-RPC ошибку, и `result.isError`; текст в `content` разбирать только по фактическому формату ответа. Не отключать allowlist диагностического помощника ради записи.

Проверено 3 ноября 2026: локальный мост вернул 58 инструментов при отсутствии Palmier в списке инструментов чата. Схемы и чтение проекта сохранены в [квитанции подключения](../../channels/paper_detour/research/2026-11-03-palmier-mcp/REPORT.md). Число инструментов — снимок, а не условие будущей проверки.

### Адресация и исполнение

- `manage_project list` → точный путь/ID → `open`, если проект ещё не загружен; `show` не нужен для редактирования.
- `get_media(projectId)` → актуальные `mediaRef` и `timelineId` → `get_timeline(projectId, timelineId)`.
- `manage_snapshots save` → сохранить возвращённый ID и проверить имя через `list`; ввод текста в UI не подтверждает переименование.
- `import_media` импортирует файлы/каталоги по пути; путь остаётся зависимостью проекта. Пакетный импорт каталога может включить невыбранные версии: монтаж брать из явного принятого списка файлов.
- `add_clips` ставит клипы по `[startFrame,endFrame)` и перезаписывает пересечения; `insert_clips` сдвигает последующие клипы. Не подменять одну семантику другой. Для пустого таймлайна `add_clips` может создать общую дорожку при отсутствии `trackIndex` у всех entries. Смешанный набор с заданным и пропущенным `trackIndex` недопустим.
- Длительности, дорожки и медиа после записи сверять через `get_timeline`/`get_media`. `inspect_timeline` даёт кадры композиции для проверки без UI. Экспорт проверять по точному job через `manage_exports` и затем по video QA.

Диагностика только читает проектную инвентаризацию; один таймлайн можно
запросить по обоим точным ID:

```sh
python3 automation/palmier/inspect_connection.py
python3 automation/palmier/inspect_connection.py --project-id PROJECT_ID --timeline-id TIMELINE_ID
```

`check_active.py` по `--project-path` и точному ID теперь проверяет, что таймлайн
принадлежит указанному проекту; его не требуется активировать или делать
видимым. Проект должен быть уже загружен в Palmier. Если нет — откройте его
через `manage_project` с `action: "open"`; это загрузит проект в фоне и не
переключит окно. `action: "show"` открывает окно только для просмотра.

Перед правкой перечитайте `manage_project/list` и `get_media(projectId)`, затем
читайте и изменяйте только таймлайн, выбранный явным `timelineId`. Не
переключайте UI для адресации. Для нескольких исполнителей назначайте каждому
собственный проект или отдельный таймлайн и уникальную папку медиа; совместную
правку одного таймлайна не считать безопасной. `undo` откатывает конкретный
собственный вызов по `actionId`, если после него таймлайн не менялся. Именной
snapshot сохраняет версию таймлайна; его можно восстановить только после
проверки истории и авторства правок. Изменять `.palmier` на диске напрямую
нельзя. Импорт по пути ссылается на исходник; сохраняйте его в постоянной
папке выпуска. После неоднозначной MCP-ошибки не повторяйте вызов: сначала
сверьте квитанцию и фактическое состояние по ID.

Если мост недоступен, проверьте, что Palmier Pro запущен и проект открыт.
Доступность MCP в этом локальном окружении не гарантирует доступ в другой
сессии или после смены проекта.

### Проверка конкретного таймлайна без переключения окна

Имя не является безопасным идентификатором. После свежего `inspect_connection.py`
проверьте точный ID в инвентаризации проекта:

```sh
python3 automation/palmier/check_active.py --project-path '<repo-root>/channels/nuviko_stories/videos/001_brother_ex_best_friend/1.palmier' --timeline-id 'ID_ИЗ_СВЕЖЕЙ_ПРОВЕРКИ'
```

Проверка сопоставляет физический путь с ровно одним доступным проектом,
подтверждает его `projectId` и наличие `timelineId` в `get_media`, затем читает
таймлайн по обоим ID. Видимость проекта не требуется. Пути должны быть
абсолютными и существовать; символьные ссылки допустимы, если указывают на тот
же физический объект. Это снимок состояния, не блокировка. Перед каждой
серией изменений повторно проверяйте целевой таймлайн по ID.
`add_clips` перезаписывает пересекающиеся клипы на дорожке и по умолчанию
добавляет звук видео; диапазоны и `includeAudio` требуют явной проверки.

### Монтажная процедура

Для сборки и правок применять [ytv-palmier-edit](../../.agents/skills/ytv-palmier-edit/SKILL.md) и текущий принятый план своего канала. Технический помощник выбирать только после проверки его контракта на нужных IDs. Перед экспортом проверить кадры, титры и синхронизацию; доставку и YouTube выполнять отдельными процедурами.
