Новые каналы сейчас не подключаются. Русскоязычный «Нувико» коллеги не наследует identity архива Stories. До подтверждения идентичности, владельца, голоса, прав и календаря не создавать его из похожего имени. Для будущих десяти каналов добавлять данные профиля и проверять recipe/capabilities, сохраняя один workflow.

Общие brand assets и provenance — [BRAND_ASSETS](BRAND_ASSETS.md). Канальный профиль не подтверждает наличие всех media в checkout.
