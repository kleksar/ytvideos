# Срез публичного веб-индекса: 20 ноября 2026 UTC

[Отчёт и методика](PUBLIC_REPORT_RU.md) описывают замер по 156 запросам: 175 уникальных video ID, из них 172 с датой и просмотрами и 165 в аналитических группах. Позиция результата относится к публичному веб-индексу, не к выдаче YouTube. Счётчики извлечены из наблюдаемых снимков, не являются синхронным live-замером. В срезе нет подтверждённых player runtimes, Google Trends численных рядов, фактических источников трафика конкурентов, RPM и доходов. Язык запроса и упаковки не определяет страну зрителя.

Сохранены фактические значения полей и публичные ссылки наблюдения; файлы CSV записаны UTF-8 без BOM с LF. При импорте в электронную таблицу задавать текстовый тип для ID и названий, не вычислять значения как формулы. Нативная выдача YouTube и Suki English остаются отдельными проверками. В репозитории нет сырых ответов провайдера, скриншотов или приватной аналитики.
