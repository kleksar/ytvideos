# Nuviko History

Канал активен; поддерживаются illustrated Short и long по закреплённому [ChannelSpec](channel.json). Для существующего run сохранять его pins и проверенные материалы; смена конфигурации требует явной миграции.

При входе читать [root](../../AGENTS.md), назначенный skill и [PROFILE](PROFILE.md). Общий lifecycle — [workflow](../../docs/workflow.md); внешность ведущего — [VISUAL_PROFILE](brand/VISUAL_PROFILE.md). Это отдельный исторический канал, не архив Stories и не русскоязычный «Нувико» коллеги.
