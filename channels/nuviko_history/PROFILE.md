# Nuviko History — профиль продукта

[ChannelSpec](channel.json) хранит текущий статус и машинные параметры; [workflow](../../docs/workflow.md) общий для всех каналов. Замороженный профиль не запускает новые выпуски без прямого поручения на снятие заморозки или конкретное исключение.

Готовый продукт — английский исторический рассказ с проверенной фактической основой. Принятую реконструкцию рассказывать связной историей, сохраняя материальную неопределённость и внутренние источники по [editorial](../../docs/standards/editorial.md).

Стиль — рисованный 2D путешественник в фотореалистичном мире. Окружение, предметы и остальные люди выглядят как реальная съёмка, ведущий сохраняет точную принятую рисовку. [VISUAL_PROFILE](brand/VISUAL_PROFILE.md) и фактические два PNG — обязательные references для сцен с героем. Реконструкции обычно в естественном приглушённом цвете; архив сохраняет исходную палитру. Монохром имеет отдельную функцию, не маскирует новодел под архив.

Голос `5vsgZsi667xMyGinrNIM`; его имя не подтверждено. Скорость 1.10× ровно один раз. Музыка обязательна в полном производстве. Партитура, права, допустимые паузы и проверки — по [audio](../../docs/standards/audio.md).

Short 9:16, long 16:9, выдачи 2K/30 FPS по [delivery](../../docs/standards/delivery.md). Цельный pan/zoom и композиции 4–6 секунд — [visual](../../docs/standards/visual.md). Screen subtitle style — [nuviko.json](../../automation/ffmpeg_montage/profiles/nuviko.json): Georgia Bold, кремовый `#F3E9D5`, активное слово `#FFD166`, тёмная плашка `#20252BCC`. Для Shorts собственный nuviko_short.json, для long общий long.json; числовые размеры задаёт соответствующий format profile; синхронизацию и смысловые группы проверять отдельно.

Для применимого long фильма последняя отдельная композиция длится 10 секунд после завершения истории. Фон тематический, созданный для этого сюжета; ведущий необязателен. Не запекать псевдокнопки, avatar, thumbnails/названия целей. Оставить свободные зоны для Subscribe и подходящих видео этого канала, проверить actual native elements в Studio. Фон и кликабельные элементы имеют разные receipts. Это исключение из общей длительности планов 4–6 секунд.

Обложки разрабатывать и проверять по [thumbnails](../../docs/standards/thumbnails.md). 2D-ведущий нужен, когда объясняет масштаб, реакцию или взгляд на событие; его присутствие не обязательно. Сохранять утверждённую идентичность и actual references, если он изображён. Не представлять внешнего рассказчика участником исторического события; без ведущего конкретный предмет или действие должны сохранять понятность обещания.

Фактические category/languages/declarations/calendar/targets проверять для выпуска по [release](../../docs/standards/release.md). Сохранённые выпуски продолжают использовать закреплённый профиль до явной миграции.
