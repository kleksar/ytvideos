## Выбор маршрута

Прочитаны youtube-upload, проектный release, API adapter и channels.json. Существующий `history` указывает источник `UCqct_dth0WSCwiDZx1WMfgg`; к назначению не переназначался и для записи не использовался.

API поддерживает баннер через channelBanners.insert + channels.update, но YouTube channel permissions не дают приглашённому Manager доступ к YouTube APIs. Это ограничение данного типа делегированного доступа, не диагностированная ошибка OAuth, квоты или отсутствующая CLI-команда. Поэтому использован доступный этому Manager интерфейс Studio. Источники: [channel permissions](https://support.google.com/youtube/answer/9481328?hl=en), [channelBanners.insert](https://developers.google.com/youtube/data/reference/rest/v3/channelBanners/insert), [branding](https://support.google.com/youtube/answer/10456525?hl=en).
