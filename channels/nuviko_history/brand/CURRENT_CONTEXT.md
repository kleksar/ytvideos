## Принятые требования пользователя

- Аудитория и публичные тексты — английские.
- Последнее уточнение пользователя: постоянный путешественник слегка мультяшный, а исторические сцены, предметы и остальные люди ультрареалистичны. Эффект — герой из мультфильма путешествует по реалистичной истории разных эпох. Полностью фотореалистичный герой из первого комплекта этому уточнению не соответствует.

- Повторно использовать стадии процесса Paper: исследование → текст → визуальная партитура → сцены → разрешённая озвучка → timing → субтитры → порученное движение → монтаж → export/QA → упаковка и выпуск. Художественные параметры Paper автоматически не копировать.
- Для Nuviko нужны экранные субтитры, включая длинные ролики; дополнительно отдельный SRT. Пользователь выбрал оформление субтитров; [эталон и параметры](VISUAL_PROFILE.md#субтитры-речи). Общий центр и низ как S01; длинная речь разбивается на последовательные однострочные cues без уменьшения шрифта. Анимация, timing и монтажные объекты ещё не реализованы.
- Для текущего исследования/подготовки пользователь прямо разрешил работать без Extra High; не переносить исключение автоматически на посторонние задачи.
