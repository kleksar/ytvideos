# Nuviko — полевой блокнот v02

Текущий комплект после замечания пользователя от 2 ноября 2026: нравится S01, не приняты смещение S02 и двухстрочный wrap. Каноническое правило и положительный PNG-эталон — [VISUAL_PROFILE](../VISUAL_PROFILE.md#экранный-текст--полевой-блокнот).

Сохранены оформление, шрифты, размеры, центр и низ плашки S01. Каждый cue — строго одна строка, x=836 и низ y=871 при native canvas 1672×941. Длинную речь показывать последовательными однострочными cues; не сжимать шрифт и не двигать субтитры вбок. S02 использует более короткие cues, чтобы центрированная плашка не закрывала ноги героя. Это статические примеры без длительности; настоящий timing нужно получить из речи и монтажа. Текст проб не является принятым narration.

Исходник — [style.json](style.json), renderer — [render.py](render.py), зависимости — [requirements.txt](requirements.txt). 21 отдельный RGBA PNG в `rendered/layers`, по три роли на каждый из семи cue-примеров. PNG полноформатные 1672×941, накладываются на исходную сцену с началом (0,0) при 100%; текст редактируется в JSON с повторным рендером. В Palmier ничего не импортировано. Фоны, прежний комплект и принятый S01 не изменены. Входные сцены — прежние style tests, историческая приёмка не выполнена.
