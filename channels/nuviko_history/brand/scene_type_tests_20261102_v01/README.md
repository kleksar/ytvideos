Точный принятый файл — `T02_fieldnotes_v01.png`; текущие правила и границы приёмки — [визуальный профиль](../VISUAL_PROFILE.md#экранный-текст--полевой-блокнот). Производство встроенным `image_gen`; полные запросы: [scenes](prompts.json), [typography](typography_prompts.json). Точные файлы, SHA-256, native geometry, происхождение и пределы авторской проверки — [manifest.json](manifest.json).

## Сцены

- [S01 — крупный план](S01_close_v01.png): путешественник справа, рисованное лицо и реалистичное окружение.
- [S02 — общий план](S02_wide_v01.png): путешественник целиком на форуме; в результате крупнее заданного в запросе.
- [S03 — мир без героя](S03_world_v01.png): интерьер пекарни, полностью реалистичная подача.

Образ сверялся с выбранным пользователем якорем, не с предыдущей новой генерацией. Полноформатные результаты просмотрены автором. Историческая точность каждого предмета и плана зданий не принята; это пробы художественной подачи. Геометрия хлеба/пекарни и точный форум требуют отдельной проверки при использовании в фильме. Независимого review нет.

## Три варианта титров на S02

1. [A — документальный](T01_documentary_v01.png): простой шрифт без засечек, белый текст, янтарное ключевое слово.
2. [B — полевой блокнот](T02_fieldnotes_v01.png): кремовые карточки, книжное оформление.
3. [C — кинематографический](T03_cinematic_v01.png): шрифт с засечками и сдержанные акценты.

Одинаковые три строки используются только для примерки. Эти три файла — растровые макеты, не готовые subtitle/caption assets; точный исходный шрифт, тайминг и анимация из них не установлены. Полноформатно проверены написание трёх строк и отсутствие перекрытия лица/ног. Изменение пикселей фона при генеративном редактировании не исключено. После выбора B отдельно выполнена [реальная реализация слоёв v01](../fieldnotes_kit_v01/README.md): детерминированные прозрачные PNG на неизменённых S01/S02/S03, с авторской проверкой полных кадров и уменьшений 390×219. Новый комплект не заменяет исходные эталоны.

Запрошено 3840×2160/16:9/highest quality. Фактически все шесть PNG — **1672×941**, без апскейла, растягивания или кадрирования; встроенный инструмент не предоставляет здесь size/quality controls. Это не нативный 4K. Импорта, движения, звука, видеоэкспорта и публикации не было. B имеет статус **USER_APPROVED_STYLE_REFERENCE** в пределах направления титров. Остальные файлы остаются **DRAFT_FOR_USER_STYLE_REVIEW**. Реальные шрифты/слои/тайминг и историческая приёмка сцен этим выбором не подтверждены.
