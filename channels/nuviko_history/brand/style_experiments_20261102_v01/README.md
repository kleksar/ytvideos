# Nuviko — десять проб стиля

Статус: пользователь выбрал приложенный кадр, совпадающий по декодированным RGB-пикселям с пробой 05, под названием «Сдержанная рисованная подача». Актуальный якорь и границы приёмки — [визуальный профиль](../VISUAL_PROFILE.md). Один герой и близкая римская сцена позволяют сравнить стилизацию; фон не идентичен по пикселям. Реальные размеры — в manifest.json. Все изображения созданы встроенным image_gen; полные запросы — prompts.json.
