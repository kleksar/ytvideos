# Дополнительное плавное движение

`dynamic_recut_keyframes_1107_v1.json` — необязательная анимация для карты `dynamic_recut_palmier_ready_review_intro_offset_1107.csv` с SHA-256 `b3e5f621677287a81386b534a20cd49712c4e80c28b22bd04560d1dcc3a9e8a2`. Если карта изменится, файл движения нужно пересоздать и заново проверить: ключи относятся к номерам клипов в конкретной версии CSV.

Для 166 клипов задана анимация `scale` от 1.02 до 1.04 или обратно, с чередованием направления. Первый ключ находится на нулевом кадре клипа, последний — на `duration_frames − 1`, интерполяция `smooth`. На границе соседних клипов числовые значения масштаба совпадают; при смене самих изображений это не гарантирует визуальной непрерывности.

По схеме Palmier ширина и высота `scale` заданы в нормализованных координатах холста, а не коэффициентом масштаба. Изображения текущей карты имеют размер 1672×941, близкий к 16:9; небольшой запас 2% предусмотрен для заполнения кадра. Положение точки масштабирования, заполнение края и итоговое кадрирование без тестового применения и просмотра не подтверждены. Перед полной сборкой обязательно проверить тестовую копию, особенно края, лица и стыки: анимация ещё не применялась через MCP.

При использовании скрипта путь к этому JSON передаётся в `--keyframes` и для сухой проверки, и для записи. Проверенный dry-run фиксирует хеш файла и карты. Интро до 1107-го кадра файл не изменяет. Переходы файл не задаёт.
