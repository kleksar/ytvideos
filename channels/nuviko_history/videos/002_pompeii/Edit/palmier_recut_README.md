# Пакетная сборка динамической версии в Palmier

`palmier_recut.py` подготовлен для CSV `dynamic_recut_palmier_ready_review_intro_offset_1107.csv`. По умолчанию он ничего не меняет в Palmier: проверяет карту, изображения и открытый проект через локальный MCP-мост. Записывающий режим подготовлен, но **ещё не испытан**: результаты dry-run не подтверждают работоспособность импорта, копирования, вставки или анимации.

## Что проверяется

- CSV с заголовками `clip,start_frame,end_frame_exclusive,duration_frames,image_path,review`; номера идут подряд от 1, диапазоны `[start,end)` непрерывно покрывают кадры 1107–28291, длительности верны, файлы существуют в постоянном `Source/Storyboard`. Интро `[0,1107)` не перекрывается новой дорожкой. Формат — 1920×1080, 30 fps; длина 28292 кадра.
- `review` содержит пояснения к отдельным решениям и не является статусом `provisional`; они выводятся в сухом отчёте и требуют содержательной проверки. Если во входной карте есть дополнительный столбец `status`, он должен содержать `available` или `provisional`. При `provisional` запись блокируется до подключения. Само название файла и отсутствие `provisional` не заменяют проверку содержания.
- Активный и видимый проект — ожидаемый `.palmier`; активный таймлайн совпадает с переданным ID; настройки холста и длина проверяются. Проверяется одна Voice: исходный рассказ `CEC13D41` на `[1107,28292)`, а предшествующие аудиоклипы целиком лежат в интро. Структура интро не зафиксирована в коде: сухой отчёт сохраняет фактические клипы и свойства, а запись требует сверить их с предварительно просмотренным отчётом. Идентификаторы нужно заново проверять перед запуском: имена таймлайнов могут повторяться.
- Новая дорожка расположится поверх существующего изображения. Если в основной части обнаружены текст, группы субтитров или более одной видеодорожки с клипами, скрипт откажется продолжать: иначе новая картинка могла бы скрыть нужные слои. Обходить эту защиту без отдельного решения о порядке дорожек нельзя. Титр интро `[975,1107)` новой дорожкой не перекрывается.
- Скрипт берёт хеши CSV, изображений и, при наличии, карты анимации. В режиме записи он повторно проверяет файлы при импорте, а после каждого пакета сравнивает все клипы новой видеодорожки с ожидаемой картой и проверяет Voice. Это структурная проверка, а не просмотр фильма.

## Проверка без изменения проекта

Закройте параллельные операции монтажа и, находясь в нужном активном таймлайне, сначала прочитайте актуальное состояние:

```sh
python3 /Users/diplomat/ytvideos/automation/palmier/inspect_connection.py
python3 /Users/diplomat/ytvideos/channels/nuviko_history/videos/002_pompeii/Edit/palmier_recut.py --source-timeline-id ID_ИЗ_ПРОВЕРКИ
```

Последняя команда выводит JSON с количеством планов, замечаниями `review`, хешами исходников и снимком Voice. После завершения чужих операций сохраните новый сухой отчёт в файл вне `.palmier` и проверьте его; запись принимает его через обязательный `--voice-manifest` и отклоняет изменения карты, изображений, анимации или Voice. Если используете исправленную карту, передайте `--map /абсолютный/путь.csv`. Неизвестно, не ограничивает ли мост размер вызова, поэтому первая партия по умолчанию составляет 10 клипов.

## Что делает режим записи

После полного успешного preflight и явного флага `--execute` скрипт создаёт **копию** активной последовательности штатным `create_timeline(from=ID)` и делает её активной. Сравнивает копию с источником, затем импортирует каждый уникальный файл по абсолютному пути в отдельную библиотечную папку `Stories/002/Edit/DynamicRecutImports/<идентификатор запуска>` и создаёт поверх старого видеотрека копии новую видеодорожку, размещая кадры партиями. Исходный видеотрек на копии остаётся под ней, оригинальная последовательность не удаляется и не перезаписывается. Изображения импортируются по ссылке на файлы, поэтому эти файлы нельзя перемещать или удалять. Импорт создаёт отдельные элементы библиотеки даже для уже импортированных файлов.

Только после подготовки и проверки готовой карты команда выглядит так:

```sh
python3 /Users/diplomat/ytvideos/channels/nuviko_history/videos/002_pompeii/Edit/palmier_recut.py --source-timeline-id ID_ИЗ_ПРОВЕРКИ --map /абсолютный/путь/утверждённая_карта.csv --voice-manifest /абсолютный/путь/проверенный_dry_run.json --batch-size 1 --execute
```

Для первого испытания добавьте `--test-first-batch --batch-size 2`: скрипт создаст копию, импортирует только изображения первой партии, вставит два клипа и остановится после проверки, пометив результат как неполный. Проверить эти клипы и звук в Palmier вручную. Продолжать эту копию автоматически скрипт не умеет; последующий полный запуск создаст новую копию. Без `--test-first-batch` команда не делает пауз после партий. Не считать код проверенным на запись, пока испытание не проведено.

Каждый запуск создаёт `Edit/palmier_recut_logs/<UTC_ID>/journal.jsonl`: перед вызовом записывается намерение, затем ответ и результаты проверок; финальный снимок успешного монтажа — `final_timeline.json`. При остановке копия и импортированные медиа могут остаться частично собранными. При ошибке или таймауте **не повторять вызов вслепую**: прочитать журнал, активный ID, медиатеку и таймлайн; попытка могла уже завершиться на стороне Palmier. Скрипт не умеет автоматически продолжать частичный запуск или откатывать операции.

## Дополнительные движения

Необязательный `--keyframes /абсолютный/путь.json`: объект, ключи которого — номера строк CSV; вложенные свойства — свойства Palmier `scale`, `position`, `crop`, `rotation`, `opacity`, `blur`. Пример:

```json
{
  "1": {"scale": [[0, 1.04, 1.04, "smooth"], [153, 1.08, 1.08, "smooth"]]}
}
```

Смещения относятся к началу клипа и должны быть меньше его длительности. Для `scale` значения — нормализованные ширина и высота, а не множитель; для `position` — координаты верхнего левого угла. Скрипт принимает минимум два различных значения на свойство и останавливается, если повторное чтение не подтверждает записанные ключи. Инструмент `set_keyframes` перезаписывает всю анимацию соответствующего свойства клипа. Между клипами автоматические переходы этот скрипт не создаёт.

Перед запуском убедитесь, что никто не управляет Palmier одновременно: проверки состояния — снимки, а не блокировка. Скрипт не обеспечивает атомарность между проверкой и записью. После записи требуется инспекция композиции в начале, на стыках и в конце, проверка слоёв и полного звучания Voice, отсутствие чёрных кадров, содержательная синхронизация и просмотр движения. Экспорт скрипт не выполняет. Схемы MCP могут измениться; перед реальным запуском проверьте текущую версию инструментов. Не редактируйте файлы внутри `.palmier` напрямую.
