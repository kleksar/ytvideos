Therefore no native experiment was launched or claimed. The three pairs are alternatives for the user to select from. Desktop Studio currently supports custom Shorts covers for verified accounts, subject to the actual target account/interface: [Add custom thumbnails](https://support.google.com/youtube/answer/72431?hl=en).
