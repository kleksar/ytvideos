## Full descriptions

### A

Voyager 1 was still reaching Earth by radio, but the information coming back could no longer be read. The spacecraft was about 24 billion kilometers away, so every repair attempt meant waiting almost two days for a reply. Engineers traced the problem to damaged memory, moved the needed program into working space, and rewrote its references. First, the spacecraft's systems report became readable. Then science data returned from all four working instruments.

### B

How do you repair a spacecraft when it is billions of kilometers away and no free memory block is large enough for the software it needs? Voyager 1's engineers split the program into pieces, placed them in working memory, and changed the references so the computer could find every part again. The first readable report came back in April 2024. By June, science data was returning from all four instruments still operating on the spacecraft.

### C

A command to Voyager 1 took about 22 and a half hours to arrive. Its answer took about the same time to return. That meant engineers had to wait almost two days to learn whether each attempt worked. The delay made a delicate software repair even harder: they had to bypass damaged memory and reconnect a program spread across several locations. The fix worked, and Voyager 1 resumed sending engineering and scientific data.
