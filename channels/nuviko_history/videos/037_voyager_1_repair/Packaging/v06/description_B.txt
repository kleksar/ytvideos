How do you reroute a program inside a spacecraft billions of kilometers away and no free memory block is large enough for the software it needs? Voyager 1's engineers split the program into pieces, placed them in working memory, and changed the references so the computer could find every part again. The first readable report came back in April 2024. By June, science data was returning from all four instruments still operating on the spacecraft.
