Visual score · narration EN v01 · 16:9

One complete static full-frame composition per scene; no internal animation or parallax. Direct cuts. Preliminary rhythm 4–6 seconds per image; set exact duration to actual narration timing. Type: **R** reconstruction, **G** explanatory graphic/conceptual space visualization, **H** Nuviko host. Scene quote markers below identify continuous narration spans; no words between markers are omitted.

## Visual system and continuity

- Space: dark blue and near-black, restrained edge light; one consistent Voyager model, varying only screen scale and position.
- Earth scenes: anonymized modern engineering workspaces, hands, silhouettes, monitors without readable invented interfaces; no specific NASA/JPL setting, logos, or people.
- Graphics: conceptual distance, delay, memory damage and program relocation; never depict real Voyager telemetry, code, address maps or chip geometry.
- Nuviko: illustrated traveler from the approved character sheet (ochre jacket, light henley shirt, backpack, graying chestnut hair, short beard), in a separate explanatory space, scenes 01, 09 and 31 only. Never inside Voyager or among mission engineers.
- Communication schematics keep Earth left and Voyager right; only signal direction changes. The damaged memory area stays visibly damaged from scene 27 through the ending; only program placement and references change.
- April 20 restores readable spacecraft-status information. June brings data from the four instruments still operating then. Do not conflate these outcomes.

## Key cuts and image-generation risks

- 04→05: cosmic emptiness to Earth; 06→07→08: signal exists, command path works, content cannot be read; 17→18→19: outbound delay, return delay, wait.
- 24→25→26: decode, memory contents, compare; 27→28: damage amount to its program consequence; 32→33→34: small free regions, oversized fragment, split code; 35→36→37: old links, corrected links, coherent program.
- 42→43→44: outgoing fix, long return, readable response; 44→46→47→48: readable message, recovered status, science task, four instruments; 50→51→52: workaround, spacecraft age, continued data.
- Prohibit invented spacecraft internals, exposed boards, chip geometry, memory addresses/layout/counts, fake dumps/code/interfaces, fabricated mission-control locations/people/logos, false-to-scale distance/heliosphere maps, physical repair depiction, false claim of science recovery on April 20, or host appearing as an event participant.
- Vary scale, angle, object and visual type; no repeated monitor shots or interchangeable Voyager views. Static full frame per scene; if later motion is used, move the whole image only.
