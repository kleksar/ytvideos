# Nuviko History 038: Guy Fawkes

Статус, действующие разрешения, версии и следующий результат — в [CURRENT_CONTEXT.md](CURRENT_CONTEXT.md). Канал и формат подтверждены прямым поручением пользователя 4 ноября 2026 года; это конкретное исключение из заморозки Nuviko.

- `Source/Script/` — принятый русский сюжет и английская производственная версия.
- `Source/Research/` — консультации и внутренняя фиксация доказательств/ограничений.
- `Storyboard/` — постановка полного фильма по профилю Nuviko.
- `Source/Images/` — сценовые изображения; `Source/Voice/` — разрешённая озвучка.
- `Assets/Generated/` — производные для монтажа; `Work/<run>/` — временные попытки.
- `Edit/` — планы, журналы и манифесты; `Deliverables/` — принятый комплект и видео для просмотра.
- `Packaging/` — метаданные и обложки после контрольной точки MP4.

Для производства применять общий `ytv-video-production`, Nuviko visual profile и применимые audio, storyboard, images, subtitles, motion, export, QA, packaging и lifecycle skills. Создание звука разрешено только в scope этого полного производства; внешняя публикация требует этапов и решений общего flow.
