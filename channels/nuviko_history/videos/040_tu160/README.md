# 040 — Ту-160

Длинный фильм Nuviko History. Сюжет принят пользователем; это прямое исключение для данного выпуска из текущей заморозки канала. Пользователь разрешил автономное производство, включая озвучку, и ожидает MP4 на просмотр.

Публичный язык — английский по общему flow. Принятый русский сюжет хранится дословно; английская версия является производственной языковой адаптацией без переписывания принятых событий.
