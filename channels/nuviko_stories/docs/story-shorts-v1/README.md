# Истории для вертикальных роликов — рабочий стандарт v1

Документация составлена по совместной редактуре ролика № 1, 28 октября 2026 года. Это **воспроизводимый ориентир**, а не команда автоматически повторять те же слова, кадры или длительности. Для следующей истории сначала слушаем новый голос и смотрим новый материал, затем применяем правила.

Текущая договорённость: пользователь присылает историю/текст; ассистент готовит отдельные RU и EN версии, озвучку, титры, переменный порядок пригодного отсмотренного видеоряда, монтаж, рендер и приватную загрузку на соответствующие каналы с метаданными и плейлистом. Отдельно разрешать рендер для каждого обычного выпуска не нужно. Сквозная автоматизация пока не подтверждена; фактическое состояние и ограничения см. в [журнале производства](../../../../automation/README.md).

Английский текст: 350 слов, 147 последовательных титров без внутренних пауз; не более 3 слов в строке, единый размер шрифта. Английский мастер обновлён до v5; см. состояние и экспорт в `CASE_002_EN.md`. Оба текста сохраняются отдельно и не подменяются автоматически ASR.
- В новых версиях титр содержит не более 3 слов в одной строке и использует единый базовый кегль. У `1_ru` остались две исторические четырёхсловные строки; их не переносить в будущие проекты. Группировки конкретных выпусков и правила зафиксированы в [CAPTIONS.md](CAPTIONS.md) и CASE-файлах.
- Белые слова остаются неподвижными; только звучащее слово выделено тёплым жёлтым и плавно увеличивается на 5%. В русских титрах знаков препинания нет, кроме дефисов внутри слов. В английской версии сохраняются апострофы в сокращениях/притяжательных формах и орфографический дефис, поскольку они меняют написание и смысл.
