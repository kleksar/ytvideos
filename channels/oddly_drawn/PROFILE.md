# Oddly Drawn

Англоязычный канал с whiteboard-подачей: человек рисует и рассказывает историю через рисунки. Это рефакторинг Two Ways Lab, не шестая identity. Актуальный [ChannelSpec](../two_ways_lab/channel.json) сохраняет machine key `two_ways_lab` и YouTube ID `UCcZWXzkL_K1mD5dr8MZBYrQ`; [проверка identity](docs/IDENTITY.md). Во всех CLI-командах для нового run использовать `--channel two_ways_lab`; директория `oddly_drawn` хранит бренд и требования, отдельного CLI alias нет.

## Рассказчик и рисунок

- Рассказчик — человек, который рисует и рассказывает историю через рисунки. Рисунок помогает следить за событиями и понимать объяснение.
- Детектив не является постоянной ролью рассказчика или обязательным стилем канала. Не превращать каждый сюжет в расследование и не добавлять детектива по умолчанию. Этот приём допустим для отдельного подходящего сюжета.
- Первое лицо участника не обязательно: рассказчик не должен утверждать, что сам пережил события. Лицо повествования выбирается по истории и достоверности; «я рисую/показываю» допустимо, когда соответствует действию.
- Сравнение A/B, эксперимент с одинаковыми условиями и измеримый победитель не являются обязательной структурой. Они допустимы, когда нужны конкретной истории. Старый backlog не является очередью новых обязательных тем.
- Прежний герой Two Ways Lab, его внешность, одежда и character sheets не задают личность нового рассказчика. Подтверждённого нового model sheet пока нет; необходимость видимого человека и его точный reference решаются до зависимой генерации.

Общие требования к фактам и драматургии — [editorial](../../docs/standards/editorial.md), к живой речи — [narration](../../docs/standards/narration.md). Формат рассказчика не задаёт новый голос, хронометраж или техническую схему генерации. Для Short сохраняется общая смысловая петля; техническая реализация начала и возврата требует отдельного определённого recipe.

## Runtime и совместимость

`status: active` разрешает сохранить run и выполнить независимую редакционную работу; shared `illustrated` задаёт task graph, а не готовый whiteboard adapter. Доставка, голос, титры и provider recipe пока имеют [явные blockers](docs/PRODUCTION.md). Не переносить старые 1080×1920/30 fps, Trebuchet, ElevenLabs voice, героя или монтаж автоматически. `profiles` сообщает `configuration_ready: false`, live readiness остаётся unverified.

Старые episodes, brand assets, публикационная история и pins сохранены; [migration](../../docs/migration.md#two-ways-lab--oddly-drawn). Existing run продолжать по закреплённому packet. Этот профиль не разрешает менять внешний YouTube, permissions, опубликованные видео или календарь.
