# Общие медиа Paper Detour

Для новых сцен и монтажей начните с [общего каталога медиа проекта](../../../.agent/ASSET_LIBRARY.md). Принятые настройки каждого материала указаны в README его папки.

- [Film Grain](Overlays/Film_Grain/README.md): принятый портретный цикл и отдельный старый ландшафтный источник.
- [CRT Ripple](Overlays/CRT_Ripple/README.md): пользовательский эксперимент ожидает результата; сохранить все исходники и мастера до следующего решения.
- [Paper references](References/Paper): общие визуальные эталоны с сохранённой provenance в исходных выпусках.

Перед повторным использованием проверяйте конкретный выпуск и назначение материала. Общая папка не делает все её файлы взаимозаменяемыми.
