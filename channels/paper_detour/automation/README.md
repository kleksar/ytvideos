# Paper Detour — помощники и сборка

Текущая сборка видео выполняется только через общий [FFmpeg montage](../../../automation/ffmpeg_montage/README.md) по [правилам канала](../AGENTS.md) и каноническому [production skill](../../../.agents/skills/ytv-video-production/SKILL.md). Выпуск собирается из проверенного плана, выбранного профиля доставки и доступных входов. Здесь нет второго монтажного workflow.

`init_episode.py` подготавливает каталог нового выпуска; перед `--create` проверь ID и slug. Команда создаёт структуру, но не рендерит, не синтезирует звук и не публикует. После инициализации зарегистрируй выпуск согласно [bootstrap](../../../.agent/CHANNEL_BOOTSTRAP.md).

`make_narration_srt.py` формирует черновую английскую SRT из alignment и текста. Проверь слова, тайминг, обрезки и звучание перед включением субтитров в FFmpeg-сборку.

Остальные вспомогательные скрипты не определяют текущий процесс сами по себе: используй только те, на которые ссылаются действующие skill и монтажный контракт. Исторические материалы готовых выпусков сохраняются у выпуска и не служат инструкциями для новых работ.
