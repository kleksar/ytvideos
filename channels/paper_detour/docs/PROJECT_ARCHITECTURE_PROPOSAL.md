# Архитектура Paper production

Paper использует [общую архитектуру](../../../docs/architecture.md), [workflow](../../../docs/workflow.md) и собственный [PROFILE](../PROFILE.md). Отдельной Paper state machine, registry bootstrap или ручного создания episode папок нет.

Фактические старые проекты/receipts сохраняются и переносятся по [migration](../../../docs/migration.md). Наличие этого документа не подтверждает завершённую миграцию активного выпуска.
