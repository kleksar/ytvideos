## Как проверено

Свежий API подтвердил авторизованный канал, принадлежность и Public всех трёх точных video ID. В актуальной публичной discovery-схеме YouTube Data API v3 поля/метода конечных заставок не обнаружено; для их чтения использован штатный редактор Studio.

У каждого фильма открыта форма «Конечные заставки». Проверка выполнена после завершения загрузки формы и появления видеопревью/звуковой волны. Интерфейс показывает галерею шаблонов и пустую дорожку элементов; фактические скриншоты просмотрены. Шаблоны «1 видео, 1 кнопка Подписаться» в галерее не означают, что такой шаблон уже применён. «Сохранить» во всех трёх формах отключено.

Формы закрыты через «Отменить изменения», последний экран сведений также показывает отключённое сохранение. Элементы не добавлялись, настройки видео, доступ и A/B-тесты не менялись. Проверка была read-only.

## Предложенный следующий шаг

Добавить на каждый фильм **одну рекомендацию другого открытого длинного фильма Paper и кнопку «Подписаться»**. Точную цель, интервал и расположение выбрать в следующем этапе с просмотром последних кадров, чтобы сохранить читаемость финального рассказа и субтитров. Изменять или перезагружать сам MP4 для штатной заставки не требуется.

По [официальной справке YouTube](https://support.google.com/youtube/answer/6388789?hl=en) конечные заставки размещаются в последних 5–20 секундах; доступны видео, плейлист и подписка. Конкретные интервалы и позиции для этих трёх фильмов пока не приняты. Добавление не выполнялось в этой проверке.
