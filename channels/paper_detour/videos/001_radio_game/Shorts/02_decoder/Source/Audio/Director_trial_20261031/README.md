# Short 02 — аудио для режиссёрской пробы, 31 октября 2026

Рабочие исходники для нового пробного монтажа, не утверждённый финальный микс. Длина выбранного монтажа — 36,6 секунды (1098 кадров при 30 fps). Голос заканчивается через 35,585510 с; оставшееся время звучит музыка. Все файлы ниже созданы в отдельной новой папке, исходники не перемещались и не перезаписывались.

## Файлы для монтажа

- `preview_mix_36p6_no_sfx_stereo.wav` — голос и музыка, **без эффектов**, PCM 24-bit stereo 44,1 кГц, 36,600000 с. Голос уже ускорен 1,05×; размещать готовый микс с начала таймлайна на 1×, не ускорять повторно и не добавлять второй раз исходный голос или музыку.
- `narration_105_draft.en.srt` — 20 английских реплик; границы машинной разметки прежнего SRT разделены на 1,05 и округлены до миллисекунды. Не вшивать автоматически: файл для отдельной дорожки; сверить с фактической речью на слух. Текст совпадает с исходным SRT и `narration_pro_v2.txt`.
- `voice_105_gain-1dB.wav` — отдельная монофоническая дорожка для возможной пересборки. PCM 24-bit 44,1 кГц, 35,585510 с; `atempo=1.05` применён один раз, затем уровень уменьшен на 1 dB. Исходный MP3 уже сжат до 128 кбит/с; преобразование в PCM не восстанавливает его качество.
- `music_excerpt_36p6.wav` — отдельная музыкальная дорожка, PCM 24-bit stereo 44,1 кГц, ровно 36,6 с. У неё короткие вход и выход; хранится для пересборки.

## Точный рецепт

1. Голос — `Shorts/02_decoder/Source/Voice/pro_v2/voice_en.mp3`, SHA-256 `a688a8904b3d1eb2379889a1f8343747c429ed6d991ccc484b659e57b395f3f3`. FFmpeg: `atempo=1.05,volume=-1dB`, вывод PCM 24-bit mono 44,1 кГц. Скорость 1,05× выбрана для этой пробы по заданию координатора.
2. Музыка — `Source/Audio/paper_sound_design/music_bed_56s_synth_stereo.wav`, SHA-256 `e9be6c968f2a27582061ac84fb6b54a4405b956b825b9e8c03b24dab9ae1621a`. Взяты секунды [3,0; 39,6), преобразован формат в PCM 24-bit, применены фейды 0,2 с в начале и 0,2 с в конце. Уровень подложки дополнительно не менялся. По её README музыка синтезирована в проекте без внешних сэмплов; субъективная пригодность ещё не оценена.
3. Голос продлён цифровой тишиной до 36,6 с, подан одинаково в левый и правый каналы и сложен со стереомузыкой через `amix=inputs=2:duration=longest:dropout_transition=0:normalize=0`. Нормализация, лимитер и SFX не добавлялись. При добавлении SFX заново проверить весь микс и пики; не считать фон музыки автоматическим доказательством слышимого сопровождения акцентного текста.
4. SRT — из `Shorts/02_decoder/Source/Voice/pro_v2/voice_en.draft.srt`, SHA-256 `1cc12fd28ef4989678986922529f883402f352ac66a0567b5f77fe19568fe059`. Деление времён — математическая оценка: фактическая длительность обработки `atempo` может немного отличаться от простого деления, паузы и произношение нужно проверить на слух.

## Техническая проверка и ограничения

`ffprobe` подтвердил длительности и параметры; полное декодирование рабочего микса с `ffmpeg -xerror` прошло без ошибок. `ebur128=peak=true` измерил −21,1 LUFS integrated и −3,8 dBTP true peak. Последняя реплика SRT заканчивается на 35,352 с, то есть внутри аудио. Измерения не подтверждают субъективную громкость, разборчивость, произношение имён или синхронизацию. Полное прослушивание и проверка с изображением не выполнены.
