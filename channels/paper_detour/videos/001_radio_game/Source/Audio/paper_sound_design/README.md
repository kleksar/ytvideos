# Рабочие синтетические звуки для бумажного монтажа

30 октября 2026. Эти рабочие заготовки созданы программой `generate_sounds.py` математическими осцилляторами и шумом; внешние записи, семплы и музыкальные произведения не использовались. Это не архивная запись и не установленное звучание оригинальной передачи. Текущий трёхсекундный `signal_reconstruction_3s.wav` — отдельный ранее подготовленный файл, его не заменяли.

| Файл | Продолжительность | Что это | RMS / пик |
|---|---:|---|---:|
| `music_bed_56s_synth_stereo.wav` | 56,0 с | Ненавязчивая синтезаторная подложка | −37,5 / −25,2 dBFS |
| `sfx_button_click_synth.wav` | 0,56 с | Искусственный щелчок кнопки | −33,2 / −11,6 dBFS |
| `sfx_tape_motor_synth_5s.wav` | 5,0 с | Искусственный звук механизма | −26,7 / −16,9 dBFS |
| `sfx_radio_search_synth_1_8s.wav` | 1,8 с | Искусственный звук настройки радио | −28,9 / −21,0 dBFS |

Все файлы PCM 16-bit stereo 44,1 кГц. Измерения вычислены по выборкам; исходный `voice_en.wav` имеет средний уровень около −24,2 dBFS и пик −1,8 dBFS. Баланс, художественная пригодность и стыки на слух не проверялись. Щелчок имеет высокий пик, поэтому перед смешиванием его нужно ослабить и проверять суммарные пики. Для подложки при повторении нужны аккуратные фейды и дополнительная редактура, чтобы не создать заметный цикл. Не считать эти файлы завершённым миксом.
