# IQ Gallery v18 — один человек в каждой сцене

Дата: 1 ноября 2026  
Статус: готово; MP4 экспортирован и проверен по указанным ниже выборкам.

## Указание пользователя

Пользователь отклонил прежнюю карточку JFK с приветствующей толпой: зритель должен видеть прежде всего конкретного человека. Попросил переделать весь минутный ролик, например показать JFK в Белом доме. Имена, порядок, IQ-значения и длительность сохранены из принятой версии v17.

## Постановка

Координатор лично выполнил два отдельных последовательных творческих прохода на ChatGPT.com в Google Chrome, внутри проекта «YT Видео», чат «Драматургический каркас Shorts» ([чат](https://chatgpt.com/g/g-p-6ae147d3975777d0-yt-video/c/6ae74b79-d8d0-83eb-8e7f-7d2ab9ea2de0)). Перед обоими запросами видимая маркировка модели была `Extra High`.

1. Первая задача: предложить по одной конкретной персональной композиции для всех 13 карточек, сохранив тайминг v17 и оставив чистую нижнюю область под титр.
2. Вторая задача: превратить эти 13 решений в отдельные английские ImageGen prompts для цельных бумажных сцен без текста; результат и исполненные prompts сохранены в [`automated_workflow/IQ_GALLERY_IMAGEGEN_PROMPTS_V18_20261101.md`](automated_workflow/IQ_GALLERY_IMAGEGEN_PROMPTS_V18_20261101.md).

Для всех кадров использован точный одобренный стилевой файл Paper Detour 004: `channels/paper_detour/videos/004_last_video/Storyboard/user_reference_parallax_20261101.png`. Индивидуальный кадр v17 каждого персонажа использовался только как ориентир лица/узнаваемости. В каждом итоговом кадре один человек, без людей в отражениях или изображениях. Обстановка подобрана под персонажа, но визуальный фокус остаётся на нём.
