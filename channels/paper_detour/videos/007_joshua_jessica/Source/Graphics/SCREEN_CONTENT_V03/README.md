# Screen-content assets v03

Registered, transparent screen-state PNGs for the Paper Detour 007 Short. Each overlay is a full-canvas 941×1672 RGBA image. P01/P14 share identical artwork for the loop. P05 keeps the existing blank paper card in FG; the three-second first-exchange composition is an intentional static reading hold, and its text sits on the card. P04’s two editorial identifiers are a separate overlay registered to the paper cards and must follow FG motion. P09 has no screen overlay because the rear of the laptop lid faces the camera.

Typography inside the display is purpose-fit editorial UI lettering; it is not presented as a verified application screenshot. Existing checked paper PNGs are reused for the JESSICA and 55% accents. Exact readable text is limited to `JESSICA`, `Jessica?`, the verified closing fragment `I will be here waiting for you.`, `RESOURCE`, `55%`, `REMAINING`, `THIS VERSION`, `PROJECT DECEMBER`, and `GPT-3`; all other message fragments are intentionally unreadable.

Full masters in `Storyboard/ScreenMasters_v03/` were composited from the actual zero-offset BG/MG/FG package plus the registered overlays; P05 reflects the timeline’s fixed −11 px MG framing. They are the visual targets for this screen correction. Before import, compare each static overlay composite to its matching master; all text remains on the relevant screen or card plane.
