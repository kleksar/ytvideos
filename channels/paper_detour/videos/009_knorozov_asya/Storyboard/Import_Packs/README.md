# Быстрый импорт слоёв

Здесь 9 папок кадров. Для каждой папки импортируйте `BG.png`, `MG.png`, `FG.png` вместе в один монтажный кадр и расположите в таком порядке. Каждый PNG — 941×1672 px; у MG/FG прозрачный фон. Меняйте кадр примерно каждые 3–6 секунд. Внутри каждого кадра все три плана движутся в одну сторону с разной скоростью: BG медленно, MG быстрее, FG быстрее всех (ориентир по смещению 1:2:3). Не анимируйте отдельные части фигур. Реплики, акценты и направления движения: [`../IMPORT_MAP.md`](../IMPORT_MAP.md).

Для сцены 04 `PAGE_SOURCE_REFERENCE.jpg` — отдельный источник страницы Дрезденского кодекса. Его не обязательно использовать; при использовании совместите перспективу с чистым листом из `MG.png`.
