# Minnie Freeman — archived image workflow v03

> **Архив workflow, 1 ноября 2026.** Текущий сюжет 027 — история Минни Фримен. Для актуальной визуальной версии Paper Detour использовать одну цельную полноформатную картинку на сцену и прямые склейки. Описанный ниже master-first/слойный метод не является текущим форматом; эта папка не содержит готовых активных кадров для нового монтажа.

## Историческое описание (заменено)

Каждый кадр выпуска начинается с полного изображения того, каким зритель должен увидеть итоговый план. Master фиксируется до создания слоёв. Только после этого отдельно готовятся BG, MG и FG, все на одинаковом холсте и зарегистрированные с master. В монтажке эти три плоскости накладываются и получают предусмотренное горизонтальное движение.

Порядок проверки:

1. Просмотреть и утвердить полный master для каждого плана.
2. Подготовить из того же master отдельные BG, MG и FG; сохранить масштабы, кадрирование, перспективу, свет, силуэты и контакты.
3. Наложить BG → MG → FG в нулевой позиции и сравнить результат с master.
4. Проверить небольшое горизонтальное разнесение в одном направлении, с возрастающей амплитудой BG → MG → FG.
5. Только после обеих проверок складывать тройку в `Import_Packs` и передавать на монтаж.

Если несовпадение заметно, комплект не импортируется. Переделывается слой или master, а не компенсируется независимым движением частей в монтажке.
