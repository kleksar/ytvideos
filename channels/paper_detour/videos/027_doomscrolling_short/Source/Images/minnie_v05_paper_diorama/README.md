# Minnie Freeman v05 — Paper Detour stills

This is the current ten-image set for Shorts 027. One file is one complete opaque 9:16 scene. The assembly uses direct cuts and reuses the exact S01 file at the end. Do not turn these images into BG/MG/FG layers, cutouts, masks, or parallax assets.

## References and process

- **Style reference:** `channels/paper_detour/videos/004_last_video/Storyboard/user_reference_parallax_20261101.png` — paper material, miniature depth, lighting, and shadows only.
- **Story references:** corresponding final scene files from `../minnie_v04_full_stills/` — scene content and continuity only. These earlier images are not current style references.
- **Character continuity:** the new S01 still was used as a paper-figure reference for subsequent images.
- **Creative prompt source:** ChatGPT project conversation [Промпты для ImageGen](https://chatgpt.com/g/g-p-6ae147d3975481919b5bfda6935777d0-yt-video/c/6ae731bf-7bdc-83ed-900e-17550b1a6bac). The visible model mode was **Extra High** when checked in Chrome. The approved scene prompts were used as content constraints; ImageGen produced each complete still.
- **Canvas:** each source is RGB PNG, 941×1672 px. Palmier fits each to the 1080×1920 timeline.

The previous `minnie_v04_full_stills` set read too much like realistic historical renders and was rejected as the current style. v05 was remade to emphasize tangible matte paper, fibers, visible cut edges, layered relief, and soft miniature contact shadows.
