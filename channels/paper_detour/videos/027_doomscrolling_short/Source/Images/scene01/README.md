**Решение координатора: обе версии окклюдера отклонены и не предназначены для монтажа.** v01 изменяет пальцы; v02 является производным изображением, полученным программной операцией над исходником, которая отдельно пользователем не запрашивалась. Пробы с этими версиями оставлены исключительно как история проверок, не как рабочие монтажные активы. Для дальнейшего поиска перекрытия можно рассмотреть имеющийся целый слой `character_v02.png`, если режиссура и фактическая монтажная проверка подтвердят читаемый результат.
