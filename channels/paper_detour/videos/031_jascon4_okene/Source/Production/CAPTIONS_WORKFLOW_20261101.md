## Канальный формат

Paper Detour использует короткие смысловые бумажные акценты внутри законченных диорам; постоянные субтитры не заменяют эту партитуру. Акцент выбирается по точным словам записи, сохраняет порядок раскрытия и не показывает будущую информацию. До импорта нужен cue sheet с точным trigger/end, сценой, временем из alignment, функцией, геометрией и проверкой каждой фактической пары «сцена + PNG» на полном кадре и в мобильном размере. Типографика требует один основной anchor, одинаковую видимую высоту букв, заранее проверенную альтернативную зону только при реальном столкновении и сохранение свободных лиц/улики. Детали — [cue-sheet workflow](../../../../../../.agents/skills/ytv-paper-storyboard/references/cue-sheet.md), [типографика](../../../../brand/TYPOGRAPHY_STANDARD.md), [правила Paper Detour](../../../../AGENTS.md).

## Способы Palmier

1. **SRT/WebVTT как полные субтитры.** Palmier принимает `.srt` и `.vtt` как subtitle asset. Импортированный файл можно разместить через `add_captions` с одним `subtitleMediaRef`; Palmier создаст caption clips по авторским таймкодам. По документации app API subtitle asset нельзя размещать через `add_clips`. В UI это можно импортировать в библиотеку и перетащить на таймлайн. Такой слой показывает весь текст на изображении и конфликтует с обычным визуальным правилом Paper; применять его только если пользователь действительно хочет полные видимые субтитры.
2. **Автоматические captions в Palmier.** `add_captions` может распознать речь на выбранной аудиодорожке и создать caption group. Можно указать `trackIndex`, язык для локального распознавания, `maxWords`, `maxCharacters`, `lines`, `maximumGapSeconds`, а также пресет/позицию/стиль. По умолчанию применяются чистые белые Helvetica captions внизу кадра. Palmier использует облачное распознавание, если для ещё не закэшированного запроса хватает кредитов; иначе — локальное. Для этого проекта автоматическая транскрипция может исказить имена и добавляет нечитаемый без проверки риск расхождения с текущей английской речью. Генерацию не запускали.
3. **Избирательные бумажные акценты.** После выбора содержания создать отдельные короткие PNG по Paper cue sheet, примерить каждый PNG на все фактические сцены, проверить safe zone Shorts и отсутствие перекрытий. Затем сделать копию v02 как следующую версию, положить cue на отдельную верхнюю дорожку и выполнить принятую синхронизацию. Полный путь акцентов — не команда автоматической транскрипции.
4. **Оба слоя.** Для доступности подготовить отдельный SRT/WebVTT-файл как sidecar, для изображения — только принятые выборочные бумажные акценты. Не импортировать sidecar в текущий таймлайн, если пользователь не хочет, чтобы весь текст отображался поверх диорам.

В актуальной документации Palmier разделены text clips, generated captions и импорт subtitle files: [Text, transcription, and captions](https://www.palmier.io/docs/text-and-captions). При импорте в таймлайн текст и авторские времена файла сохраняются; пересекающиеся cue обрезаются, чтобы клипы не накладывались на одной дорожке.

- Рекомендация Extra High: вариант 3 — отдельный SRT/WebVTT для доступности плюс выборочные бумажные акценты. Полные встроенные субтитры доступны без звука, но перегружают композицию, конкурируют с диорамами и нарушают правило канала. Только акценты сохраняют стиль, но не передают всю речь.

| Вариант | Плюсы | Минусы |
|---|---|---|
| Полные вшитые субтитры | Понятно без звука; текст всегда виден | Перегружают кадр и противоречат визуальному правилу Paper |
| Выборочные акценты | Сохраняют стиль и усиливают смысловые моменты | Не передают всю речь и не дают полной субтитровой доступности |
| Отдельный SRT/WebVTT + акценты | Доступность без перегруза диорам; сохраняется авторская подача | Нужно отдельно подготовить SRT/WebVTT |
