## Full-scene coverage audit

The Extra High review concluded that S01 and S16 are sufficient and found no missing third accent. The no-text scenes have distinct visual functions:

- **S02–S05:** war context → carrier → port arrival → shore leave in batches; changing compositions form a continuous visual explanation.
- **S06:** a short context pause before the separately reported Pattaya events.
- **S07–S09:** the detention report, mayor's separate denial, and visit-related patrols remain distinct; no overlay avoids implying a causal connection.
- **S10–S12:** a continuous rules-and-access block, carried by the scene's map/document labels and open street view.
- **S13–S15:** presentation, biography, and first half of the quote reduce visual text load before the S16 resolution.
- **S17 → S01:** clean exact image return; the no-text ending lets the spoken unfinished clause carry the loop.

The long run without a semantic overlay (S02–S15) is accepted at this planning stage because each scene advances a new visual beat, with changes in scale, location, documents and subject. This is not a synchronization or retention finding; re-evaluate only if the actual voice/edit reveals a comprehension gap.
