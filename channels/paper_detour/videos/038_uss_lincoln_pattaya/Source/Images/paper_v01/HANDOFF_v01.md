## Measured file and delivery properties

- All 16 selected unique files are PNG, 941×1672 pixels, and report `hasAlpha: no`; each fills all four edges with an opaque paper scene.
- Native source aspect is 941:1672 (about 0.5628); delivery is 1080:1920 (0.5625). Proportional fill is approximately 1.148× with a negligible subpixel-width crop and no padding or stretch.
- Requested 4K target was present only in the text prompt. The built-in tool returned the smaller native dimensions above. The project-bound files therefore remain 941×1672 and do not become native Full HD through scaling.
- **Coordinator quality decision:** keep the selected set for a phone-first Full HD Short with the approximately 1.148× proportional upscale. The visible paper detail, shapes and labels remain legible at the actual native source view; no sharpening or grain was added. Reassess if later crop, zoom, delivery geometry or title/cover use changes.
- Final-frame color conversion, actual video crop, subtitles, caption motion, Palmier timeline integration and final-video QA have not been evaluated here.
