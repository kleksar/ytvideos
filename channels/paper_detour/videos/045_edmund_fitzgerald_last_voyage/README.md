# Paper Detour 045 — Последний рейс «Эдмунда Фицджеральда»

Полнометражный выпуск по принятому пользовательскому сюжету. Полное производство ведётся по общему Paper flow; сам сюжет не меняется.

- Текущее состояние: [CURRENT_CONTEXT.md](CURRENT_CONTEXT.md)
- Принятый русский текст: [narration_ru_accepted_v01.md](Source/Script/narration_ru_accepted_v01.md)
- Английский narration: [narration_en_v01.md](Source/Script/narration_en_v01.md)
- Озвучка: [generation log](Source/Voice/en_v01_lawrence/GENERATION_LOG_v01.md)
- Карта производства: [FLOW_STATE.json](FLOW_STATE.json)

- `Research/` — источники, факты, ограничения и конкуренты.
- `Source/Script/` и `Storyboard/` — сценарий и постановка, с точными версиями.
- `Source/Images/` — одна законченная статичная бумажная диорама на кадр;
  смена композиций прямыми склейками по правилам канала.
- `Source/` — постоянные оригиналы этого монтажа.
- `Assets/Generated/` — постоянные производные для импорта, включая подготовленные cue PNG.
- `Work/<run>/scratch` — воспроизводимые временные файлы; `previews` — варианты для проверки.
  Запуск, состояния и назначение файлов вести через [media lifecycle](/Users/diplomat/ytvideos/.agents/skills/ytv-media-lifecycle/SKILL.md).
- `Edit/` — журналы и манифесты; пакет `.palmier` управляется приложением.
- `Deliverables/` — локальный путь выдачи нового выпуска по умолчанию;
  иной принятый путь записать в CURRENT_CONTEXT, не переносить импортированные файлы.
- `Packaging/` — обложки, метаданные и черновики постов отдельно от исходников монтажа.
- `Shorts/` — связанные короткие видео, если они нужны.

Исходные решения и новые версии сохраняются здесь; этапы пользовательской приёмки определяет production skill.
