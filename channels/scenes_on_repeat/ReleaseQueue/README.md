# Данные очереди Scenes on Repeat

Существующие `RELEASE.json`, `RELEASE_STATE.json`, `YOUTUBE.json` и ссылки на media сохраняются как фактические источники для [импорта](../../../docs/migration.md). Они не являются вторым workflow новых runs: новые задачи/версии/approvals ведёт общий store.

## Исторические поля

На фильм хранились exact file paths/SHA-256, роль сцены `lead`/`reserve`, video ID и upload outcome. `YOUTUBE.json` — снимок каталога с временем, не live состояние. Совпадение title только сигнал возможного duplicate; идентичность версии подтверждается video ID + file hash в receipt.

Read-only сверка старой очереди:

```bash
python3 channels/scenes_on_repeat/automation/queue_status.py --verify-files
```

`--refresh-token` использует конкретный разрешённый token вне Git для свежего чтения YouTube. Содержимое credentials не переносить в queue. LOCAL/UPLOADED/SCHEDULED/PUBLISHED проверять по реальным данным и времени snapshot; просроченный Private slot требует reconcile. Права проверяются отдельно.

## Редакционная очередь

Один `lead` на фильм, с причиной выбора; другие сцены — `reserve`. Первую волну формировать из разных фильмов; близкие сцены одного фильма разносить по разным неделям. Рабочий ориентир — три Shorts в неделю, до шести разных фильмов за первые две недели. Это редакционная настройка, не назначенные даты и не автоматическое разрешение выпустить весь резерв.

Фактический размер партии/слоты зависят от свежего календаря, готовности, прав и бюджета. Одобрение exact MP4 само по себе не разрешает upload или schedule; выполнять их в пределах прямого поручения пользователя. Идентичность и операции после импорта сверять по [общему release](../../../docs/standards/release.md).

## Планирование персонажных эдитов

Для одной серии персонажных эдитов планировать пока по два ролика на персонажа с разными кадрами фильма; планировать два ролика в день с разными персонажами. Повторный ролик об одном персонаже ставить примерно через календарный месяц после предыдущего; учитывая уже занятые слоты и состояние YouTube. Ориентир партии — 30 роликов на 15 дней. Сначала распределять персонажей и слоты, затем проверять точные дату, время, часовой пояс, готовность и права каждого файла; локальный план сам по себе не подтверждает назначение на YouTube.
