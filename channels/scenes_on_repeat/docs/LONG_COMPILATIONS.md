# Длинные подборки Scenes on Repeat

Общий lifecycle — [workflow](../../../docs/workflow.md). Канальный recipe имеет два варианта: сборник принятых трейлеров и тематическая подборка сцен. Права, язык и metadata — [PROFILE](../PROFILE.md).

## Сборник трейлеров

Для каждого принятого trailer сохранить порядок кадров, source boundaries и разрешённый оригинальный звук, переоформив исходные планы под 16:9. Не переносить вертикальную подложку, CTA или музыку native Shorts. Применить [long captions](LONG_CAPTIONS.md), выровнять громкость блоков, главы по началу каждого trailer сверить с exact MP4.

После каждого фильма, включая последний, поставить card: его постер растянут по двум осям на весь фон и сильно Gaussian blurred; при необходимости затемнён. Поверх слева тот же poster целиком с сохранением пропорций, справа крупное original title, ниже подтверждённые year/genre English. Без надписи Scenes on Repeat. Source/rights сохранить; длина card по ритму, безопасные поля/читаемость проверить. Принятый ориентир — v05 двухтрейлерного сборника от 09.11.2026, а не обязательная длина каждого будущего выпуска.

## Тематические сцены

Сформулировать одно зрительское обещание: что связывает сцены и зачем смотреть их вместе. У каждого кандидата exact фильм/год/version/track, source timecodes, связь с темой, минимальный контекст, локальная развязка и spoilers. Views Short — сигнал, не доказательство пригодности для long. Количество/длина задаются содержанием, без фиксированного пятисценового комплекта.

Начать с сильного понятного действия. Каждая сцена сохраняет завязку, изменение и результат/реакцию. Заново выбирать source boundaries для цельного просмотра; убрать повторные вступления/CTA Shorts, не склеивать вертикальные masters. Порядок определяется ясностью, напряжением и настроением; для перехода записать смысловую связь, не создавать ложной причинности между разными фильмами.

Вернуться к исходным кадрам и спроектировать широкий crop/text/subtitle geometry. Сверить чистые cuts по [EDIT_NOTES](EDIT_NOTES.md), целые реплики и баланс mix между фильмами. Прежний Short/отсутствие claims/доступность native music не заменяют права на новый long формат. Narration добавляется только по смыслу принятого плана.

## Выдача

Run содержит exact promises, порядок, исходные/финальные frames, sources/rights, настройки и artifacts. Shared source остаётся dependency каждого активного использующего его run. Batch Shorts helper сам не строит compilation; нужен отдельный edit plan/adapter.

На exact MP4 проверить понятность первого зрителя, развязки, transitions/crop, word sync и mix по [delivery](../../../docs/standards/delivery.md). Chapters/packaging представляют всю подборку. Schedule Short не становится schedule compilation; Related video назначается по реальному scope и сохраняется с read-back.

Пилот оценивать по одинаковым окнам/источникам/длине: impressions/CTR, retention начала и границ сцен, average duration. Отсутствие базы — baseline. Общий рост views не доказывает переходы из Shorts.
