# Meme Time Machine

Отдельный английский формат Scenes on Repeat: пять реальных фрагментов разных лет из кино/сериалов/жизни с видимым действием/реакцией без долгой вводной. Первоначальная целевая аудитория 4–18 лет; фактические audience/declarations определять по содержанию выпуска, не автоматически объявлять всю широкую возрастную группу одной platform category.

Места рейтинга редакционные. Порядок показа независим от номера места и меняется по замыслу; пилот `2→4→3→5→1` не является постоянной квотой порядка. До сборки проверить, что каждое место встречается один раз.

## Источники

Сверить имя мема/год, найти реальную версию по автору/студии, реплике и действию. Репост может помочь идентификации, но не подтверждает права. Открыть и проверить начало шутки/реакцию, записать URL/ID/channel, source boundaries и отдельные разрешения на video/audio. Рабочий файл перепроверить по точным frames.

## Монтаж

Вертикальная sequence 1080×1920. Снизу вверх: V1 blurred duplicate текущего clip, V2 sharp original, V3 заголовок/список; A1 только одна исходная дорожка V2, duplicate audio выключен. V1 может растягиваться по X/Y для мягкого full-frame background; V2 сохраняет пропорции и важные лица/действие. На cuts короткие audio fades, целые реплики, выровненные уровни.

Для 16:9 sharp clip по ширине 1080 px имеет около 608 px высоты в центре. Сверху blurred фон, снизу пять rating строк; subtitles внутри clip у нижнего края, жирный white с dark outline. Для vertical source sharp clip может занимать весь canvas, список — в свободной области. Сохранить margins под right/bottom Shorts UI; светлый фон под текстом при необходимости приглушить.

Перед каждым мемом короткая заставка на blurred кадре следующего clip; название плавно проявляется по центру. Затем сразу clip со звуком. Список сохраняет положение и во время заставки.

## Рейтинг и проверка

Снизу всегда строки 1…5 в неизменном порядке, жирные номера/названия. Будущая строка содержит только номер. На первом кадре соответствующего clip раскрыть его название, сохраняя уже раскрытые до конца. Текущую строку выделять только цветом, не сдвигать и не менять начертание; фон списка прозрачный. В конце видны все пять названий.

Проверить каждый frame boundary/title reveal, последовательность, отсутствие duplicate sound, читаемость, слова и права. Последний clip заканчивается понятным результатом, не служебным пустым кадром. Точный output contract и два gates остаются общими по [workflow](../../../docs/workflow.md); это recipe, не новый процесс публикации.
