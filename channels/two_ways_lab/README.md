# Oddly Drawn (machine key two_ways_lab)

[Актуальный профиль](../oddly_drawn/PROFILE.md) · [ChannelSpec](channel.json) · [identity evidence](../oddly_drawn/docs/IDENTITY.md) · [migration](../../docs/migration.md#two-ways-lab--oddly-drawn).

Новые задания используют Oddly Drawn: человек рассказывает историю рисунками на доске. `uv run ytv start --channel two_ways_lab --format short --intent 'точный запрос'` сохраняет новый run для редакционной работы; производство пока имеет явные blockers. `oddly_drawn` — директория бренда, не второй автоматизированный канал или CLI alias.

Старые [brand assets](brand/README.md), [backlog](docs/BACKLOG.md), [publication queue](docs/PUBLICATION_QUEUE.md), research и videos сохраняются как история Two Ways Lab. Они не задают требования новым tasks. Сохранённые runs продолжаются по своим pins; датированная очередь не подтверждает live-состояние. Переименование внешнего канала, публикации и календарные действия этим изменением не выполняются.
