# TWL E002 — The sock pile

Channel: Two Ways Lab | English Short | status: narration approved; video v01 awaiting review | model: `experiment/model.py` / `events.json`.
Viewer value: sorting can reduce matching checks on a mixed pile, but the saved count depends on the starting arrangement and one move does not necessarily take the same time as one comparison.

## Story and test

A person wants four matching pairs. Start both methods with the identical eight socks: blue, orange, green, purple, then blue, orange, green, purple. Exactly two of each, plain colors, same sizes. Method A takes the first remaining sock and compares it to following socks in order until the same color is found; remove both and repeat. Each comparison scores one action: 4 + 3 + 2 + 1 = 10. Method B places each of eight socks into its color pile; each placement scores one action, including identifying its color, then pairs in each pile are already apparent: 8. Both methods remove the same four pairs; that common handling is omitted. A comparison and a placement are counted equally as a simplified score, not as equal real-world time. Outcome applies only to this starting order and counting rule.
