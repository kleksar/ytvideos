# vidIQ: бюджет кредитов между сессиями

Кредиты vidIQ общие для подключённого аккаунта и расходуются из разных сессий Codex. Перед любым платным запросом считай их общим ограниченным бюджетом, а не локальным лимитом текущего чата.

## Наблюдение на 13 ноября 2026 года

vidIQ сообщил, что на аккаунте осталось 2 кредита; ближайшее пополнение указано на 6 декабря. Запрос списка собственных приватных/скрытых роликов стоит 5 кредитов и был отклонён без списания. Значит, такой запрос пока недоступен. Это датированный снимок, а не постоянное значение баланса.

## Правило перед вызовом

1. Сначала реши, повлияют ли данные vidIQ на выбор канала, выпуск или иной конкретный шаг. Для фактчекинга новостей используй первичные источники и обычный веб-поиск; не трать кредиты vidIQ ради сведений, которые можно получить напрямую.
2. До платных операций проверь текущий баланс через бесплатную `vidiq_balance` и прочитай стоимость нужного инструмента из его актуального описания. Баланс мог измениться после этой записи.
3. Сложи стоимость всех необходимых запросов и сравни её с текущим балансом до первого платного вызова. Сессии расходуют один и тот же пул; параллельные и повторные запросы тоже учитываются.
4. Если баланса не хватает хотя бы на нужный запрос, не вызывай его и не пробуй эквивалентный инструмент в другой сессии. Скажи, каких данных получить не удалось, почему и какой бесплатный источник/локальное состояние можно использовать вместо них.
5. Используй платные запросы только для решения, которое действительно требует этих данных. По возможности объединяй независимые проверки одним поддерживаемым вызовом; не повторяй уже полученный результат.

## Наблюдённые стоимости и замена

| Запрос | Стоимость, наблюдённая в этой сессии | Когда оправдан |
|---|---:|---|
| `vidiq_user_channels` | 0 | Однократно определить подключённые каналы, если их ID неизвестны |
| `vidiq_balance` | 0 | Проверить доступный общий баланс перед платными запросами |
| `vidiq_user_videos` | 5 | Нужен список собственных приватных/скрытых роликов или дат расписания для выбора очереди |
| `vidiq_channel_videos` | 5 | Нужны последние публичные публикации чужого или своего канала |

Стоимость инструментов может меняться. Перед каждым платным использованием сверяй актуальное описание; эта таблица фиксирует только наблюдённые значения. Публичные публикации можно отдельно искать обычным веб-поиском. При доступе к YouTube Studio приватные и запланированные ролики можно проверить там напрямую, без кредита vidIQ. Если доступной проверки нет, состояние очереди остаётся непроверенным; не выдавай публичные загрузки за полную очередь канала.
