# vidIQ: бюджет кредитов между сессиями

Кредиты относятся ко всему подключённому аккаунту. Разные сессии расходуют один бюджет; локальный лимит чата и прочитанный баланс не резервируют средства. Текущие остаток, стоимость и дата пополнения принадлежат provider observation конкретной задачи, а не постоянной документации.

## Перед платным вызовом

1. Определить, какое решение требует данных vidIQ. Для проверки фактов использовать первичные источники и обычный веб-поиск; для уже сохранённого состояния — доступные актуальные artifacts. Не расходовать кредиты на сведения, которые можно получить напрямую.
2. Прочитать актуальное описание нужного инструмента и способа проверки баланса. Проверить текущий общий баланс через `vidiq_balance`, убедившись в бесплатности этой операции по текущему описанию. Не переносить стоимость из памяти другой сессии и не записывать неизвестную цену как ноль.
3. До первого платного вызова посчитать стоимость необходимых запросов с учётом уже выполняемых и запланированных операций других сессий. При отсутствии общего резервирования выполнять платные вызовы последовательно через одного координатора; не объявлять локальный расчёт межсессионной блокировкой.
4. Если доступного остатка недостаточно, не вызывать операцию и не пробовать эквивалентный инструмент из другого чата. Сохранить конкретные недоступные данные, фактическую причину и применимый бесплатный источник; продолжить независимую работу.
5. Использовать минимальное число необходимых запросов. Объединять проверки только когда инструмент действительно поддерживает такой вызов. Перед следующей платной операцией заново учитывать баланс и результаты предыдущих действий.

## Сохранение результатов и повторы

Сохранять параметры запроса, канал/период, фактический ответ, наблюдённый расход и доступные provider IDs рядом с задачей. Повторная доставка поручения или новая сессия использует сохранённый подходящий результат; новый запрос нужен при изменившемся вопросе либо действительно устаревших данных.

После timeout или потери ответа сначала сверить исход и расход доступным способом. Не отправлять повтор автоматически и не считать неизвестный исход отсутствием списания. При невозможности сверки сохранить `UNKNOWN` и продолжить доступную независимую работу. Успешный ответ не создаёт универсальную гарантию idempotence API.

## Бесплатные источники

Публичные публикации можно искать обычным веб-поиском. Приватные и запланированные ролики проверять через YouTube Studio при доступном разрешённом доступе либо по актуальному сохранённому состоянию. Публичный список не заменяет полную очередь канала; если проверить приватную очередь нельзя, она остаётся непроверенной. Недоступность vidIQ не отменяет исследование по первоисточникам и другие разрешённые этапы.
