# What If You Could Read Minds — production reference

Кирилл оценил готовый англоязычный фильм You But Weird как почти идеальный ориентир по изображениям, переходам и анимации. Исторический machine ID, указанный при передаче, — `scenes_on_repeat`; текущий ChannelSpec следует проверять отдельно, не выводя идентичность или recipe из старого ID. Это художественный ориентир, не разрешение менять существующие runs, выпускать фильм или воспроизводить его без сохранённых входов.

## Версии и границы

- **EN 1.0** — принятый исторический baseline; сохранять его точные bytes и исходные prompts неизменными, включая прежние запреты текста. Само название файла не доказывает его идентичность; связать файл с manifest и решением владельца после получения evidence.
- **EN 1.1** — отдельная версия. Default voice/speed закреплены в ChannelSpec после PR #144; эта запись не меняет конфигурацию и не утверждает, что производная версия принята.
- **Dialogue/text v2** — отдельная версия с надписями. 16.11.2026 Кирилл одобрил точный `MIND_READING_EN_DIALOGUE_1.1x_1080p30.mp4` как эталон (источник решения `Sentinel_c68252d328e48191b6fee1b2a0268408`); это обновляет прежний статус «не одобрена» только для этого файла. Не заменять ею baseline.

Новые storyboard prompts могут включать короткий английский текст по [visual standard](../standards/visual.md#раскадровка); прежние prompt bytes остаются историческим evidence. Развлекательность, ясная визуальная идея и ритм важнее механического добавления надписей.

## Художественный ориентир движения

В переданном описании baseline используются цельное 2D движение кадра и прямые склейки, малые спокойные zoom/pan: приближение к деталям, отдаление для контекста, горизонтальный pan между связанными объектами. Направления pan и zoom чередуются независимо. Восстановленные `mind-reading-video/en/production-plan.json` и `render_video.py` задают 15360×8640 (8× по каждой стороне) для движущихся сцен и 1920×1080 для hold, с выходом 60 fps. Точную привязку остальных приёмов к конкретным кадрам сверять с motion plan. Не переносить 4–6 секунд из рецепта Paper/Nuviko на этот фильм: в описании проекта единица storyboard — предложение; фактические кадры и тайминги сверять с архивом. Действующий Nuviko запрещает vertical pan; это ограничение не меняется данным ориентиром. Использовать эталон как художественное evidence, а не как новую конфигурацию любого канала.

### Что переносить в новые работы

Развлекательный сюжет строить вокруг понятного hook, развития ставок и payoff; сюжетные детали не копировать. Для текущего You But Weird следовать [плотности отдельных смыслов](../standards/visual.md#плотность-отдельных-смыслов): отдельное предложение/самостоятельный смысл получает соответствующий кадр; соседние реплики нельзя молча укрупнять до редких ключевых иллюстраций. Поддерживать узнаваемого персонажа, контур и стиль; использовать плавное осмысленное движение камеры и чистые склейки. Короткие английские реплики или мысли в кадре ставить на важных акцентах, когда они помогают сцене, оставляя достаточно времени для чтения; не превращать каждый кадр в субтитры. Смысл и интерес важнее дополнительных механических проверок. По восстановленному Desire render script текстовые сцены удерживаются, движущиеся используют внутреннее масштабирование 15360×8640 при выходе 1080p30; это конкретный приём, а не универсальный числовой default. Порядок scene/motion и точные prompts брать из архивов; прежние prompts не переписывать.

Это художественные references, а не новый runtime guard. You But Weird пока не имеет зарегистрированного ChannelSpec; старый `scenes_on_repeat` и pins существующих run сохраняются. Применимость новых правил к run определяется профилем и [migration](../migration.md).
