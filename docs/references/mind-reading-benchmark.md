# What If You Could Read Minds — production reference

Кирилл оценил готовый англоязычный фильм You But Weird как почти идеальный ориентир по изображениям, переходам и анимации. Исторический machine ID, указанный при передаче, — `scenes_on_repeat`; текущий ChannelSpec следует проверять отдельно, не выводя идентичность или recipe из старого ID. Это художественный ориентир, не разрешение менять существующие runs, выпускать фильм или воспроизводить его без сохранённых входов.

## Версии и границы

- **EN 1.0** — принятый исторический baseline; сохранять его точные bytes и исходные prompts неизменными, включая прежние запреты текста. Само название файла не доказывает его идентичность; связать файл с manifest и решением владельца после получения evidence.
- **EN 1.1** — отдельная версия. Изменение default voice/speed ведётся в PR #144; эта запись не меняет конфигурацию и не утверждает, что PR уже слит или что версия принята.
- **Text v2** — отдельно порученная новая версия с редкими осмысленными надписями; она не является одобренной. Не заменять ею baseline.

Новые storyboard prompts могут включать короткий английский текст по [visual standard](../standards/visual.md#раскадровка); прежние prompt bytes остаются историческим evidence. Развлекательность, ясная визуальная идея и ритм важнее механического добавления надписей.

## Индекс восстановления

Проверенный в Library snapshot baseline: `YOU_BUT_WEIRD_MIND_READING_BASELINE_2026-11-16.tar.gz`, 461574250 bytes, SHA-256 `789e50bc88ba776175d77c3a4010c307075bf7e46bf2851fb6af1a294de77dbf`. По переданному verification он содержит 166 исходных файлов, включая 110 финальных PNG, storyboard с точными prompts, EN/RU scripts, raw audio, alignment, request/receipt, render scripts, измерение движения и batch manifests; члены архива сверены с исходными SHA-256. RU — история неправильного языка, EN 1.0 — неизменный принятый baseline. Mapping исходных generation invocation IDs неполон. Active 1.1, text v2, caches и render chunks исключены. Library manifest, README и verification существуют отдельно; идентификаторы доступа не публикуются в Git.

Отдельный derivative EN 1.1: `YOU_BUT_WEIRD_MIND_READING_EN_1.1_DERIVATIVE.tar.gz`, 85625640 bytes, SHA-256 `bfc61fbffa636155d11c132ad83dd229b52cb70a8864692a0c009ec19e5cfc92`. По переданному verification все 13 source members сверены; он содержит full/compact MP4, timing/motion scripts и обработанный голос, а PNG повторно использует из baseline по hash. Это не text v2 и не доказательство нового approval.

Для локального восстановления получить архивы и отдельные manifest/verification из авторизованной Library, проверить размеры и SHA-256, затем сверить каждый извлечённый файл и роли с manifest. Сохранить локальную копию вне Git и независимую проверенную резервную копию; записать URI, версию, происхождение и права в artifact store. На текущем Mac transfer пока не завершён, локальная копия и restore остаются **UNVERIFIED**. Связать exact MP4 с manifest и решением владельца до утверждения его идентичности. Не придумывать отсутствующие IDs, hashes, параметры и provider receipts. Восстановление прежних bytes требует исходных media и проверенного backup/restore по [storage contract](../standards/storage.md#архив-и-recovery); повторная генерация по prompt не гарантирует тех же bytes.

Его принадлежность к baseline, внутреннее разрешение рендера и остальные параметры ещё требуют сверки с точным manifest. Абсолютный путь на Mac — локатор, не постоянная идентичность. ## Художественный ориентир движения

В переданном описании baseline используются цельное 2D движение кадра и прямые склейки, малые спокойные zoom/pan: приближение к деталям, отдаление для контекста, горизонтальный pan между связанными объектами. Направления pan и zoom чередуются независимо. 8× internal resolution заявлено при передаче, но до сверки render scripts/measurement остаётся **UNVERIFIED**, как и точная привязка остальных приёмов к конкретным кадрам. Не переносить 4–6 секунд из рецепта Paper/Nuviko на этот фильм: в описании проекта единица storyboard — предложение; фактические кадры и тайминги сверять с архивом. Действующий Nuviko запрещает vertical pan; это ограничение не меняется данным ориентиром. Использовать эталон как художественное evidence, а не как новую конфигурацию любого канала.
