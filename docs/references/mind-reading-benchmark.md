# What If You Could Read Minds — production reference

Кирилл оценил готовый англоязычный фильм You But Weird как почти идеальный ориентир по изображениям, переходам и анимации. Исторический machine ID, указанный при передаче, — `scenes_on_repeat`; текущий ChannelSpec следует проверять отдельно, не выводя идентичность или recipe из старого ID. Это художественный ориентир, не разрешение менять существующие runs, выпускать фильм или воспроизводить его без сохранённых входов.

## Версии и границы

- **EN 1.0** — принятый исторический baseline; сохранять его точные bytes и исходные prompts неизменными, включая прежние запреты текста. Само название файла не доказывает его идентичность; связать файл с manifest и решением владельца после получения evidence.
- **EN 1.1** — отдельная версия. Изменение default voice/speed ведётся в PR #144; эта запись не меняет конфигурацию и не утверждает, что PR уже слит или что версия принята.
- **Text v2** — отдельно порученная новая версия с редкими осмысленными надписями; она не является одобренной. Не заменять ею baseline.

Новые storyboard prompts могут включать короткий английский текст по [visual standard](../standards/visual.md#раскадровка); прежние prompt bytes остаются историческим evidence. Развлекательность, ясная визуальная идея и ритм важнее механического добавления надписей.

## Индекс восстановления

Полный snapshot и его manifest ожидаются отдельно. По переданному описанию они включают storyboard с точными prompts, 110 исходных PNG, EN/RU scripts, raw audio, alignment, request/receipt, render scripts, измерение движения и batch manifests. Это описание состава **не подтверждает** наличие или целостность архива. После получения сохранить immutable URI, версию, размер и SHA-256 архива и manifest; сверить каждый файл, его роль, источники, настройки, зависимости и права. Связать exact MP4 с manifest, решением владельца и hash; отдельно указать каждую производную версию. Не придумывать отсутствующие IDs, hashes, параметры и provider receipts.

На доступном локальном файле `MIND_READING_EN_1080p.mp4` read-only `ffprobe` показал H.264 1920×1080, 60/1 fps, AAC и длительность 226 секунд. Его принадлежность к baseline, внутреннее разрешение рендера и остальные параметры ещё требуют сверки с точным manifest. Абсолютный путь на Mac — локатор, не постоянная идентичность. Восстановление прежних bytes требует исходных media и проверенного backup/restore по [storage contract](../standards/storage.md#архив-и-recovery); повторная генерация по prompt не гарантирует тех же bytes.

## Художественный ориентир движения

В переданном описании baseline используются цельное 2D движение кадра и прямые склейки, малые спокойные zoom/pan: приближение к деталям, отдаление для контекста, горизонтальный pan между связанными объектами. Направления pan и zoom чередуются независимо. 8× internal resolution заявлено при передаче, но до сверки render scripts/measurement остаётся **UNVERIFIED**, как и точная привязка остальных приёмов к конкретным кадрам. Не переносить 4–6 секунд из рецепта Paper/Nuviko на этот фильм: в описании проекта единица storyboard — предложение; фактические кадры и тайминги сверять с архивом. Действующий Nuviko запрещает vertical pan; это ограничение не меняется данным ориентиром. Использовать эталон как художественное evidence, а не как новую конфигурацию любого канала.
