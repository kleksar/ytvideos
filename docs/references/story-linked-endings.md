# Сюжетные финалы: утверждённый reference

Кирилл утвердил оба теста Mind Reading → Everyone Wants You и обратный переход: «ДА!!!!! ЭТУ АХУЕННО! МЕНЯЙ ДОКУ! ВСЕ СЛЕДУЮЩИЕ ВИДЕО ИДУТ ТАК!!!». Источник решения: `Sentinel_96626629efdc81918c79f1cb41d66387`. Это прямое поручение закрепить подход для следующих видео всех каналов, а не только You But Weird. Процедура/требования принадлежат [editorial](../standards/editorial.md#сюжетный-переход-к-следующему-видео), [delivery](../standards/delivery.md#монтаж-сюжетного-финала) и [release](../standards/release.md#end-screen-и-ab); эта страница хранит художественное основание, не второй preset.

Переданные тесты — два 22-секундных MP4 в пользовательской папке `Desktop/You But Weird — Ending Tests`, со script и README рядом. По отчёту изготовителя они сохраняют последние 8 секунд настоящей развязки, связывающий экранный вопрос, 5 секунд живого intro следующего ролика и свободную зону под кликабельный end screen. Новую озвучку не генерировали. Путь — локатор, не hash/backup receipt; этот docs-change не заявляет собственное прослушивание или проверку bytes тестов.

Принятые конкретные мосты:

- Mind → Everyone: `You know what they think. What if they all wanted YOU?`
- Everyone → Mind: `Everyone wants you. But what are they REALLY thinking?`

Сильная функция: сначала выполнено обещание текущей истории, затем его результат вызывает новый вопрос; зритель видит, куда ведёт переход, а не универсальный рекламный экран. Эти фразы и 22/8/5 секунд — детали примеров, не обязательные формулировки или тайминги для новых сюжетов. Не переносить автоматически на Shorts: самостоятельная развязка и петля сохраняются, кликабельная связь адаптируется к Related video. Показанное место под ссылку не доказывает, что native элемент настроен. Пользователь одобрил монтажный подход; этот PR не меняет YouTube и не означает принятие ещё не собранных полных финальных MP4.
