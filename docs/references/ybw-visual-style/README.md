# You But Weird — единый визуальный язык

Канальный reference pack по прямому поручению владельца: сохранить рисовку двух принятых роликов Mind Reading и Everyone Wants You. Здесь **11 кадров, извлечённых из реальных MP4**, а не исходные файлы генерации. Они сохраняют монтажный crop, движение/надписи и компрессию экспортов. Нельзя называть их восстановленными imagegen originals. Новые 10 тестовых изображений и отклонённый Three Wishes V2 не входят в этот пакет извлечений. Владелец одобрил остальные референсы, но явно исключил уличный Everyone130 (2:10) за избыток деталей: его нет среди PNG, в паспорте, crop map и коллажах. Не возвращать его как пример окружения.

Пакет относится к новому направлению You But Weird в [профиле](../../../channels/scenes_on_repeat/PROFILE.md), не к историческому licensed-clips recipe. Он не меняет принятые видео, ChannelSpec, параметры генератора или pins текущих run. Общие требования — [visual](../../standards/visual.md), применение — [процедура раскадровки](../../../.agents/skills/ytv-produce-video/references/storyboard.md).

## Реальные изображения

- [Позы и эмоции героя](collages/01_character_poses_emotions.jpg): два подписанных варианта, не один смешанный персонаж.
- [Предметы](collages/02_objects_visual_language.jpg): кофемашина, фишки, документы, торт, дверь, чашки.
- [Композиции сцен](collages/03_scene_compositions.jpg): 11 полных кадров, в том числе крупный диалоговый план; без отклонённой детализированной улицы.
- [Паспорт источников](source_passport.json): точные MP4, SHA-256, секунды seek, команды извлечения и хеши PNG.
- [Карта кропов](crop_manifest.json) и [сборщик коллажей](build_collages.py): производные учебные листы, не новые сцены.
- [Пример reference lock](reference-lock.example.json): переносимый список реально прикладываемых изображений; это пример, не approval нового выпуска.

Полные PNG лежат в `originals/`. Имя с секундами относится именно к указанному в паспорте экспорту, не к произвольной версии того же сюжета. Абсолютные Mac-пути — provenance, не обязательный путь на другом компьютере; идентичность сверяется хешем. MP4 в Git не добавляются. Ограниченный набор PNG и коллажей сохранён здесь по явному поручению владельца закоммитить реальные художественные референсы; это не правило коммитить production media или все результаты генерации.

## Общее, действительно видимое в двух роликах

- Тёплое кремовое поле, охра/горчичный жёлтый, приглушённый сине-серый и угольный контур. Это словесный ориентир по изображениям, не выдуманный точный HEX/palette preset.
- Простые округлые чёрные/тёмные контуры, большие светлые головы, минимум черт лица. Эмоция читается по бровям, глазам, рту, наклону головы и позе.
- У главного героя чёрные округлые ладони/варежки, не анатомические пальцы. У второстепенных персонажей следовать конкретному референсу: например, у начальника Mind43 видны светлые простые руки. Не объявлять каждую руку в архиве чёрной.
- В основном плоские матовые формы, мягкая бумажная фактура и умеренная тень. Не глянцевый 3D, не объёмная анатомия, не ярко-синяя пластиковая одежда.
- Среда поддерживает действие: простая мебель, читаемый реквизит, разнесённые силуэты. Крупный план и пространство для действия важнее декоративных деталей. Минимализм — обязательная часть направления: только необходимые для действия предметы, простые формы и свободное пространство; декоративная насыщенность не повышает качество.
- Короткая английская надпись появляется по смыслу. Mind43 показывает облако мысли, Mind178 — речевой пузырь с читаемым текстом. Цветной знак мысли не обязателен в каждом плане и не должен становиться непонятной линией. Не копировать чужую реплику из reference в новую сцену.

## Два профиля персонажа, не противоречие

| ID | Фактический источник | Что сохранять |
|---|---|---|
| `mind-stick` | Mind12, Mind23, Mind43, Mind105 | Тонкое чёрное тело и конечности stick figure без одежды; светлая круглая голова с одним завитком; горчичный шарф; чёрные округлые ладони. Часы видны в нескольких кадрах: закреплять их отдельно, если нужны выбранному образу. |
| `everyone-hoodie` | Everyone16, Everyone46, Everyone82, Everyone190 | Матовая приглушённая сине-серая худи с охристыми деталями, тёмные брюки/обувь, горчичный шарф; круглая светлая голова с завитком, чёрные простые ладони. |

**Худи сама по себе не ошибка.** Ошибка — иной материал/цвет/пропорции и незаметное смешение выбранных вариантов. Новый выпуск фиксирует один профиль по принятому направлению и actual references, а не усредняет их и не превращает всех героев в stick figure. Для продолжения сохраняется ранее выбранный профиль. Не добавлять имя, биографию, одежду или аксессуары только потому, что они были в позднем тестовом prompt. Сюжетные изменения состояния персонажа отмечаются явно.

## Reference lock и проверка результата

Lock выпуска фиксирует выбранный `character_profile`, версию пакета/commit, scene ID, конкретные reference files + SHA-256, роль каждого reference (character / prop / composition), неизменяемые признаки и разрешённое новое действие. Каждый image task получает сами выбранные файлы, не только ссылку на каталог/длинный текст. Профиль героя берётся из кадров, где он действительно виден: Mind62/178 — соперники, Everyone28 — другая пара, не портрет главного героя.

Один общий стиль не означает одинаковый фон и позу. Новая сцена должна показывать своё действие и самостоятельный смысл, сохраняя материал, контур и выбранную идентичность. Подпись/zoom/crop не заменяют отдельную постановку.

При проверке сопоставляются actual output и actual reference: голова/завиток, форма тела, одежда выбранного профиля, руки, контур, палитра, уровень детализации, предметное действие, эмоция и текст. При drift исправляется сцена, а не переопределяется эталон задним числом. Удачный тест становится reference только после явной приёмки владельцем точного изображения; этот пакет содержит только указанные реальные извлечения и не подменяется поздними тестами.

## Шаблон стилевого блока prompt

Это образец формулировки для соответствующего выбранного профиля, а не утверждение о реальном историческом prompt или настройках модели:

```text
Use the attached real-video reference frames as the visual authority.
Match their matte warm cream / ochre / muted blue-gray palette, simple dark
contours, sparse expressive faces and readable flat illustrated staging.
Character profile: [mind-stick OR everyone-hoodie, as locked for this episode].
Preserve the selected character's head, curl, scarf, hands and body/clothing
from the attached character reference. Do not blend the two body profiles.
New scene: [one specific action / state / reaction, camera and emotion].
Objects: [only story-relevant props; use attached prop reference if applicable].
Exact English text: [approved wording and placement, or no text].
Do not copy reference dialogue into this new scene. No glossy 3D, realistic
fingers, saturated plastic clothing or elaborate photorealistic interiors.
```

Провайдер, размеры и параметры берутся из применимого task packet, не из этого примера. Коллаж — средство изучения; для generation предпочтительны соответствующие полные PNG, чтобы подписи учебного листа не попали в результат.

## Передача actual references

Перед вызовом генератора реально открыть 2–3 подходящих полных PNG и обозначить роль каждого в prompt. Новый предмет или второстепенного персонажа сначала сверить с object/scene boards; отсутствующую в источниках деталь отметить `proposed`, а не каноном.

## Проверка и пересборка пакета

`python3 docs/references/ybw-visual-style/verify_pack.py` проверяет хеши PNG, размеры, полное покрытие паспорта и допустимые crop boxes. `build_collages.py` использует Pillow и Arial на Mac (fallback зависит от системы); повторная сборка сохраняет источники и геометрию, но байты JPG/метрики подписей зависят от версии Pillow и доступного шрифта. Извлечения повторять только из MP4 с соответствующим SHA-256.
