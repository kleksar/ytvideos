## Применение в проекте

- Hook patterns помогают выбрать форму проверенного материала. Они не являются квотой, оценкой качества, новым gate или разрешением переписывать exact accepted script.
- Production examples применяются по нужному разделу и только в границах закреплённого рецепта. Static whole-frame camera cards не задают camera action для Flow A→B или licensed clips.
- Новые references входят в snapshot соответствующих этапов. Существующие pinned runs используют прежние тексты; перенос правил требует обычной migration.
- На источники из этой заметки не нужно переходить из production worker: его входом остаётся локальный pinned packet. Исследовательская заметка не входит в обязательное чтение каждого task.
