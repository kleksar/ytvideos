## Редакционная рамка

Выпуск должен показать пять подлинных мемных фрагментов, распространённых в одном выбранном календарном году. Для каждого нужно отдельно подтвердить мем и год, а затем найти конкретную первичную версию по автору/студии, реплике и действию. Репост допустим как подсказка для идентификации, но не подтверждает происхождение или права. Не подставлять известные мемы по памяти: packet не называет ни год, ни пять мемов.

Рейтинг — редакционный. Назначить каждому фрагменту уникальное место 1–5; одно место нельзя повторять. Порядок показа отдельно выбрать для драматургии, он не обязан идти по числам. Рабочее предложение для порядка показа — **2 → 4 → 3 → 5 → 1** (пример пилотного рисунка из канального рецепта, не установленная квота); принять его только после назначения рейтингов и проверки, что раскрытие списка остаётся понятным. Пять названий в списке всегда стоят по рейтингу 1–5, независимо от порядка появления клипов.

## Компоновка и экспорт

- Sequence: вертикальная 1080×1920, 48 fps, H.264 BT.709, AAC stereo 48 kHz — параметры именно рецепта Meme Time Machine. Не использовать настройки обычного сценового Short (24 fps, центральная полоса, CTA/card).
- Дорожки снизу вверх: V1 — размытый дубликат текущего клипа; V2 — исходный резкий клип; V3 — заголовок/список. A1 — только оригинальная дорожка V2; аудио V1 выключить. A2 — переходные эффекты в исходной длине и темпе.
- Для горизонтального 16:9 клипа, вписанного по ширине 1080 px, резкое изображение будет примерно 608 px высотой по центру. Размытый дубль закрывает фон. Для вертикального исходника резкий клип может занимать весь холст; расположить список в свободной области.
- Список всегда в нижней части в постоянном месте и с прозрачным фоном: строки 1–5, жирные номер и название. Для будущего мем-слота показывать только номер; на первом кадре его клипа раскрыть название. Не перемещать список и не менять начертание активной строки — только её цвет.
- Исходные субтитры располагать внутри резкого клипа у нижнего края, жирным белым с тёмной обводкой; проверить конфликт со списком и Shorts UI справа/снизу. Не закрывать лицо или ключевое действие. Если фон под текстом светлый — приглушить его без потери деталей.
- Перед каждым клипом — короткая заставка на размытом кадре следующего клипа. Заголовок входит крупным с первого кадра, дважды быстро вращается по часовой стрелке, уменьшается; фон одновременно становится резким. Резкий заголовок держать 250 мс, затем растворить, клип начинается сразу со звуком.

## Приёмочный checklist для будущей сборки

Это критерии будущей проверки, не результаты выполненных проверок.

1. Для всех пяти мемов сверить имя/год по источникам и установить конкретную первичную версию; сохранить URL/ID канала, автора/студию и даты/свидетельства распространения.
2. Для каждого источника зафиксировать точные source in/out, границы и выбранные кадры; проверить начало шутки, реакцию и payoff в исходнике и в подготовленном файле.
3. Отдельно подтвердить права на изображение и оригинальный звук каждого использованного фрагмента; сохранить доказательства разрешений. Репост, доступность ролика и отсутствие Content ID claim не заменяют разрешение.
4. Проверить наличие всех пяти рейтингов ровно по одному разу; сверить порядок появления с рейтингом и раскрытие строк по каждому первому кадру.
5. Просмотреть каждую заставку, каждую границу клипа и оба 100-мс нахлёста; подтвердить полную длину/темп переходного эффекта, отсутствие лишних кадров соседнего плана и отсутствие duplicate audio.
6. Просмотреть все кадры списка/субтитров и проверить читаемость, кадрирование, safe margins, непрерывность клипов и законченный последний payoff.
7. До полного рендера иметь принятый script/точный монтажный план, storyboard, законные исходники, окончательный микс или зафиксированное решение о звуке, проверенные субтитры/word map и loop plan. После рендера нужны проверки фактического MP4 по duration, provenance и streams; без исполнения не ставить PASS.
