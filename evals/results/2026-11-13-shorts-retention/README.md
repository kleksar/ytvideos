## Проверенное поведение повторной пробы

- CLI trace фиксирует `instructions`, явные `paper_detour`, `retention`, `short`, exit 0 и пустой stderr. Полный stdout содержит `ytv-operate`, общую процедуру, профиль, editorial и retention reference. Координатор сверил все 5 документов packet с точными bytes/hash источников и все 8 записей чтения.
- Модель выделила спад 89% → 65% между 18 и 24 секундами, связала его с предоставленным timing sheet и отдельно обозначила гипотезу о повторе. Причинность не объявлена доказанной; MP4 не заявлен просмотренным.
- Выбран один следующий опыт: заменить повторное объяснение новым видимым действием/уликой. Названы локальная кривая, stayed-to-watch и AVD/APV для последующего наблюдения; это не рандомизированный A/B.
- Для второго ролика модель сохранила отсутствие retention report и отказалась выводить удержание из public views. Учтены разные длительности/возраст и отсутствие подходящего сравнения.
- Вывод передан research по конкретному пути заметки. Синтетическая identity не смешана с реальным каналом; production run и внешние изменения не нужны для этого задания.

## Оставшиеся ограничения

В raw ответе есть неточная фраза «отметки целые», хотя в таблице правильно указаны `43.8` и `55.8` секунды. Таблица соответствует `elapsedVideoTimeRatio × 60`, но пояснение нельзя считать безошибочным. Определения AVD/APV и engaged views раскрыты не полностью: ответ не повторяет, что первые относятся к продолжившим просмотр, а engaged views исключают циклы. Эти ограничения сохранены вместе с исходным ответом, а не исправлены задним числом. Независимый reviewer подтвердил основной вывод и один опыт, но не полный PASS всех деталей процедуры.

В CLI trace сохранены два восстановленных отказа: YouTube ID вместо имени каталога канала и интерпретатор без `PYTHONPATH`. Затем выполнены успешные вызовы с явным `paper_detour` из входа. Это не проход без retries и не доказательство безошибочного выбора параметров; неправильный канал был отклонён до анализа.

Запись чтений и сохранённый CLI stdout подтверждают конкретные входы/выдачу правил, но не заменяют экспорт всех tool calls или доказательство полного понимания. Один повторный успешный маршрут не доказывает устойчивость в других запросах. Не проверены live Studio/API, реальный playback, эффект на retention, следующий production research/script run и исполнение нового `shorts_to_short` action внешним host. Полный сценарный цикл не заявляется результатом этой аналитической пробы. Tokens/cost/полный session trace не экспортированы.
