# Драматургия и переработка: ограниченные пробы Luna

Проверка изменения общего [editorial](../../../docs/standards/editorial.md) от 2026-11-13. Это отдельные текстовые задачи в свежих GPT-6 Luna, не полный production run, не весь набор `shorts_editorial` и не измерение удержания. Исторические результаты и статус полного набора не переписаны.

## Что выполнено

| Проба | Наблюдённый результат |
|---|---|
| Гладкий пересказ без развития | Reviewer отклонил текст и назвал повторы результата вместо объяснения/решающего действия. |
| Переработка бытовой истории | Reviewer обнаружил потерю конкретных действий, выбора сестры и последствия; не принял общий вывод о границах за развязку. |
| Конкурирующие обещания и подразумеваемая причина | Reviewer отклонил намёк на связь заявки и закрытия, не подтверждённую учебным fact pack, и финал без отдачи. |
| Спокойное объяснение, первый вход | Функции истории распознаны. Reviewer запросил более полные условия модели и раннюю оговорку; также чрезмерно трактовал слово «оказалось» как эмпирическое утверждение. Этот ответ сохранён без ретуши. |
| Отдельный полный положительный контроль | Другой reviewer принял объяснение по тексту и проверил арифметику; не потребовал конфликта, петли для Long или повторения оговорки в каждой реплике. |
| Авторская переработка вымышленного Short | Writer сохранил конкретную сцену, действия и развязку; честно оставил независимую проверку и AV-стык UNVERIFIED. Первая фраза почти повторяет исходник, поэтому полную самостоятельность формулировок этот выход не доказывает. |
| Поэтапный первый слушатель нового текста | Сначала получил только начало, затем полный текст без заметок автора. Нашёл ответ, смену ожидания, кульминацию и развязку; отдельно отклонил неестественный стык «за час до ужина. За час до ужина». Общий script PASS не заявлен. |

После первого reviewer-прохода standard уточнён одной фразой: когда область условной модели уже ясна, не требовать одинаковой оговорки в каждой реплике. Для положительного контроля отдельно предоставлены полные исходные данные и ранняя оговорка. Это **другой вход**, поэтому результаты не являются A/B-доказательством улучшения модели или причинного эффекта этой строки.

## Входы и независимость

- [Четыре reviewer-входа](reviewer-inputs.json) содержат только задания; `expected_observations`, parent conversation и диагноз автора новой сессии не передавались.
- [Запрос автору](writer-request.txt), [точный выход](writer-output.txt) и [рабочие заметки](writer-notes.md) сохранены раздельно. Пользовательская область — ручная работа только с текстом Nuviko Stories; production run не создавался.
- Первый слушатель сначала получил только начальную реплику; [начальный ответ](first-listener-opening.md) сохранён до передачи полного текста. Затем прочитал текст и standard, без writer-notes и исходника: [полный отзыв](first-listener-full.md).
- Положительный контроль: [условия и текст](positive-control.txt), [независимая проверка](positive-control-review.md).
- [Первый reviewer-выход](reviewer-output.md) сохранён полностью, включая избыточную осторожность. Его четыре входа прочитаны целиком: это узкий редакторский проход, не поэтапный first-listener protocol.

Фактически прочитанные пути перечислены в outputs/манифесте. Абсолютные пути в сырых ответах относятся к среде выполнения; переносимые копии входов находятся рядом. Model session handles, задания с нормализованными путями, версии требований и hashes — в [result.json](result.json); это не полный trace. Проверяющие не являются автором оцениваемого текста; отсутствие аудио не подменялось «прослушиванием».

## Граница результата

Проба подтверждает, что новый review способен назвать эти конкретные дефекты и не обязан отвергать спокойное объяснение. Она не доказывает, что все будущие сценарии интересны или что автор всегда соблюдает правила с первой попытки. Найденная неудачная петля остаётся зафиксированным FAIL этого учебного текста, а не замаскированным PASS.

Нет production approvals, TTS, изображений, MP4, публикации или YouTube-метрик. Полный сценарный прогон research → выбор темы → script через актуальный runtime context, весь исторический набор cases и AV-прослушивание здесь не выполнялись. Для продолжения существующего выпуска нужны его реальные context/pins; обновление checkout не доказывает миграцию run.
