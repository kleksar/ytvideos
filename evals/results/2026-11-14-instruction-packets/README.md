# Переносимые инструкции: проверка изменения

Проверяется доставка skill и выбранных документов в entry/native packet, сохранение pins и узкая маршрутизация research. Это не приёмка полного видеопроизводства.

## Машинные проверки

Новые тесты до исправления дали 4 FAIL и 1 ERROR: дублированный текст skill, сломанная относительная ссылка, прежняя identity entry-каталога и отсутствие проверки skill hash/path. После исправления адресный набор дал 91 PASS и 48 PostgreSQL SKIPPED локально. Полный locked core suite: 722 обнаружены, 570 PASS, 152 SKIPPED. [CI первого коммита](https://github.com/kleksar/ytvideos/actions/runs/43618703850) прошёл, включая PostgreSQL и automation suites. Финальный CI относится к head PR и виден в его checks.

Canonical context/outbox не изменяются материализацией. Проверены одинаковые повторные запросы, concurrent publication, подмена файла, версия/путь/hash descriptor, неизменность pinned требований после изменения checkout и восстановление legacy native job без повторной отправки.

## Размер файлов

[measurements.json](measurements.json) сравнивает main `636386783a13b7b11d2173c233b68654f43d9848` с финальной реализацией: три канала × research/scene_image/render, формат Short. Одинаковый offline envelope оборачивает `instruction_packet`; считаются UTF-8 bytes всех материализованных файлов, включая `TASK.json`, skill и requirements. Production run, providers и бюджет не создаются.

```bash
python evals/results/2026-11-14-instruction-packets/measure.py /path/to/baseline /path/to/candidate
```

Уменьшение составляет 4,6–10,6%. Это размер этих девяти пакетов, не число tokens, latency, стоимость или оценка всех этапов. Состав reference routes не сокращался; полного транзитивного closure Markdown-ссылок нет.

## Две свежие сессии Luna

[runs.json](runs.json) содержит точные prompts, версии, модель, hashes и журнал фактических команд с кодами завершения. Оба запуска выполнены без истории родительского анализа. Выводы и самоотчёты сохранены без редактирования. Полные захваченные shell stdout/stderr сжаты в `attempt-*/trace.jsonl.xz`; `record.py` — использованный logging wrapper. Декомпрессия: `python -c 'import lzma,sys; sys.stdout.buffer.write(lzma.open(sys.argv[1], "rb").read())' PATH`.

1. [Первый ответ](attempt-1/output.md) получен на `ac3352c4a515e6189c00e60ccaccb8f0202507b8`. Модель вызвала `instructions --stage research`, дала условный редакторский вердикт и использовала веб-поиск. Полный разбор первоисточников не выполнялся. Широкий `rg` вернул более 3 MB, включая прежние evals: этот запуск не подтверждает эффективное чтение контекста. [Самоотчёт](attempt-1/evidence.md) отделён от машинного trace.
2. [Второй ответ](attempt-2/output.md) получен на том же коде с финальным уточнением общей процедуры о недоверенных данных/evidence. Hash изменённого reference записан в `source_overlay_sha256`; tests/evals отсутствовали в рабочем snapshot. Сначала модель придумала stage `idea`; CLI отклонил его, после чего она выбрала `research`. Поиск по отсутствующей папке `evals` тоже завершился с exit 2. Обе ошибки сохранены. Фактчекинг не выполнен: формулировка prompt «внешние публикации» была истолкована как ограничение внешних материалов. Это ограничение самой пробы, не запрет веб-исследования в проекте. [Самоотчёт](attempt-2/evidence.md) не доказывает противоположное.

Ни один запуск не сообщил ложный blocker из-за отсутствующего narration standard. Однако выдача полных документов в stdout не доказывает их полное чтение моделью; coverage остаётся `UNVERIFIED`. Первые чтения и часть действий выполнялись вне wrapper, поэтому журналы не объявлены полной tool trace. Для hashes использовать пересчитанный `runs.json`, а не промежуточные значения внутри авторского самоотчёта.

Эти узкие пробы не исполняют materialized image worker, не подтверждают всю сценарную цепочку, художественное качество, прослушивание, генерацию или публикацию. Путь skill и сохранность его bytes проверены контрактными тестами; поведение модели оценено только в описанных пределах. Existing runs не мигрировались. Статистический выигрыш, сокращение ошибок и ускорение по двум ответам не установлены.
