# Проверка понятной истории и петли Shorts

Владелец правил — [editorial](../../docs/standards/editorial.md); AV-стык — [delivery](../../docs/standards/delivery.md). Здесь задания и редакционный пример, не канальный профиль, не публикационный пакет и не approval. Исторические результаты в `evals/results/` не переписываются.

## Что проверено автоматически

[Тест](../../tests/test_editorial_contract.py) проверяет связи навыков с общим стандартом, отсутствие прежнего optional-loop маршрута, согласованность каталога, неизменность последнего полного текста и арифметику E001. Это не проверка привлекательности, естественности речи или удержания.

```bash
python -m unittest discover -s tests -p 'test_editorial_contract.py' -v
```

## Живой прогон skill: НЕ ВЫПОЛНЕН

До снятия draft-ограничения MR выполнить в свежей доступной модельной сессии обычную задачу через актуальный task context и `ytv-write-script`, без подсказки ожидаемой структуры в пользовательском prompt. Не выдавать этот документ целиком автору в качестве готового ответа.

1. Пример входа: «Напиши короткий сюжет про выбор кассы для Two Ways Lab по приложенной модели». Дать только реальную модель, профиль и штатные правила из context. Не добавлять ожидаемый вердикт или готовый reference narration. Если профиль ещё локальный, передать его явным входом; не создавать второй канал.
2. Ещё два задания взять из реальных fact packs разных жанров/каналов. Не выдумывать исторические факты ради тестирования. Ограничить число проб и бюджет; не запускать TTS, image generation или публикацию.
3. Передать точный выход независимому первому слушателю без диагноза автора. Сначала показать только начало, затем весь текст, затем конец → начало. Получить пересказ, вопрос, причину результата, точные непонятные места и оценку стыка. После этого отдельно сверить с fact pack/моделью.
4. [cases.json](cases.json) — отрицательные и положительные reviewer-пробы. Проверяющему передавать только `input`; `expected_observations` использовать после ответа. Они не являются измеренным качеством автора и не предназначены для подгонки ответа.
5. Сохранить code/skills/profile pins, входы, точный текст/hash, trace/session handles, реальные checks и ограничения в новом eval result. Недоступный независимый reviewer — UNVERIFIED, не авторское «переключение роли».

Принятие MR не является доказательством улучшения метрик YouTube. Проверять cold-open, причинность, отдачу, факты и петлю отдельно; один высокий средний балл не компенсирует провал необходимого условия. Автоматические tests не закрывают этот живой прогон.

## Two Ways Lab E001: исходный пример

[e001_reference_en.txt](e001_reference_en.txt) сохраняет последний **полный** английский текст из диалога без переписывания. Владелец предпочёл более простую подачу и направление «неожиданный исход → объяснение». Для этого направления в [e001_model.json](e001_model.json) отдельно записан предложенный opening. Полный текст с новым opening ещё не предъявлялся: нельзя молча склеить две версии и оформить это как одобрение точного артефакта.

Это справочный материал для следующей локальной редакции, не gold score и не команда запустить видео. Профиль Two Ways Lab, его ID, TTS, images, approvals и текущие локальные runs этим MR не создаются и не меняются. Прежний v1.1 handoff с необязательной петлёй — исторический материал, не источник действующих правил; при локальном продолжении использовать pinned общий стандарт этой версии. Автоматически не переписывать утверждённые выпуски.

### Модель и смысл

Слева два покупателя с 14 и 11 товарами, справа пять с 2, 3, 4, 2 и 3. Сканирование товара — 2 модельные секунды; каждая оплата — 12. Новых приходов, неисправностей и смены правил нет. Измеряется ожидание начала собственного обслуживания, не полный выход зрителя из магазина.

A заканчивает покупателей в 40 и 74 секунды; B — в 16, 34, 54, 70 и 88. На t=34 справа ушли двое, слева ещё никто. На t=74 слева пусто, справа остаётся последний: он ещё сканирует товары, оплата начнётся на t=76. Нельзя нарисовать зависшую оплату в этот момент. Корзины экономят 22 секунды сканирования, но три дополнительные оплаты стоят 36; разница — 14 секунд.

Это условный пример, не замеры магазина и не универсальный совет. Сам факт воспроизводимой арифметики не делает рассказ понятным. Длительность 35–40 секунд из обсуждения — ориентир, не измеренный TTS. Петля последней полной версии: «Now imagine you're back at the checkout...» → «Two full shopping carts. Five tiny baskets. Which line would you pick?»; живое прослушивание ещё не выполнено.

Сохранить image-first способ: состояния исходной AI-иллюстрации и FFmpeg, без нового Remotion/симуляционного движка. Не требовать непрерывной анимации ради этого редакционного изменения.
