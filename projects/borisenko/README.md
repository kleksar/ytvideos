# Borisenko — англоязычная версия

Рабочая папка подготовки англоязычного дубляжа видео Дмитрия Борисенко. Задача первого теста — сохранить его манеру и смысл русской речи, добавить английскую озвучку и проверить, насколько естественно она синхронизируется с видеорядом.

Дмитрий Борисенко — отец пользователя. Пользователь сообщил, что согласие на использование его голоса есть. В ElevenLabs создан голос **Maxim Orlov**. Исходная запись голоса для модели и готовая английская озвучка — разные материалы; созданную озвучку нельзя считать автоматически проверенным переводом или готовым дубляжом.

- [Пилот 001: материалы и состояние](pilot_001/README.md)
- [Процесс дубляжа и проверки пауз](DUBBING_WORKFLOW.md)

В качестве предварительной стратегии обсуждались английские название и описание канала и добавление английской аудиодорожки к исходному видео в YouTube Studio при наличии функции. Окончательное название, оформление и способ публикации ещё не согласованы. Работа в этой папке сама по себе не разрешает публикацию.
