# Переозвучка v2: материалы и техническая проверка

Пользователь поручил заново сгенерировать английскую речь отдельными фразами с учётом русских пауз. Разметка `regen_script_v1.json` содержит 108 фраз и примерные русские окна; изменённые формулировки перечислены в `regen_overrides_v1.json`. Оригинальные версии озвучки находятся в `../Source/Voice/regen_v1/`, а версии с изменёнными фразами — в указанном для каждой фразы каталоге overrides. Исходники не перезаписываются.

`../../tools/prepare_phrase_timeline.py` проверяет SHA-256 сгенерированного MP3 и текста по состоянию ElevenLabs, создаёт отдельные WAV при `atempo=0.95` в `../Source/Voice/regen_v1_095/` и вычисляет позиции по примерному русскому началу и измеренной длительности. При `--trim-safe-tail --materialize-tails` оригинальные WAV сохраняются; для фраз, у которых обнаружен тихий хвост, создаются отдельные копии `trimmed/<ID>/<ID>_095_tail.wav`. Рез выполняется не ранее чем через 0,2 секунды после последнего сэмпла с пиком не ниже −50 dBFS. Этот критерий акустический и не гарантирует сохранение тихих нюансов без прослушивания.

Для каждой созданной укороченной копии соседний JSON фиксирует SHA-256 исходного и нового WAV, SHA-256 сохранённого PCM, исходный последний кадр и результаты проверки паузы. При создании скрипт побайтово сравнивает сохранённый PCM копии с префиксом исходника. Перезапись не допускается.

План `regen_placement_v2_trimmed_materialized_v2.json` содержит 108 полных WAV для размещения в Palmier; 54 пути ведут к новым укороченным копиям. Файлы рассчитаны на проигрывание 1× в редакторе: скорость 0,95 уже применена к звуку. План не означает, что монтаж выполнен, и не даёт разрешения повторно создавать или менять таймлайн без проверки состояния. На момент подготовки `assemble_regenerated_palmier.py` проверил план в режиме dry-run без правки проекта: все 108 файлов доступны, расчётные интервалы не перекрываются, длина дорожки не превышает 16 093 кадра.

В автоматической оценке по ASR и акустическим меткам исходный v2 имел среднее абсолютное отклонение начала около 0,382 с и максимум 2,000 с; план с хвостами и запасом по кадрам — среднее около 0,314 с и максимум 1,667 с. У девяти фраз отклонение превышает секунду. Приблизительно 38 английских фраз заканчиваются позже границ соответствующих русских окон. Это диагностика, не гарантия правильной синхронизации; необходимо прослушать весь дубляж и проверить текст, переходы, концовки и баланс фоновой русской дорожки. Отчёты относятся к конкретным файлам и таймлайну на момент подготовки.
